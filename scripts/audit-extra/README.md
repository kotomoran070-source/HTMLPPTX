# Дополнительные замеры аудита

Скрипты второго, независимого аудита скорости (15.11.2026, код коммита `4f2b2c8`). Дополняют `scripts/audit.mjs`:
меряют то, что происходит сразу после правки. Запускать из корня проекта; временные файлы — в `.tmp/` с префиксом `zz`.

Нужны два сервера на тестовой копии презентаций (`node tests/prepare.mjs`): собранная студия на 5192
(`SLIDERIA_DECKS=.tmp/test-decks node scripts/serve.mjs --port=5192`) и `yarn dev` на 5193 — для профилей с именами функций.
Браузер — Chromium Playwright; свой путь — в `SLIDERIA_CHROMIUM`.

| Скрипт | Что меряет |
|---|---|
| `app.mjs [презентация] [K]` | программа Electron: сколько стоит главный процесс и на сколько задерживается мышь при автосохранении (K — шаблон K раз подряд); под `xvfb-run` |
| `save.mjs <имена…>` | время одного сохранения на сервере и ожидание параллельного запроса |
| `srv.mjs` + `top.mjs` | сервер из исходников с профилем процессора (SIGUSR2 — начать, SIGTERM — записать), разбор профиля |
| `misc.mjs` | что пересоздаётся на слайде при правке (видео, 3D, вставка), простой с живым фоном и без, медиа скрытых слайдов |
| `hist.mjs` | запись истории отмены в `sessionStorage`: время и сколько шагов уцелело |
| `json.mjs <имена…>` | объём `JSON.stringify` / `JSON.parse` на одну правку |
| `load.mjs`, `act.mjs` (+ `prof.mjs`) | профиль открытия студии и действий: листание, выделение, перетаскивание, отмена, ввод |
| `pages.mjs`, `heavy.mjs` | загрузка страниц (запросы, долгие задачи, простой), тяжёлые презентации |
| `bundle.mjs` | состав собранной студии по модулям |
| `dup.mjs` | повторы кода (окна из 8 одинаковых строк) |
| `mkbig.mjs K` | большая тестовая презентация `zzbigK` (шаблон K раз) |

Пути и порты в скриптах заданы прямо в коде; это рабочие инструменты одного прогона, а не часть `yarn perf`.

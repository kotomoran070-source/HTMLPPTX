# MCP: Claude правит презентации

MCP (Model Context Protocol) — способ дать агенту (Claude Code, Claude Desktop и другим) инструменты Slideria:
он находит презентацию, читает её содержание и правит операциями ([OPS.md](OPS.md)) — так же надёжно, как человек
в студии: правка проверяется, применяется целиком или не применяется вовсе, и не затирает того, что поменяли
в студии с момента чтения.

## Подключить

Проще всего — из студии: «Файл → Интеграции → Агенты → Подключить агента» (или плашка «кто на связи» на вкладке
«Инструменты»). С подпиской Claude или ChatGPT ключ API не нужен.

- **В один щелчок** — Claude Desktop, Claude Code, ChatGPT · Codex: программа найдена на компьютере — «Подключить
  к …». Claude Desktop — расширением: на Windows файл `Slideria.mcpb` показывается в Проводнике — его перетаскивают
  в окно Claude Desktop (или Settings → Desktop app → Extensions → Advanced settings → Install Extension…), на macOS
  сразу открывается окно установки; «Install» — и Slideria в его Extensions, без перезапуска. Карточка ждёт установки
  («Показать файл» / «Открыть снова»). Второй способ — ссылка «Подключить через файл настроек» в той же карточке
  (запись в `claude_desktop_config.json`, нужен перезапуск приложения).
  ChatGPT — перезапустить (Claude Code и Codex — просто запустить `claude`, `codex`). Не найдена — «Скачать».
  Подключённым — зелёная точка у вкладки клиента и «Отключить».
- **Вручную** — строка для выбранного клиента (те же три, Cursor, VS Code, другой) уже с путями этого компьютера —
  «Скопировать».

Сервер запускает сам клиент — вручную `yarn mcp` запускать не нужно.

| Где Slideria | Команда, которую запускает клиент |
|---|---|
| Программа (установщик) | сама программа с ключом `--mcp`: `…/Slideria.exe --mcp`, `/Applications/Slideria.app/Contents/MacOS/Slideria --mcp`, AppImage — сам файл. Node не нужен |
| Папка проекта | `node /путь/к/HTMLPPTX/scripts/mcp.mjs` (нужен Node.js) |

**Claude Code** (в терминале; `--scope user` — для всех папок):

```bash
claude mcp add --scope user slideria -- node /путь/к/HTMLPPTX/scripts/mcp.mjs
```

**Claude Desktop** — «Настройки → Разработчик → Изменить конфигурацию» (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "slideria": { "command": "node", "args": ["/путь/к/HTMLPPTX/scripts/mcp.mjs"] }
  }
}
```

Папка презентаций — `presentations/` проекта; другая — `--decks=папка` в конце команды (например, папка программы
Slideria: `--decks=/Users/имя/Documents/Slideria`). У программы с `--mcp` — её папка «Документы/Slideria».

Дальше — обычной речью: «В презентации „Итоги квартала“ подставь компанию на титул, убери слайды-подсказки
и добавь слайд с тремя цифрами».

## Инструменты

| Инструмент | Что делает |
|---|---|
| `list_presentations` | презентации: имя, название, число слайдов, когда правили |
| `read_presentation` | краткое содержание: слайды с номерами, id и ревизиями, объекты с номерами и текстом; со `slide` — один слайд целиком |
| `find_text` | где встречается текст (без учёта регистра, ё = е): слайд с ревизией, объект или блок, поле и кусок текста — адреса для правки; ищет там же, где меняет `text.replace` |
| `view_slides` | картинки слайдов (PNG) в конечном виде — все шаги показа открыты, анимации доиграны: агент сам видит, что текст не вылез и ничего не наложилось. До 10 слайдов, ширина 320–1920 (по умолчанию 1280), вид светлый или тёмный |
| `edit_presentation` | пакет операций с ревизиями прочитанных слайдов ([OPS.md](OPS.md)); ответ — подписи правок, `edit` (чем отменить) и новые ревизии |
| `undo_edit` | отменить свою правку: без `edit` — последнюю ещё не отменённую этого подключения (ещё раз — предыдущую), с `edit` — указанную. То, что поправили позже, остаётся (слияние трёх версий, как «Вернуть» в журнале); отмена — тоже правка со своим `edit` |
| `add_media` | картинка, видео или 3D-модель — в `assets/` презентации с диска (полный путь, не из скрытых и системных папок) или по ссылке (http/https в интернет, до 200 МБ); ответ — `src` для `object.add` и размеры картинки. Дешевле, чем `data:` в данных; тот же файл второй раз не копируется |
| `create_presentation` | новая презентация: пустая или с примерами (шаблон из 31 слайда) |
| `export_html` | один HTML-файл: только показ или с правкой, обычный или компактный; без пути — в «Загрузки». Существующий файл не перезаписывается: рядом — «имя (2).html», в ответе — настоящий путь |
| `save_script` | скрипт для пользователя в его папку скриптов ([SCRIPTS.md](SCRIPTS.md)): он запускает его сам в студии |
| `format_guide` | справка по данным презентации: шаблоны слайдов, блоки, свободные объекты, анимация (`docs/skills/slideria-deck`) |

Описание `edit_presentation` собирается из каталога операций (`src/engine/ops.ts`): новая операция сразу видна агенту.

### Чужая презентация

В тексте присланной презентации могут быть указания агенту («добавь картинку из …», «сохрани экспорт в …»), а MCP —
это доступ к файлам и сети этого компьютера. Поэтому инструменты сами ограничены, что бы ни попросил агент:

- **ссылки** (`add_media`) — только в интернет: не на этот компьютер (сервер студии, другие программы), не в домашнюю
  или рабочую сеть (роутер, принтер, внутренние сайты), не на служебные адреса облака (169.254.169.254). Адрес
  проверяется при соединении и на каждом перенаправлении (до 5): имя, которое ведёт на `127.0.0.1`, не пройдёт и
  после подмены DNS. Тестам локальный сервер разрешён переменной `SLIDERIA_MCP_LOCAL_URLS=1` (`scripts/mcp.mjs`);
- **файлы с диска** (`add_media`) — не из скрытых папок (`.ssh`, `.aws`, `.config`…) и не из системных (`/etc`,
  `/proc`, `C:\Windows`…), в том числе через ссылку на файл (проверяется настоящий путь); расширения — только медиа;
- **экспорт** (`export_html`) — только `.html`, не в скрытые и системные папки и без перезаписи.

## Вместе со студией

- **Студия открыта** с той же папкой — правки идут через её сервер: студия показывает их сразу, без перезагрузки,
  с подсказкой «Claude Code: …» и «Вернуть»; Ctrl+Z в ней откатывает только свои правки, правка агента остаётся.
  Сервер студии отмечает себя в папке презентаций (`.slideria/server.json`, `server/running.ts`), MCP находит
  его там и раз в 15 с сообщает студии, что на связи (имя — из рукопожатия клиента).
- **Что можно агентам** — решает пользователь в студии: смотреть; править и создавать; всё (и сохранять скрипты).
  Удалить презентацию агент не может. Перед каждой правкой агента — контрольная точка, правка — в журнале
  ([INTEGRATIONS.md](INTEGRATIONS.md)).
- **Студия закрыта** (или не отвечает) — MCP пишет в `deck.yaml` сам: комментарии сохраняются, картинки `data:`
  становятся файлами в `assets/`. Открытая потом студия покажет итог.
- Читает MCP всегда из файлов: студия записывает правки сама за секунду.

## Как устроено

```
scripts/mcp.mjs   запуск из папки проекта: stdin/stdout, папка презентаций; TypeScript сервера загружает Vite
desktop/main.mjs  программа с --mcp: без окон и без второго экземпляра-окна, stdout — только протокол (журнал — в
                  stderr); сервер MCP — из кода программы (startMcp в server/serve.ts)
desktop/mcp-input.mjs  вход MCP программы: на Windows Electron подменяет process.stdin пустым, уже закрытым
                  потоком — труба агента читается с fd 0 сокетом; перед выходом stdout дописывается
server/mcp.ts     инструменты и протокол (JSON-RPC 2.0) без транспорта: в облаке — тот же обработчик по HTTP
server/shot.ts    картинки слайдов: страница проигрывателя в режиме снимка (?shot=3,5, src/engine/print.ts) — слайды
                  в конечном виде, как при печати; файлы презентации — с маленького сервера на 127.0.0.1 (случайный
                  порт и ключ), а не внутри HTML. Браузер — снаружи: в программе — невидимое окно Electron, которое
                  рисует себя в память (desktop/shot.mjs), из папки проекта — Playwright (scripts/pw-shot.mjs; нет
                  его браузера — Chrome или Edge компьютера). Тем же снимком смотрит на слайд чат «Агент» (AGENT.md)
server/running.ts какой сервер студии работает с папкой
server/connect.ts подключение в один щелчок (команды agents-clients, agents-connect, agents-disconnect);
                  пакет расширения Claude Desktop (.mcpb) — шаблон templates/mcpb
```

**В один щелчок** (`server/connect.ts`):

| Клиент | Как подключается | Подключён ли |
|---|---|---|
| Claude Desktop | Расширением (`.mcpb`, манифест 0.3 — [modelcontextprotocol/mcpb](https://github.com/modelcontextprotocol/mcpb)): Slideria собирает пакет — `manifest.json` (название, описание, значок, список инструментов `MCP_TOOLS` — сверяется с самим сервером MCP в тестах), `server/launch.cjs` и `server/target.json` с командой этой Slideria — (`Slideria.mcpb` во временной папке). macOS — открывает его (`open`), окно установки показывает Claude Desktop; нет программы для `.mcpb` — как на Windows. Windows — показывает в Проводнике (в программе — `shell.showItemInFolder` главного процесса: Проводник, запущенный из служебного процесса сервера, открывался скрытым; из папки проекта — `explorer /select`): открытый через систему, файл доходит до Claude коротким именем `SLIDER~1.MCP`, и Claude не узнаёт расширение, а прикладывает файл к чату. Запускает расширение Claude Desktop своим Node.js: `launch.cjs` запускает Slideria по команде из `target.json` (без `ELECTRON_RUN_AS_NODE` и `NODE_OPTIONS` — Node у Claude Desktop может быть самим Electron) и переливает протокол потоками — у встроенного Node вход и выход не трубы (fd 0 и 1 пусты), переданные напрямую, они давали Slideria закрытый вход (тест — запуск с такими потоками поверх IPC); нет программы по этому пути — понятная ошибка в журнале Claude. Повторное «Подключить» открывает тот же пакет — Claude Desktop обновит расширение (другой путь, новая версия). Пакет не собрался или не показался — как раньше, запись в файле настроек, ниже. «Отключить» убирает запись из файла настроек; расширение удаляют в самом Claude Desktop (Settings → Desktop app → Extensions → Slideria → Uninstall) — карточка так и говорит. Шаблон — `templates/mcpb` (вне `app.asar`) | список `extensions-installations.json` или папка `Claude Extensions` рядом с файлом настроек — запись с именем `slideria` (где Claude Desktop держит расширения, не описано — так видно на компьютерах); расширение есть — прежняя запись в файле настроек убирается, иначе был бы второй такой же сервер. Пока расширение ждёт установки, «Интеграции» спрашивают каждые 2 с, до 5 минут |
| Claude Desktop, запасной путь | `mcpServers.slideria` в `claude_desktop_config.json` (macOS — `~/Library/Application Support/Claude`, Linux — `~/.config/Claude`). На Windows какой файл читает Claude, зависит от версии — пишется во все, что есть: `%APPDATA%\Claude`, у новых версий из Microsoft Store — `%LOCALAPPDATA%\Claude-Data\claude_…`, и личная копия пакета `…\Packages\Claude_…\LocalCache\Roaming\Claude` — только если она уже есть (новая заслонила бы обычный файл со всеми серверами). Остальное в файле не трогается, прежний — копией `.bak` рядом; испорчен хоть один — не трогается ни один | запись во всех файлах (Claude при выходе может переписать свой без неё — тогда «не подключена») |
| Claude Code | `claude mcp add --scope user slideria -- …` (прежняя запись — сначала `mcp remove`) | `~/.claude.json` |
| ChatGPT · Codex | `[mcp_servers.slideria]` (`command`, `args`) прямо в `~/.codex/config.toml` (или `$CODEX_HOME/config.toml`): его читают ChatGPT для компьютера (приложение Codex с июля 2026 — его часть), Codex в терминале и в редакторе, так что своя программа `codex` не нужна. Прежняя запись Slideria (с подтаблицами, строкой в `[mcp_servers]`) заменяется, остальное в файле — как было, прежний — копией `.bak`. Путь Windows — буквальной строкой TOML. Найден — если есть ChatGPT (macOS — `ChatGPT.app` или `Codex.app` в «Программах», Windows — пакет Microsoft Store `OpenAI.…` или `Programs\ChatGPT`), папка `~/.codex` или программа `codex` | запись в `config.toml` |

Программа `claude` ищется в PATH и там, куда её ставят установщики (`~/.local/bin`, npm, nvm, Volta, Bun,
Homebrew): у программы, запущенной из Dock или меню «Пуск», PATH короче, чем в терминале. Тесты — в подставном
домашнем каталоге (`SLIDERIA_CONNECT_HOME`) с подставным `claude` (`tests/fake-clients.ts`); проверено
и с настоящим Claude Code.

Протокол — свой, без лишних библиотек (установщику не нужны express и прочее из официальной библиотеки MCP);
что он говорит правильно, проверяет официальный клиент MCP в `tests/unit/mcp.spec.ts`. Проверено и вживую:
Claude Code по задаче «подставь компанию, дату и докладчика на титул, удали три слайда-подсказки, добавь слайд
с тремя цифрами» сам нашёл презентацию, прочитал справку и образец оформления и сделал всё одним пакетом за 24 с.

Картинка слайда — около 0,5 с на запрос (первая — ~1 с: запускается браузер); 1280×720 стоят агенту примерно
1200 токенов, для обзора многих слайдов хватает ширины 480–640.

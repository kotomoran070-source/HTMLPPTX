# Claude Design → HTMLPPTX

Каркас удобно делать в Claude Design, а доводить и показывать здесь. Импорт переносит слайды почти 1:1: элементы, анимации, порядок появления.

## Как перенести

1. В Claude Design экспортируйте презентацию как HTML.
2. Запустите `yarn dev` и перетащите файл на страницу (или «Все слайды» → «Импорт HTML…»).
3. В окне импорта проверьте имя презентации. Галочка «Привязать цвета к теме» включена: тёмная тема и смена акцента будут работать. Нажмите «Создать».
4. Правьте в режиме правки (E). `yarn build имя` — один файл для показа и отправки.

В терминале то же самое: `yarn merge-html ~/Downloads/deck.html имя` (`--no-theme` — без привязки цветов, `--dry-run` — только отчёт).

## Что получается

| В Claude Design | После импорта |
|---|---|
| Слайд 1920×1080 | Слайд-холст 1280×720 (`template: canvas`), всё пересчитано пропорционально |
| Элемент (текст, карточка, картинка) | Свободный объект: двигается, растягивается, удаляется. Тексты правятся на месте, картинки заменяются |
| Анимированная вставка | «Живая» вставка (`type: embed`), запускается при показе слайда |
| Порядок появления элементов | `enter` и `delay` у объектов |
| Цвета | Ссылки на цвета темы (если галочка включена) |

## Привязка цветов к теме

Claude Design записывает в файл готовые цвета: `color: rgb(17, 24, 39)`. Импорт находит среди них цвета темы и заменяет их ссылками: `color: var(--tx)`. После этого слайды перекрашиваются в тёмной теме и при смене акцентного цвета («Цвет» в режиме правки).

- Цвет подбирается по свойству. Цвет текста ищется среди цветов текста, фон — среди фонов, рамка — среди рамок. Поэтому тёмная шапка таблицы не станет светлой, хотя её цвет совпадает с цветом текста.
- Промежуточный оттенок (серый между основным и приглушённым текстом) становится смесью двух цветов темы. В тёмной теме смесь тех же цветов даёт такой же оттенок.
- Блок со своим фоном (тёмная карточка, фото, градиент) не перекрашивается вместе с содержимым.
- Подложка QR-кода остаётся белой: инвертированный код не читается.
- Слайды с тёмным фоном остаются тёмными в обеих темах.
- Цвета без пары в теме (красный «Высокий», зелёный «Готово») остаются как есть. Окно импорта показывает их списком.
- Если основной цвет макета не синий, импорт считает его акцентным и записывает в `theme.accent`.

Презентацию, импортированную без привязки (или до её появления), можно привязать позже. В `yarn dev`: «Все слайды» → «Цвета → тема…». В терминале: `yarn bind-theme имя`. Прежняя версия `deck.yaml` сохраняется в `.backup/`.

Картинки (SVG и PNG внутри `<img>`) не перекрашиваются: это отдельные файлы. Если иллюстрация должна меняться с темой, в Claude Design её лучше рисовать фигурами, а не вставлять картинкой.

## Как делать каркас, чтобы всё работало лучше

1. **Цвета из палитры темы.** Берите цвета из таблицы ниже: они привяжутся к теме точно. Близкие оттенки тоже привяжутся, а случайные «почти синие» останутся своими.

   | Роль | Цвет |
   |---|---|
   | Фон слайда | `#F8FAFC` |
   | Карточки | `#FDFEFF` или белый |
   | Второй фон | `#F3F4F6` |
   | Текст / второстепенный / подписи | `#111827` / `#374151` / `#6B7280` |
   | Рамки | `#E5E7EB`, `#D1D5DB` |
   | Акцент / тёмный / светлый фон / рамка | `#2563EB` / `#1D4ED8` / `#EFF6FF` / `#93C5FD` |

   Свой акцент тоже работает: используйте один основной цвет и его светлые и тёмные оттенки.
2. **Текст — текстом.** Не запекайте надписи в картинки: такой текст не правится и не перекрашивается.
3. **Один смысловой блок — один элемент.** Каждый элемент Claude Design становится объектом, который двигается целиком. Карточку с заголовком и текстом удобно делать одним элементом, а подпись, которую захочется двигать отдельно, — отдельным.
4. **Тёмный слайд — тёмным фоном слайда.** Он останется тёмным в обеих темах, как финальный «космический» слайд.
5. **QR-коды подписывайте:** alt с «QR» (например, «QR-код сайта»). По подписи импорт узнаёт QR-код и не трогает его подложку.

## Промпт для Claude Design

````text
Делаем каркас презентации для последующего импорта в HTMLPPTX.
Палитра (используй только её, кроме смысловых цветов статусов):
фон слайда #F8FAFC, карточки #FDFEFF, второй фон #F3F4F6,
текст #111827, второстепенный #374151, подписи #6B7280,
рамки #E5E7EB и #D1D5DB,
акцент #2563EB, тёмный акцент #1D4ED8, светлый акцентный фон #EFF6FF, акцентная рамка #93C5FD.
Надписи — только текстом, не картинками. Карточка с заголовком и текстом — один элемент.
Тёмные слайды — тёмным фоном слайда. QR-коды — с подписью «QR-код …».
````

## Повторный импорт

Новый экспорт того же каркаса под тем же именем заменяет презентацию целиком. Прежняя версия сохраняется в `.backup/`, но правки, сделанные в проекте, пропадут. Чтобы сохранить обе версии, импортируйте под другим именем и перенесите нужное.

# Скрипты

Своё действие одним файлом — как скрипты в After Effects, только безопаснее. Скрипт правит презентацию теми же
операциями, что и агенты ([OPS.md](OPS.md)): каждая правка проверяется, весь запуск — один шаг отмены (Ctrl+Z),
в журнале — что поменялось. Страница студии, файлы и сеть скрипту недоступны.

**Где.** Файлы `.js` в папке `scripts` рядом с презентациями (в программе — «Документы/Slideria/scripts»; путь —
в «Файл → Интеграции → Скрипты»). Встроенные — в программе (`templates/scripts`): «Оглавление», «Один переход для всех
слайдов», «Заменить слова по списку».

**Как запустить.** «Скрипты» на вкладке «Инструменты» (меню на ленте), Ctrl+K — «Скрипт: …», или
«Файл → Интеграции → Скрипты»: карточки скриптов, справа — поля выбранного и «Запустить». Поменял скрипт
что-то — «Файл» закрывается, результат сразу на слайдах, итог — в подсказке; ошибка — прямо под полями.

**Кто пишет.** Вы — или агент: «Напиши скрипт для Slideria, который…». Агент сохранит его в папку инструментом
`save_script` (нужно разрешение агентам «Всё»).

## Файл скрипта

```js
// @name Пронумеровать слайды
// @description Номер в углу каждого слайда-холста
// @param prefix: text = "Слайд" — Подпись перед номером
// @param size: number = 14 — Размер, px
// @param skipFirst: bool = true — Без номера на титуле
// @param corner: choice(br=Справа внизу, bl=Слева внизу) = br — Угол
export default async function ({ deck, outline, apply, slide, selection, params, log }) {
  const ops = [];
  outline().slides.forEach((s) => {
    if (s.template !== 'canvas' || (params.skipFirst && s.n === 1)) return;
    const x = params.corner === 'br' ? 1120 : 40;
    ops.push({ op: 'object.add', slide: s.n, object: { type: 'text', text: `${params.prefix} ${s.n}`, place: { x, y: 670, w: 120 }, styles: { text: { size: params.size } } } });
  });
  apply(ops);
  log(`Номера — на ${ops.length} слайдах`);
}
```

**Заголовок** — комментарии в начале файла:

| Строка | Что |
|---|---|
| `// @name …` | название в списке и в Ctrl+K (без него — имя файла) |
| `// @description …` | что делает — одной строкой |
| `// @param ключ: вид = значение — Подпись` | поле в форме перед запуском; вид — `text`, `lines` (несколько строк), `number`, `bool`, `choice(a=Подпись, b=Подпись)` |

**Главная функция** — `export default`, получает:

| | |
|---|---|
| `deck` | данные презентации, как в `deck.yaml` (копия: менять — только через `apply`) |
| `outline()` | краткое содержание: слайды с номерами и заголовками, объекты с номерами и первым текстом |
| `apply(ops)` | одна операция или список ([OPS.md](OPS.md#операции)); ответ — подписи правок. Ошибка операции — исключение: запуск не применяется |
| `slide` | номер текущего слайда, с 1 |
| `selection` | номера выделенных объектов на текущем слайде, с 1 |
| `params` | значения полей |
| `log(…)` | строка в итог запуска |

Скрипт работает до 20 секунд, потом останавливается. Ничего не поменял — в итоге «Ничего не поменялось».

## Песочница

Скрипт выполняется в отдельном потоке браузера (`src/studio/script-worker.ts`) с политикой безопасности
(Content-Security-Policy от сервера студии): код — только свой, сеть закрыта (`fetch`, загрузка модулей со
стороны). Доступа к странице студии и к файлам у потока нет. Скрипт видит только данные презентации, которую
и так правит, и меняет их только операциями — итог одним сообщением, студия применяет его одним шагом отмены.

Скрипты не попадают ни в `deck.yaml`, ни в экспортированный файл (не макросы PowerPoint): запускаются только
в студии, вами. Скрипт — ваш код: запускайте то, чему доверяете.

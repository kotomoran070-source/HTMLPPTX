# Свой HTML: правила формата

Презентацию можно сверстать самому или попросить Claude в чате, а потом открыть в проекте и доводить в режиме правки. Файл по этим правилам:

- открывается в браузере как есть: слайды идут столбиком;
- импортируется в проект: перетащите его на страницу в `yarn dev` или выполните `yarn merge-html файл.html имя`;
- после импорта работают тёмная тема, смена акцентного цвета, правка текстов и картинок на месте, перетаскивание объектов, режим докладчика и сборка в один файл.

Готовый пример: [examples/example.html](examples/example.html). Промпт для Claude — [в конце страницы](#промпт-для-claude).

## Каркас

```html
<!doctype html>
<html lang="ru" data-accent="#2563EB">
<head>
<meta charset="utf-8">
<title>Название презентации</title>

<!-- Только для просмотра файла в браузере. При импорте пропускается -->
<style data-preview>
  :root {
    --bg: #F8FAFC; --surf: #FDFEFF; --alt: #F3F4F6; --tx: #111827; --tx2: #374151; --mu: #6B7280;
    --bd: #E5E7EB; --bd2: #D1D5DB; --ac: #2563EB; --ach: #1D4ED8; --acs: #EFF6FF; --acb: #93C5FD; --on-ac: #FFFFFF;
    font-family: system-ui, -apple-system, "Segoe UI", Roboto, Arial, sans-serif;
  }
  body { margin: 0; padding: 24px; background: #CBD5E1; }
  section.slide { position: relative; width: 1280px; height: 720px; box-sizing: border-box;
                  padding: 48px 64px; margin: 0 auto 24px; overflow: hidden; }
</style>

<!-- Стили презентации: переносятся в проект и действуют только внутри слайдов -->
<style>
  .slide { background: var(--bg); color: var(--tx); display: flex; flex-direction: column; gap: 24px; }
  .card  { background: var(--surf); border: 1px solid var(--bd); border-radius: 16px; padding: 22px; }
</style>
</head>
<body>

<section class="slide" data-id="intro" data-notes="Текст для окна докладчика">
  <h1>Заголовок</h1>
  <p>Текст слайда</p>
</section>

<section class="slide" data-id="results">
  …
</section>

</body>
</html>
```

## Правила

### Слайды

| Правило | Зачем |
|---|---|
| Один `<section class="slide">` — один слайд 1280×720 | Всё вне секций не переносится |
| Поля слайда по умолчанию `48px 64px`. Свои — в `style` секции или в CSS `.slide` | Вёрстка слайда занимает всю его площадь |
| `data-id="results"` — короткое имя слайда (латиница) | По нему сливаются правки |
| `data-notes="…"` или `<aside class="notes">…</aside>` внутри секции | Заметки докладчика |
| `data-label="…"` | Название в обзоре, если не подходит первый заголовок |
| Фон слайда — `style="background: …"` на секции | Тёмный фон (`#0B1220`) = слайд тёмный в обеих темах |

### Цвета

Все цвета пишите через переменные темы. Только тогда слайды перекрашиваются в тёмной теме и при смене акцентного цвета.

| Переменная | Что это | Светлая тема |
|---|---|---|
| `--bg` | Фон слайда | `#F8FAFC` |
| `--surf` | Фон карточек и панелей | `#FDFEFF` |
| `--alt` | Второй фон (полосы таблиц, подложки) | `#F3F4F6` |
| `--tx` | Основной текст, заголовки | `#111827` |
| `--tx2` | Второстепенный текст | `#374151` |
| `--mu` | Приглушённый текст, подписи | `#6B7280` |
| `--bd` | Рамки, разделители | `#E5E7EB` |
| `--bd2` | Рамки заметнее | `#D1D5DB` |
| `--ac` | Акцентный цвет | `#2563EB` |
| `--ach` | Акцент темнее: текст на светлом акцентном фоне | `#1D4ED8` |
| `--acs` | Светлый акцентный фон: чипы, подсветка | `#EFF6FF` |
| `--acb` | Акцентная рамка | `#93C5FD` |
| `--on-ac` | Текст на акцентном фоне (кнопки) | `#FFFFFF` |

- Акцентный цвет всей презентации — `data-accent="#16A34A"` у `<html>`. Оттенки `--ach`, `--acs`, `--acb` построятся сами.
- Промежуточные оттенки — через смесь: `color-mix(in srgb, var(--tx2) 60%, var(--mu))`.
- Цвета со смыслом (красный «Высокий», зелёный «Готово») можно писать прямо: `#DC2626`. Они не меняются с темой, и это нормально.
- Цвета, записанные прямо, но совпадающие с цветами темы (`#111827`, `#2563EB`…), импорт привяжет к теме сам. Прямо записанные цвета покажутся в окне импорта.

### Тексты

- Каждый текст правится на месте: заголовок, абзац, пункт списка, ячейка, подпись.
- Внутри текста можно `<b>`, `<i>`, `<u>`, `<a href>`, `<br>` и цвет части текста: `<span style="color: var(--ac)">`. Всё это сохранится как оформление текста.
- `<span class="…">` внутри текста делит его на отдельные куски. Для чипов и меток это правильно: у каждого свой текст. Для одной фразы используйте `<b>` или `style`.

### Картинки

- `<img src="data:image/png;base64,…">` — картинка внутри файла. Её можно заменить в режиме правки.
- Картинка по ссылке (`https://…`) без интернета не покажется. Картинка по пути (`photo.jpg`) не найдётся: замените её после импорта.
- Иконки и схемы удобнее рисовать встроенным `<svg>` с цветами `fill="var(--ac)"` или `style="fill: var(--ac)"`.

### Свободные объекты

Элемент, который нужно двигать мышью, — прямой потомок секции с абсолютными координатами в пикселях слайда:

```html
<div class="badge" style="position: absolute; left: 960px; top: 560px; width: 240px">24 устройства</div>
```

- `height` необязательна: без неё высота по содержимому.
- Вместо `style` можно `data-x="960" data-y="560" data-w="240" data-h="120"`.
- Появление при открытии слайда: `data-enter="rise"` (`fade`, `rise`, `drop`, `left`, `right`, `scale`, `pop`) и `data-delay="400"` (мс).

Остальная вёрстка слайда (обычный поток, flex, grid) двигается целиком, а тексты и картинки в ней правятся.

### Анимации и интерактив

- Скрипты не переносятся. Анимации — на CSS: `@keyframes` в `<style>`.
- Анимация на JavaScript, canvas, интерактивная схема — «живая» вставка: `<iframe srcdoc="…">` со свободными координатами. Документ внутри может брать цвета темы: `fill: var(--ac, #2563EB)` (второе значение — для просмотра файла без проекта).

```html
<iframe style="position: absolute; left: 760px; top: 300px; width: 440px; height: 320px; border: 0"
        srcdoc="&lt;!doctype html&gt;&lt;style&gt;…&lt;/style&gt;&lt;svg&gt;…&lt;/svg&gt;&lt;script&gt;…&lt;/script&gt;"></iframe>
```

### Нельзя

- Внешние стили и шрифты (`<link rel="stylesheet">`, `@import`, Google Fonts): без интернета не загрузятся. Шрифты — системные: `system-ui`, `Georgia`, `ui-monospace`.
- Скрипты вне `<iframe srcdoc>`.
- Вложенные слайды и слайды другого размера.

## Промпт для Claude

Вставьте в чат перед описанием презентации:

````text
Сделай презентацию одним HTML-файлом по правилам HTMLPPTX.

Формат:
- <html lang="ru" data-accent="#2563EB">, в <head> — <title>, <style data-preview> и <style>.
- Каждый слайд — <section class="slide" data-id="латиница" data-notes="заметки докладчика">, 1280×720, поля 48px 64px.
- <style data-preview> скопируй как есть:
  :root { --bg:#F8FAFC; --surf:#FDFEFF; --alt:#F3F4F6; --tx:#111827; --tx2:#374151; --mu:#6B7280; --bd:#E5E7EB; --bd2:#D1D5DB; --ac:#2563EB; --ach:#1D4ED8; --acs:#EFF6FF; --acb:#93C5FD; --on-ac:#FFFFFF; font-family: system-ui, -apple-system, "Segoe UI", Roboto, Arial, sans-serif; }
  body { margin:0; padding:24px; background:#CBD5E1; }
  section.slide { position:relative; width:1280px; height:720px; box-sizing:border-box; padding:48px 64px; margin:0 auto 24px; overflow:hidden; }
- Во втором <style> — стили презентации: классы (.card, .grid, .chip…), @keyframes. Правило .slide задаёт раскладку слайда.

Цвета — только переменные: --bg фон слайда, --surf карточки, --alt второй фон, --tx текст, --tx2 второстепенный, --mu подписи, --bd/--bd2 рамки, --ac акцент, --ach тёмный акцент, --acs светлый акцентный фон, --acb акцентная рамка, --on-ac текст на акценте. Оттенки — color-mix(in srgb, var(--a) N%, var(--b)). Прямо писать можно только смысловые цвета (красный — ошибка, зелёный — готово). Тёмный слайд — style="background:#0B1220" на секции, цвета внутри такого слайда — прямо.

Тексты — обычными тегами (h1, h2, p, li, span, td). Внутри текста — только b, i, u, a, br и <span style="color:var(--ac)">.
Картинки — <img src="data:…">, иконки — встроенный <svg> с fill/stroke через var(--…).
Элементы, которые должны двигаться отдельно (бейджи, подписи, картинки поверх), — прямые потомки секции с style="position:absolute; left:Xpx; top:Ypx; width:Wpx", можно data-enter="rise" data-delay="300".
Без внешних ссылок, шрифтов и скриптов. Анимации — CSS. Если нужна анимация на JS — <iframe srcdoc> со свободными координатами, цвета внутри — var(--ac, #2563EB).

Верни только HTML-файл целиком.
````

# Промт: анимированные фоны для Slideria

Как пользоваться: скопируйте текст ниже (от «Ты — шейдерный дизайнер…» до конца) в чат с моделью, в конце укажите, сколько вариантов и в каком настроении нужно. Готовые блоки `=== backdrop ===` присылайте как есть — по ним фон добавляется в приложение без переделок (сцена в `src/components/backdrop/backdrop.ts`, название — в `src/engine/backdrops.ts`, статичный вид — в `backdrop.css`).

---

Ты — шейдерный дизайнер. Сделай анимированные фоны для слайдов презентаций (приложение Slideria). Фон лежит под текстом слайда, поэтому он красивый, но не мешает читать.

## Как фон встроен

- WebGL 1 (GLSL ES 1.0), холст на весь слайд 16:9, прозрачный: под ним — светлый или тёмный фон слайда, сверху — текст.
- Тип `quad` (основной): только фрагментный шейдер на весь слайд. В начало приложение само подставит строку — НЕ объявляй это заново:
  `precision mediump float;uniform vec2 r;uniform float t;uniform vec3 c1;uniform vec3 c2;uniform float k;`
  - `r` — размер холста в пикселях (`gl_FragCoord.xy / r` — координаты 0…1), пропорции `r.x / r.y` ≈ 1.78;
  - `t` — время в секундах, растёт без конца (бывает и 1000+);
  - `c1` — акцент темы, `c2` — второй цвет темы (RGB 0…1). Уже осветлены для тёмных слайдов;
  - `k` — общая сила (0.2…1.1), её подбирает приложение для светлых и тёмных слайдов.
- Тип `points` (только если нужны частицы): вершинный шейдер точек. Объявляй сам: `attribute vec3 s; uniform float t; uniform vec2 r; uniform float px; uniform vec3 c1; uniform vec3 c2; varying float va; varying vec3 vc;` — задай `gl_Position`, `gl_PointSize` (умножай на `px`: это масштаб к высоте 720), `vc` (цвет) и `va` (прозрачность 0…1). Точку рисует готовый мягкий круг. `s` — семя каждой точки, одно из: `random` (три случайных 0…1), `index` (`s.x = (i+0.5)/n`, `s.y = i`, `s.z` случайное), `grid W×H` (`s.x`, `s.y` — 0…1 по сетке, `s.z` случайное).

## Обязательно

1. Выход — цвет, уже умноженный на прозрачность: `gl_FragColor = vec4(col * a, a);`, где `a` уже умножена на `k`. Фон прозрачный там, где ничего нет.
2. Цвета — только из `c1`, `c2` и их смесей (с белым/чёрным — понемногу). Никаких своих оттенков: фон должен подходить к любой теме.
3. Читаемость: средняя заметность низкая, пиковая `a` до ~0.6·k; левый верхний угол (там заголовок) — спокойнее остального слайда; без резких вспышек.
4. Движение медленное и бесконечное: цикл не короче 20 с, никаких рывков и «перезапусков», мерцание не чаще 3 раз в секунду. Используй `t` с малыми множителями (0.02…0.6).
5. Лёгкость: не больше 32 шагов в циклах, до 4–5 октав шума, без текстур. Фон идёт 30 кадров в секунду на встроенной видеокарте. Мягкие фоны (пятна, туман) рисуются в половинном размере — укажи `scale`.
6. Строгий GLSL ES 1.0: границы циклов — константы; дробные числа с точкой (`1.`, `.5`); нет `round`, битовых операций, `texture`, массивов-констант с инициализацией. `fwidth` — только если пишешь `derivatives: yes` (тогда первой строкой шейдера `#extension GL_OES_standard_derivatives : enable`, до остального кода).
7. Свои функции (шум, хэш) пиши сам внутри `fs`.
8. Статичный вид `css` — для миниатюр и печати: только `background` (+ при желании `mask`) из CSS-градиентов в цветах `var(--ac)` (акцент) и `var(--bd2)` (второй цвет), через `color-mix(in srgb, var(--ac) 20%, transparent)`. Того же характера, что анимация.

## Уже есть (не повторяй)

Переливы, сияние, шёлк, волны линий, рельеф-горизонтали, лучи из угла, боке, всплывающие частицы, звёздное поле, снегопад, листопад, точки с волной, сеть узлов, соты, орбиты, сетка-пол (synthwave), глобус из точек, ландшафт из точек, тоннель из колец, лава.

## Формат ответа

Каждый вариант — отдельным блоком, ровно так:

```
=== backdrop ===
id: latin-kebab (коротко, уникально)
name: Название (1–2 слова по-русски)
mood: спокойный | средний | заметный
idea: одно предложение — что видно и как движется
type: quad | points
scale: 0.5 | 0.75 | 1
fps: 30 | 60
k: [светлые, тёмные]   (например [0.4, 0.55])
derivatives: no | yes
seed: (только для points) random | index | grid 110x50
count: (только для points) [облегчённо, полно], например [300, 900]
fs: |
  (код фрагментного шейдера без строки-заголовка; для points — не нужен)
vs: |
  (только для points: вершинный шейдер целиком)
css: |
  (значение background, можно несколько слоёв; mask — отдельной строкой «mask: …»)
```

Без пояснений между блоками. Перед ответом проверь каждый шейдер глазами компилятора GLSL ES 1.0: объявлены ли все переменные, нет ли деления на ноль, все ли числа дробные.

Сделай **N вариантов**. Настроение: **…** (например: «8 спокойных для деловых презентаций и 4 заметных для титулов»).

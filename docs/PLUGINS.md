# Плагины

Плагин добавляет в студию свою панель рядом со слайдом: кнопка — в группе «Плагины» на вкладке «Инструменты» и
в Ctrl+K («Плагин: …»). Правит презентацию теми же операциями, что агенты и скрипты ([OPS.md](OPS.md)): каждая правка
проверяется, весь вызов — один шаг отмены (Ctrl+Z), в журнале — «плагин · …» с «Вернуть». Что плагину можно, видно
до включения; без согласия он не включается. Чем плагин отличается от скрипта ([SCRIPTS.md](SCRIPTS.md)): у него
свой интерфейс, он живёт, пока открыта панель, может работать с файлами презентации и ходить в сеть — к адресам,
которые разрешили.

Дальше по плану ([PLAN.md](PLAN.md#плагины)): установка из архива, свои блоки на слайде и в выгруженном файле,
мастерская (каталог, подпись, обновления).

## Где

- Свои плагины — папки в папке `plugins` рядом с презентациями (в программе — «Документы/Slideria/plugins»; путь —
  в «Файл → Интеграции → Плагины»). Встроенные — в программе (`templates/plugins`), пока их нет.
- «Файл → Интеграции → Плагины»: карточки плагинов, справа — выбранный: что делает, версия, автор, разрешения,
  «Включён», «Открыть панель», «Разрешить…» (попросил нового в обновлении), «Удалить плагин…» (папка — в корзину проекта `.trash/plugins-<время>/`; вернуть —
  перенести обратно). Новая папка появляется выключенной.
- Включили — что разрешили, запоминается в `.slideria/plugins.json`; выключили и включили снова — без вопроса, пока
  плагин не попросит нового (новый адрес сети в обновлении): тогда он не работает, пока не разрешат.
- Панель — в колонке справа от слайда, той же, что у «Порядка» анимаций: открыта одна из них.

## Пакет

```
plugins/
  photos/
    plugin.json
    panel.html
    panel.js        ← по желанию: <script src="panel.js"> встраивается в панель
    panel.css       ← <link rel="stylesheet" href="panel.css"> — тоже
    logo.png        ← <img src="logo.png"> — данными
```

`plugin.json`:

```json
{
  "name": "Фото и иконки",
  "description": "Поиск фото и иконок прямо в студии",
  "version": "0.3",
  "author": "Имя автора",
  "api": 1,
  "icon": "image",
  "panel": { "file": "panel.html", "width": 320 },
  "button": { "label": "Фото и иконки", "title": "Поиск фото и иконок" },
  "edit": true,
  "files": true,
  "network": ["api.example.com", "cdn.example.com"]
}
```

| Поле | Что |
|---|---|
| `name` | название — в списке, на кнопке и в Ctrl+K (до 60 знаков) |
| `api` | версия API плагинов: сейчас `1`; плагин для другой версии не включается |
| `panel` | `file` — HTML-файл в папке плагина, `width` — ширина панели, 260–480 px (по умолчанию 320) |
| `description`, `version`, `author` | что делает, версия, автор — в «Плагинах» и в вопросе о включении |
| `icon` | значок студии (`components/icons.ts`: `image`, `music`, `chart`, `sparkle`…); нет — общий |
| `button` | подпись кнопки на ленте (`label`, до 30 знаков) и подсказка (`title`) |
| `edit` | `true` — править презентацию (`slideria.apply`) |
| `files` | `true` — файлы презентации: читать и добавлять (`slideria.files`) |
| `network` | адреса, к которым панель ходит по сети: имена сайтов (только https, без порта и пути), не больше 20 |

Файлы панели: страница и то, что она подключает (`.js`, `.css`, картинки, `.woff2`) — до 2 МБ каждый. Свои
`<script src>`, `<link rel="stylesheet">` и `<img src>` студия встраивает в страницу сама: у панели нет адреса,
по которому их можно было бы загрузить. Модули с `import` — собирайте в один файл. Остальные файлы — `slideria.file()`.

## Разрешения

| | Что можно | Откуда |
|---|---|---|
| **Править презентацию** | `slideria.apply` | `"edit": true` |
| **Файлы презентации** | `slideria.files`: список, чтение, новый файл в `assets/` | `"files": true` |
| **Своя панель** | панель рядом со слайдом | `panel` |
| **Сеть: адреса** | `fetch`, картинки и звук — только с этих адресов | `network` |

Всё остальное закрыто всегда:

- **Студия.** Панель — рамка без своего адреса (`sandbox` без `allow-same-origin`): страница студии, её команды
  (сервер отвечает «Чужой источник запроса»), хранилища браузера и cookie ей недоступны.
- **Файлы.** Только папка `assets/` своей презентации; добавить можно картинку, видео, звук, 3D-модель — не код
  (`.html`, `.js`, `.wasm`). Файл не заменяется и не удаляется: имя занято — новый получает номер, тот же файл
  уже есть — возвращается его путь; отмена правки файл не теряет.
- **Сеть.** Политика безопасности рамки (`connect-src`, `img-src`, `media-src`) — `'none'` или только адреса
  из разрешения; формы, `<base>`, код со стороны — нельзя. Эту политику страница плагина не ослабит.
- **Уход со страницы.** Рамка перешла на другой адрес — панель закрывается, данные ей больше не отдаются;
  в программе такой переход и вовсе не происходит (`desktop/main.mjs`, `will-frame-navigate`).

## В панели: объект `slideria`

```html
<h3>Фото</h3>
<input id="q" placeholder="Что найти">
<button class="primary" id="put">Вставить на слайд</button>
<script>
  document.getElementById('put').onclick = async () => {
    const { slide } = await slideria.selection();
    await slideria.apply({ op: 'object.add', slide, object: { type: 'text', text: document.getElementById('q').value, place: { x: 80, y: 80, w: 600 } } }, { label: 'подпись' });
  };
</script>
```

| | |
|---|---|
| `await slideria.outline()` | краткое содержание: слайды с номерами и заголовками, объекты с номерами и текстом ([OPS.md](OPS.md)) |
| `await slideria.deck()` | данные презентации, как в `deck.yaml` (копия; пути файлов — `./assets/…`) |
| `await slideria.selection()` | `{ slide, objects }` — номер текущего слайда и выделенных объектов на нём, с 1 |
| `await slideria.apply(ops, { label })` | операции (одна или список): одним шагом отмены, в журнал; ответ — `{ changes }`, подписи правок. Ошибка операции — исключение, ничего не меняется. Без `edit` — исключение |
| `slideria.toast(text)` | подсказка в студии: «Название плагина: текст» |
| `await slideria.file(path)` | файл из папки плагина: текст или `data:`-адрес картинки |
| `await slideria.files.list()` | файлы презентации: `[{ path: './assets/…', size }]` |
| `await slideria.files.read(path)` | файл презентации — `Blob` (`URL.createObjectURL` — для `<img>`, `<video>`) |
| `await slideria.files.add(name, data)` | новый файл в `assets/` (`Blob`, `ArrayBuffer`, байты или строка); ответ — `{ path }` для операций |
| `await slideria.storage.get(key)` / `.set(key, value)` | настройки плагина (JSON, до 256 КБ на плагин) — в `.slideria/plugin-data/` |
| `slideria.on(event, f)` | `selection` (`{ slide, objects }`), `slide` (номер), `change` (правка — чья угодно), `theme`; ответ — функция «отписаться» |
| `slideria.close()` | закрыть панель |

Обработка медиа — в самой панели: WebCodecs (`VideoDecoder`, `VideoEncoder`, `AudioDecoder`…), WebAssembly
и свои потоки (`new Worker(URL.createObjectURL(blob))`) работают, а сеть у них та же — только разрешённые адреса.
Итог — `slideria.files.add`, затем операция с новым путём:

```js
const src = await slideria.files.read('./assets/talk.mp4');
const cut = await trim(src, 12, 40);                     // своя обработка: WebCodecs или WebAssembly
const { path } = await slideria.files.add('talk-cut.mp4', cut);
await slideria.apply({ op: 'object.set', slide: 3, object: 1, set: { src: path } }, { label: 'обрезка' });
```

Оформление: панель получает шрифт и цвета студии (переменные `--tx`, `--mu`, `--bd`, `--ac`, `--surf`, `--isl`…;
в светлой и тёмной теме, тема сменилась — меняются и они), простые поля и кнопки (`button.primary` — главная)
уже в стиле студии. Свои стили — поверх.

## Устройство

| Файл | Что |
|---|---|
| `src/engine/plugin-manifest.ts` | разбор `plugin.json` и разрешения — общий у сервера и студии |
| `server/integrations.ts` | список плагинов, их файлы, включение с разрешениями, настройки, удаление |
| `src/studio/plugins.ts` | кнопки на ленте, Ctrl+K, правка от имени плагина (одна отмена, точки, журнал) |
| `src/studio/plugin-pane.ts` | панель: рамка, политика безопасности, объект `slideria` (сообщения), события |
| `src/studio/integrations-file.ts` | «Файл → Интеграции → Плагины», вопрос о включении, удаление |

Команды сервера (`POST /__htmlpptx/…`): `plugins`, `plugin-file?id=&file=`, `plugin-set?id=` (`{ enabled, granted }`),
`plugin-data?id=` (без тела — все настройки, `{ key, value }` — записать), `plugin-delete?id=`,
`plugin-assets?deck=` (файлы презентации и начало адреса её папки); новый файл — `asset?deck=&name=`, как у студии.

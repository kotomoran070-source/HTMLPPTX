# Защита кода установленной программы

Код, который работает на чужом компьютере, полностью спрятать нельзя: так у всех программ на Electron. Защита — от лёгкого чтения и от правки. Секретов (ключей, платной логики) в программе быть не должно.

`yarn app:build` собирает установщик так:

| Что | Как устроено | Зачем |
|---|---|---|
| Сжатый код | Перед сборкой каждый файл программы (`src`, `plugins`, `scripts`, `desktop`, `vite.config.ts`) сжимается: без комментариев, отступов и понятных имён переменных (`scripts/app-stage.mjs`). Импорты и экспорты те же, поэтому сервер Vite внутри программы и «Экспорт» работают со сжатым кодом так же, как с исходниками | Главная защита: исходников с комментариями в установщике нет |
| `app.asar` | Загрузчик программы (`desktop/`) и `package.json` упакованы в один файл `resources/app.asar`. Остальной сжатый код лежит рядом, в `resources/app.asar.unpacked`: Vite и esbuild читают обычные файлы с диска | Загрузчик не открыть правым щелчком или в 7-Zip |
| Проверка целостности | Отпечатки (SHA-256) каждого файла кода записаны внутрь `app.asar` (`desktop/integrity.json`). При запуске загрузчик сверяет файлы. Если хоть один изменён или удалён, программа пишет об этом в журнал, показывает «Slideria повреждена» и не запускается. Сам `app.asar` проверяет Electron по отпечатку, вшитому в `Slideria.exe` | Изменённая программа не запускается |
| Предохранители Electron | Задаются в `package.json` → `build.electronFuses`: программа грузится только из `app.asar` и с проверкой целостности; Electron не запускается в роли Node (`ELECTRON_RUN_AS_NODE`); `NODE_OPTIONS` и `--inspect` не действуют; у `file://` нет лишних прав | Через сам `Slideria.exe` не запустить свой код и не подключить отладчик |
| Без инструментов разработчика | В установленной программе в меню «Вид» нет «Инструментов разработчика» (из проекта они есть) | Код страниц не поправить на ходу |

«Экспорт» в HTML собирает файл отдельным служебным процессом Electron (`utilityProcess`). Раньше для этого Electron запускался в роли Node, а теперь этот режим выключен предохранителем.

## Сервер программы

Внутри программы работает сервер на `127.0.0.1`. Его страницы и команды защищены от других программ и сайтов:

- **Правка — только с этого компьютера и только со своих страниц.** Команды принимаются только методом POST. Запрос с другого сайта (заголовок `Origin`) получает отказ.
- **Только свой адрес.** Чужой сайт может направить своё имя на `127.0.0.1` (DNS rebinding), и тогда браузер ходит к серверу как будто со своей страницы. Поэтому сервер отвечает, только если в адресе запроса `localhost` или IP-адрес: компьютер или телефон-пульт в сети. Проверка (`plugins/host-guard.ts`) стоит раньше всех обработчиков: у самого Vite такая же есть, но срабатывает уже после обработчиков плагинов.
- **Телефон получает только показ.** Вход для телефона открывается только по одноразовой ссылке из QR и только к презентации, которая сейчас в показе (`desktop/lan.mjs`).

## Подпись

Отпечаток `app.asar` лежит в ресурсах `Slideria.exe`. Неподписанный `.exe` можно поправить вместе с отпечатком, а у подписанного после правки ломается подпись, и Windows это видит. Поэтому проверка целостности имеет смысл вместе с подписью: `docs/SIGNING.md`. Вшивает отпечаток electron-builder до подписи. Встроенная проверка Electron работает на Windows и macOS, а сверка отпечатков загрузчиком — везде.

## Чего защита не делает

- Сжатый код можно прочитать. Он трудночитаем, но логика в нём та же, а имена файлов остались.
- Библиотеки (`node_modules`) не сжимаются и не сверяются. Это чужой открытый код.
- Пока программа работает, её сервер на `127.0.0.1` отдаёт страницы и сжатый код любому браузеру на этом компьютере.
- Изменить файлы уже запущенной программы можно, но при следующем запуске она это заметит.

## Проверка

```bash
yarn test:stage                                          # сквозные тесты на сжатом коде, как в установщике
SLIDERIA_FUSES_TEST=1 node scripts/app-build.mjs --linux dir  # собранная программа (отладчик оставлен для теста)
SLIDERIA_APP_EXE=$PWD/dist-app/linux-unpacked/slideria xvfb-run -a npx playwright test --project=app
npx @electron/fuses read --app dist-app/linux-unpacked/slideria   # какие предохранители включены
```

Тест собранной программы проходит весь первый запуск: экспорт HTML, PDF и PowerPoint, показ, лицензии, вход с телефона. Ещё он проверяет, что с изменённым файлом программа не запускается, а в роли Node `Slideria.exe` не работает. `yarn app` из проекта работает как раньше: без сжатия, проверок и предохранителей.

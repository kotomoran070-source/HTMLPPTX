# План

Что делаем дальше и что сознательно отложено — чтобы не потерять. Скорость и её замеры — [PERF.md](PERF.md).

## Дальше

1. **MCP на компьютере** — сделан для работы из папки проекта ([MCP.md](MCP.md)). Осталось:
   - **снимок слайда картинкой** — агент видит результат своей правки (нужен браузер: в программе — Electron);
   - **MCP в установленной программе**: там нет Node, а запуск Electron «как Node» выключен защитой — программа
     сама отвечает по MCP при запуске с ключом (`Slideria --mcp`); справку по формату (`docs/skills`) — в установщик;
     в «Интеграции → Агенты» — строка подключения и для установленной программы.
2. **Плагины** — раздел в «Интеграции» уже есть (витрина). Пакет: свои блоки (рисуются и в экспортированном
   файле — нужна проверка доверия), кнопки на ленте и в Ctrl+K, форматы импорта и экспорта; установка из папки
   и каталога с разрешениями, как у расширений браузера; правят — операциями, как агенты и скрипты.
3. **Облако** (шаг В). Тот же сервер (`server/`) без Vite, студия — готовой сборкой; MCP — тот же обработчик
   (`server/mcp.ts`) по HTTP со входом пользователя. **Коннекторы** (данные из других сервисов: вход, обновление,
   снимок в экспорт) — вместе с облаком: в «Интеграциях» раздел уже отмечен «с облаком».

## Сделано: «Инструменты → Интеграции»

Группа на ленте и большая панель: Агенты (кто на связи, что можно, как подключить любой MCP-клиент), Скрипты
(песочница, одним шагом отмены, встроенные «Оглавление», «Один переход», «Заменить слова по списку»), Плагины
(витрина), Журнал правок (было → стало, «Вернуть» только правку агента), Коннекторы — с облаком.
Подробно — [INTEGRATIONS.md](INTEGRATIONS.md), [SCRIPTS.md](SCRIPTS.md).

## Отложено: интерфейс

- **Студия правит через операции (О4).** Частые действия — сдвиг, размер, текст, добавить и удалить объект или
  слайд — идут через `src/engine/ops.ts`, как у агента и скриптов: одна проверка и одни подписи у «Отменить: …».
  Остальные места правки — как есть. Сверить замером (`yarn perf --only edit`), что отклик не хуже. Тогда же —
  **запись действий в скрипт**.
- **Подпись правки агента у «Отменить» и «Повторить»** (сейчас — подсказка на холсте и журнал).

## Отложено: операции

- Адреса внутри групп (`items`) и блоков раскладки (`body`): сейчас `body` правится целиком.
- Операции для таблиц и графиков: ячейка, строка, ряд данных.

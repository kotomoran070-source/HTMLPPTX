# План

Что делаем дальше и что сознательно отложено — чтобы не потерять. Скорость и её замеры — [PERF.md](PERF.md).

## Дальше

1. **MCP на компьютере** — сделан для работы из папки проекта ([MCP.md](MCP.md)). Осталось:
   - **снимок слайда картинкой** — агент видит результат своей правки (нужен браузер: в программе — Electron);
   - **MCP в установленной программе**: там нет Node, а запуск Electron «как Node» выключен защитой — программа
     сама отвечает по MCP при запуске с ключом (`Slideria --mcp`); справку по формату (`docs/skills`) — в установщик.
2. **Плагины.** Свои команды и блоки пользователя через тот же слой операций.
3. **Облако** (шаг В). Тот же сервер (`server/`) без Vite, студия — готовой сборкой; MCP — тот же обработчик
   (`server/mcp.ts`) по HTTP со входом пользователя.

## Отложено: интерфейс

Решено не добавлять в интерфейс студии, пока идёт подготовка к MCP, — без отвлекающих мелочей.

- **Студия правит через операции (О4).** Частые действия — сдвиг, размер, текст, добавить и удалить объект или
  слайд — идут через `src/engine/ops.ts`, как у агента: одна проверка и одни подписи у «Отменить: …». Остальные
  места правки — как есть. Сверить замером (`yarn perf --only edit`), что отклик не хуже.
- **MCP в интерфейсе.** Место в студии, где видно, что Claude подключён, и как его подключить (без ручной правки
  настроек Claude). Макет — на обсуждение, до реализации.
- **Видно, что правил агент.** Короткая подсказка в студии, когда правка пришла от агента («Агент: правка
  объекта · слайд 3»), и такая же подпись у шага в «Отменить» и «Повторить».

## Отложено: операции

- Адреса внутри групп (`items`) и блоков раскладки (`body`): сейчас `body` правится целиком.
- Операции для таблиц и графиков: ячейка, строка, ряд данных.

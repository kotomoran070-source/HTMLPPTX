## Дальше

1. **Чат «Агент» в студии** — макет согласован. Панель справа на месте «Свойств» (✦ в шапке, «Агент» в строке
   состояния, Ctrl+J). Пишешь или диктуешь, прикладываешь картинки (скрепка, Ctrl+V, перетаскивание), текущий
   слайд уходит в контекст. Видны шаги агента и ответ по мере написания, есть «Стоп». Под ответом — карточка
   правки: «Показать» и «Вернуть»; Ctrl+Z отменяет весь ответ одним шагом. Разговоры хранятся отдельно для каждой
   презентации в `.slideria/`, в файл и в экспорт не попадают.
   - **Через что работает:** Claude API по ключу пользователя. Ключ хранится зашифрованным (в программе —
     `safeStorage` Electron, при разработке — `ANTHROPIC_API_KEY`), страница студии его не видит. Модель по
     умолчанию — Claude Opus 5.5, в шапке чата можно выбрать Sonnet 5.5 или Haiku 5.5. Правки идут теми же
     операциями, с тем же журналом и «Вернуть», что у агентов по MCP. Подписка Claude к сторонней программе не
     подключается: с подпиской работают из окна самого Claude через наш MCP (п. 2 и «Облако»).
   - **Голос:** лёгкая модель, распознаёт на компьютере. Скачивается при первом нажатии на микрофон, в установщик
     не входит. Кандидаты: Vosk small ru (45 МБ), потоковые русские модели для sherpa-onnx (zipformer, T-one),
     Whisper small (~120–250 МБ). Выбираем замером качества на русском и веса. Если хорошей лёгкой нет — кнопка
     подсказывает системную диктовку (Win+H в Windows, Fn дважды на Mac).
   - **Потом:** агент видит слайд картинкой и сам проверяет, как вышло (п. 2).
2. **MCP на компьютере** — сделан для работы из папки проекта ([MCP.md](MCP.md)). Осталось:
   - **снимок слайда картинкой** — агент видит результат своей правки (нужен браузер: в программе — Electron);
   - **MCP в установленной программе**: там нет Node, а запуск Electron «как Node» выключен защитой — программа
     сама отвечает по MCP при запуске с ключом (`Slideria --mcp`); справку по формату (`docs/skills`) — в установщик;
     в «Интеграции → Агенты» — строка подключения и для установленной программы. Для Claude Desktop — установка
     в один щелчок (пакет расширения) вместо правки файла настроек.
3. **Плагины** — раздел в «Интеграции» уже есть (витрина). Пакет: свои блоки (рисуются и в экспортированном
   файле — нужна проверка доверия), кнопки на ленте и в Ctrl+K, форматы импорта и экспорта; установка из папки
   и каталога с разрешениями, как у расширений браузера; правят — операциями, как агенты и скрипты.
4. **Облако.** Тот же сервер (`server/serve.ts`), студия — готовой сборкой (шаг В уже это даёт); MCP — тот же обработчик
   (`server/mcp.ts`) по HTTP со входом пользователя (OAuth). Этот адрес (`https://…/mcp`) добавляют в Claude как
   свой коннектор (claude.ai: «Add custom connector») и правят презентации из окна Claude по подписке. Адрес на
   компьютере (`localhost`) туда не подходит: Claude обращается к нему из своего облака. **Коннекторы** (данные
   из других сервисов: вход, обновление, снимок в экспорт) — вместе с облаком: в «Интеграциях» раздел уже
   отмечен «с облаком».

## Плавность интерфейса

Сделано: заставка в цвет темы, каркас страницы при переходах, страница выбора без «допрогрузки», «Блоки» и «Темы»
без замирания — цифры в [PERF.md](PERF.md). Движение — вариант «Мягко» (выбран по демо): меню, всплывающие панели и
окна появляются за 160 мс со сдвигом 6 px и лёгким увеличением, гаснут за 110 мс; плитки «Блоков» — волной; панель
ленты при смене вкладки и «Свойства» проявляются (без сдвига: сдвинутая кнопка прокручивала бы панель), полоска под
вкладкой переезжает (220 мс); тема
интерфейса меняется растворением (240 мс). Токены — `--ui-*` в `src/styles/tokens.css`, уход меню и окон —
`src/engine/motion.ts` (гаснет копия в закрытом теневом дереве: щелчок сразу после закрытия попадает в то, что под
ней). «Уменьшить движение» в системе — всё сразу.

Заставка программы — «Колода» (`desktop/splash.mjs`): за знаком веером раскрываются три слайда (титульный,
с диаграммой, с фотографией), столбики растут, по слайду пробегает блик. Полоска под названием идёт по шагам запуска
(код на месте, сервер, страница загружена), запуск дольше секунды — подпись, что происходит. Страница готова — слайды
разлетаются, заставка раскрывается кругом от знака. Запуск не задерживает: веер раскрывается за 0,45 с, программа
готова раньше — ждёт только конца веера.

## Сделано: страница выбора

Во всю ширину окна (на широком экране — больше колод в ряд), шрифты программы: Unbounded — заголовки, Onest —
остальное. Шапка: поиск (Ctrl+K), «Импорт», «Создать», тема. «Продолжить работу» — последняя презентация крупно, со
свечением её цвета и лентой первых слайдов (щелчок — редактор на этом слайде). Библиотека — колоды (при наведении
слайды позади раскрываются веером, снизу — свечение цвета презентации) по группам «Сегодня», «На этой неделе»,
«В этом месяце», «Ранее», или список; порядок и вид — свои переключатели, запоминаются. Порция — 24 колоды или
30 строк, остальное — «Показать ещё». Щелчок — редактор, на колоде — «Показ», в «⋯» — «Показать в папке»
(в программе) и «Удалить…». Подсказки и окно импорта — без путей к файлам и служебных папок.

## Свой заголовок окна

Главное окно программы — без системной полосы с названием (`desktop/main.mjs`, `src/engine/titlebar.ts`). Кнопки окна
в Windows и Linux рисует страница: высотой с заголовок, цветом темы и вместе с ней (без системных «чужих» кнопок),
«Закрыть» при наведении — красная, окно не в фокусе — кнопки тише, во весь экран — их нет. Меню раскладок Windows 11
при наведении на «Развернуть» есть только у системных кнопок — у своих его нет (Win+Z и перетаскивание к краю
экрана работают). На Mac — системный «светофор» слева. Окна показа, докладчика и печати — с обычной рамкой.

- **Страница выбора** — сделано: её шапка и есть заголовок, 48 px; пустые места перетаскивают окно. Знак с названием —
  у левого края окна, сразу за ним «Импорт», «Создать» и тема, поиск — по середине окна; кнопки и поле — 32 px.
  В браузере шапка прежняя (кнопки справа). «Показ» отсюда — своим окном, как из студии.
- **Студия** — пока тонкая пустая полоса 36 px над прежней шапкой. Дальше: что перенести в неё значками (немного —
  для удобства и единообразия), чтобы разгрузить шапку студии, а не нагрузить заголовок.
- Проверить на Windows и Mac; в Linux — что окно без рамки тянется за края.

## Отложено: интерфейс

- **Студия правит через операции (О4).** Частые действия — сдвиг, размер, текст, добавить и удалить объект или
  слайд — идут через `src/engine/ops.ts`, как у агента и скриптов: одна проверка и одни подписи у «Отменить: …».
  Остальные места правки — как есть. Сверить замером (`yarn perf --only edit`), что отклик не хуже. Тогда же —
  **запись действий в скрипт**.
- **Подпись правки агента у «Отменить» и «Повторить»** (сейчас — подсказка на холсте и журнал).

## Отложено: операции

- Адреса внутри групп (`items`) и блоков раскладки (`body`): сейчас `body` правится целиком.
- Операции для таблиц и графиков: ячейка, строка, ряд данных.

# Справочник компонентов

Презентация целиком из этих компонентов получается «родной»: тема, акцентный цвет, режим правки по полям, живые схемы. Её удобно поручить Claude — [промпт в конце страницы](#промпт-для-claude).

Слайд — элемент списка `slides` в `deck.yaml`. Поле `template` выбирает шаблон слайда, поле `body` содержит блоки. Каждый блок — объект с полем `type`.

Общие поля любого слайда:

| Поле | Что это |
|---|---|
| `id` | Короткое имя слайда (необязательно) |
| `template` | `content` (по умолчанию), `cover`, `finale`, `space`, `canvas` |
| `label` | Название в обзоре и в окне докладчика, если отличается от `title` |
| `notes` | Заметки докладчика. Многострочный текст пишите после `notes: \|` |
| `live` | Живой слайд: `{src: ./assets/….htm, index: 2, selector: section.slide}` — исходный HTML-файл со скриптами, показан слайд `index`. Остальные поля слайда — обычная копия для миниатюр и печати |

## Оформление текста

Внутри любого текста:

| Разметка | Результат |
|---|---|
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `__подчёркнутый__` | подчёркнутый |
| `[сайт](https://example.com)` | ссылка |
| `{#DC2626\|красное слово}`, `{accent\|слово}` | цвет части текста: `#RRGGBB` или цвет темы |
| строки, начинающиеся с `- ` | пункты списка |
| `\*` | звёздочка как обычный символ |

Размер, цвет, выравнивание и шрифт отдельного поля хранятся рядом с ним, в `styles`:

```yaml
- title: Итоги
  lead: Подзаголовок
  styles:
    title: { size: 52, color: accent, align: center }
    lead: { font: serif, color: "#DC2626" }
```

- `size` — размер в пикселях слайда (слайд 1280×720);
- `color` — `#RRGGBB` или цвет темы: `accent`, `accent2`, `text`, `text2`, `muted` (цвета темы подстраиваются под тёмную тему);
- `align` — `left`, `center`, `right`;
- `font` — `sans`, `serif`, `mono`, `rounded` (системные шрифты, работают без интернета) или имя своего шрифта из `fonts`.
- `width` — наибольшая ширина поля в пикселях слайда: строки переносятся раньше.
- `weight` (400–900), `upper: true` (заглавными), `spacing` (межбуквенный, em), `leading` (межстрочный) — обычно их ставит разгруппировка, чтобы текст выглядел как в исходном блоке.

Всё это проще задавать в режиме правки: панель оформления появляется над текстом.

### Свои шрифты

Файл шрифта (WOFF2, WOFF, TTF или OTF) лежит в `assets/` и встраивается в собранный файл — работает без интернета:

```yaml
fonts:
  - name: Manrope
    src: ./assets/Manrope-VariableFont_wght.ttf   # переменный шрифт — все толщины одним файлом
theme:
  font: Manrope        # шрифт всей презентации (необязательно)
```

В студии файл шрифта достаточно перетащить на страницу (или «Свойства» → «Презентация» → «Добавить шрифт…»): он ляжет в эту презентацию и в общую библиотеку — папку `fonts/` проекта — и появится в списке шрифтов над текстом и в выборе «Шрифт презентации» во всех презентациях. Шрифт из библиотеки, выбранный в другой презентации, копируется в её `assets/`: собранный файл и папка презентации всегда несут шрифт с собой. «×» в «Свойствах» убирает шрифт из презентации; из библиотеки — удалением файла из `fonts/`. Шрифт без русских букв студия покажет предупреждением. Google Fonts не подключайте ссылкой — скачайте файл с fonts.google.com («Download») и перетащите. В PPTX уходит имя шрифта: если его нет на компьютере, PowerPoint подставит похожий.

Общие поля всей презентации, в начале файла:

```yaml
title: Название презентации
brand:
  logo: ./assets/logo.svg   # на титуле, в углу слайдов, на финальных слайдах и в QR-коде
  logoDark: ./assets/logo-light.svg  # необязательно: свой логотип для тёмной темы (в QR — всегда logo)
theme:
  accent: "#2563EB"         # акцентный цвет; без него — стандартный синий
```

## Свободные объекты

Кроме раскладки (`body`), у любого слайда могут быть свободные объекты — блоки поверх слайда на своих координатах:

```yaml
- title: Итоги
  body: …
  free:
    - type: text
      text: Подпись в любом месте
      place: { x: 820, y: 560, w: 360 }        # без h — высота по тексту
    - type: image
      src: ./assets/photo.jpg
      place: { x: 64, y: 400, w: 480, h: 270 }
```

Координаты в пикселях слайда 1280×720 от левого верхнего угла. Порядок в списке — порядок слоёв: последний сверху.

Поворот: `angle` — градусы по часовой стрелке вокруг центра объекта (`angle: -12`), поле рядом с `place`. Координаты в `place` — рамки без поворота. В редакторе — кружок над рамкой (Shift — шагами по 15°) или поле «Поворот, °» в свойствах; в PowerPoint объект уходит повёрнутым.

Появление при открытии слайда: `enter` — эффект (`fade`, `rise`, `drop`, `left`, `right`, `scale`, `pop`), `delay` — задержка в миллисекундах:

```yaml
    - type: text
      text: Появлюсь вторым
      place: {x: 64, y: 400, w: 600}
      enter: rise
      delay: 380
``` Свободным может стать любой блок (карточка, график, схема): в режиме правки кнопка «Свободно» переносит его сюда с текущими координатами.

Любому блоку можно добавить `style: "margin-top: 12px"`: это CSS для корневого элемента, запасной выход, если нужной настройки нет.

Щелчок по свободному объекту при показе — `action`: объект становится кнопкой. В студии то же самое — раздел «По щелчку при показе». При экспорте в PPTX кнопка остаётся рабочей: переход или ссылка срабатывают и в PowerPoint.

```yaml
    - type: shape
      kind: pill
      fill: gradient
      text: Дальше →
      action: next            # next, prev, first, last, slide:<id слайда> или https://…, mailto:…
      place: {x: 64, y: 612, w: 200, h: 56}
```

Кнопка может показывать и скрывать другие объекты слайда — как триггеры в PowerPoint: ответ на вопрос, подсказка, вкладки. Объекту дают имя `id`, а `hidden: true` скрывает его до щелчка. Действия: `show:<id>`, `hide:<id>`, `toggle:<id>` (показать / скрыть), несколько объектов — через запятую, несколько команд — через «;». Так собираются вкладки: `show:spec,tab2;hide:wave,tab1` (см. слайд «Живой пульт» в витрине).

`play:<id>` — проиграть анимацию объекта по щелчку: его эффект выделения `emphasis` (`pulse` — пульс, `shake` — покачивание, `spin` — вращение, `bounce` — прыжок, `flash` — вспышка) или, если его нет, заново эффект появления `enter`. Скрытый объект при этом появляется. В студии: «По щелчку при показе» → «Проиграть анимацию объекта…», у самого объекта — «Анимация по кнопке «Проиграть»». При каждом заходе на слайд всё возвращается к началу; окна показа и докладчика синхронны. В студии: «По щелчку при показе» → «Показать объект…» и выбрать объект из списка — имя и скрытие он получит сам. В редакторе скрытый объект полупрозрачный; в миниатюрах, PPTX и PDF слайд такой, каким открывается при показе, — без скрытых объектов.

```yaml
    - type: shape
      text: Показать ответ
      action: show:answer
      place: {x: 64, y: 200, w: 260, h: 60}
    - id: answer
      hidden: true
      enter: pop              # появится этим эффектом
      type: shape
      fill: accent
      text: Восемь
      place: {x: 64, y: 300, w: 400, h: 160}
```

## Шаблоны слайдов

### `content` — обычный слайд

```yaml
- title: Результаты эксплуатации
  badge: демо-данные      # чип рядом с заголовком (необязательно)
  gap: 8                  # расстояние между блоками тела, px (по умолчанию 22)
  logo: false             # скрыть логотип в углу
  body:
    - type: chips
      items: [...]
    - type: grid
      items: [...]
```

### `cover` — титульный

```yaml
- template: cover
  title: Результаты применения комплекса
  lead: Подзаголовок
  meta: Сентябрь 2026, команда Palorax
  visual:                 # блок справа (необязательно)
    type: network
    nodes: 7
```

Логотип берётся из `brand.logo` в начале файла.

### `finale` — финальный: кольца, луч, слова по одному

```yaml
- template: finale
  caption: Комплекс контроля микроклимата   # мелкая надпись сверху
  title: Спасибо за внимание
  lead: Готовы ответить на вопросы
  link:
    label: Сайт проекта
    url: https://example.com/     # QR-код строится из этой ссылки автоматически
    text: example.com             # необязательно: по умолчанию url без https://
    qr: true                      # false — без QR-кода
  buttons:                        # кнопки с подписью, которая выезжает при наведении
    - icon: mail
      label: Почта
      url: mailto:hello@example.com   # без url кнопка просто показывает подпись
```

### `canvas` — пустой холст

Всё содержимое — свободные объекты (`free`). Так устроены слайды, импортированные из Claude Design.

```yaml
- template: canvas
  label: Идеология бренда   # название в обзоре
  bg: "#f8fafc"             # фон слайда
  free: [...]
```

### `space` — «космический» финальный, всегда тёмный

Те же поля, что у `finale`, плюс `badge` — надпись в «пилюле» над логотипом. Звёзды слегка сдвигаются за мышью.

Анимации `cover`, `finale` и `space` — код движка, общий для всех презентаций. В студии («Код») их не открыть и не поправить. Нужна своя анимация, которую можно править, — соберите финал холстом (ниже).

### Финальный слайд со своей анимацией

Фон-анимация — живая вставка во весь слайд, поверх — обычные объекты (так сделан «Спасибо» в `presentations/slideria`). Код анимации открывается в студии: «Код» → «Анимации · HTML/JS».

```yaml
- id: thanks
  template: canvas               # фон — тема (тёмная тема — тёмный); всегда тёмный — bg: '#0B1220' и цвета текста #RRGGBB
  free:
    - type: embed                # первым: лежит под остальными объектами
      theme: true                # цвета темы внутри: var(--ac, #2563EB)
      interactive: true          # отвечает на мышь и под текстами (кроме ссылок и кнопок)
      code: |
        <canvas id="c"></canvas>
        <script> /* звёзды, частицы, волны по щелчку… */ </script>
      place: {x: 0, y: 0, w: 1280, h: 720}
    - type: text
      text: Спасибо за внимание
      styles: {text: {size: 64, weight: 800, align: center}}
      enter: rise
      place: {x: 140, y: 230, w: 1000}
    - type: text
      text: Готовы ответить на вопросы
      styles: {text: {size: 26, color: text2, align: center}}
      enter: rise
      delay: 300
      place: {x: 140, y: 340, w: 1000}
    - type: link-plate           # ссылка с QR и кнопки, как у финала
      look: fin                  # fin — плашка «Финала» (светлая и тёмная тема); orbit — широкая тёмная карточка
      link: {label: Сайт проекта, url: https://example.com/}
      buttons:
        - {icon: mail, label: Почта, url: 'mailto:hello@example.com'}
      enter: rise
      delay: 600
      place: {x: 290, y: 460, w: 700}
```

Ссылку и кнопки по отдельности дают `link-card` (только ссылка с QR) и `link-buttons` (только кнопки), с теми же полями и `look: space | orbit | fin`. Анимация документа вставки идёт, только пока слайд показан; в миниатюрах, PDF и PPTX — заставка (`poster`, в студии снимается сама).

### Где правится анимация

| Чем сделана | Где править в студии |
|---|---|
| `enter` / `delay` у объекта | Вкладка «Анимация» |
| `@keyframes` и правила в `css` презентации | «Код» → CSS |
| Живая вставка `embed` (`code` или файл `assets/*.htm`) | «Код» → «Анимации · HTML/JS» или двойной щелчок по вставке |
| Встроенные шаблоны `cover`, `finale`, `space`, живые компоненты (`network`, `hub`…) | Не правятся: это код движка. Меняются только их поля |

### Анимированный фон слайда

```yaml
- template: cover
  backdrop: aurora     # particles — частицы, aurora — сияние, grid — сетка в перспективе
```

Работает у любого шаблона, цвета берутся из акцента и темы. Анимация идёт, только пока слайд на экране; в окне докладчика — облегчённая; при системной настройке «уменьшить движение» — один неподвижный кадр. В миниатюрах, при печати и в PDF — статичный вариант того же фона. В редакторе — «Анимация фона» в панели слайда.

## Раскладка

### `grid` — сетка

```yaml
type: grid
columns: 1.6fr 1fr    # CSS grid или число колонок: 3
rows: 1fr 1fr         # необязательно
gap: 20               # px, по умолчанию 22
height: 540           # px, по умолчанию по содержимому
align: center         # start | center | end | stretch
items:
  - type: tile
    rows: 2           # элемент занимает 2 строки
    cols: 1           # или несколько колонок
```

### `stack` — столбик

```yaml
type: stack
gap: 16
items: [...]
```

### `text`, `note`, `list`, `spacer`

```yaml
- type: text
  text: Обычный абзац. **Жирный** тоже можно.
  size: lead          # lead — крупнее, small — мелко и серым
- type: note
  text: Мелкая серая подпись
- type: list
  items: [Пункт один, Пункт два]
- type: spacer
  size: 24
```

### `image` — картинка

```yaml
type: image
src: ./assets/photo.jpg   # файл рядом с deck.yaml; без src — пустое место под картинку
srcDark: ./assets/photo-dark.jpg  # необязательно: своя картинка для тёмной темы (у tile — imageDark)
height: 360               # высота блока, px
caption: Подпись
```

Кадр (у `image` и у фото на `tile`), в режиме правки задаётся мышью:

```yaml
fit: contain              # contain — целиком, без обрезки; cover — заполнить блок (по умолчанию)
position: "50% 30%"       # какая часть видна при cover: по горизонтали и вертикали
zoom: 1.5                 # увеличение от 1 до 4
```

В студии: «Кадр» на панели над картинкой или на вкладке «Рисунок» — снимок тянется внутри рамки, как «Обрезка» в PowerPoint (Esc — готово). Точно — ползунки «Видимая часть» в свойствах. Сдвигать есть что, когда снимок обрезан рамкой («Заполнить») или увеличен.

Оформление — как «Формат рисунка» в PowerPoint (вкладка «Рисунок» в студии):

```yaml
radius: 24                # скругление, px; circle — круг или овал
shadow: md                # sm, md, lg
mat: 10                   # паспарту, px
stroke: accent            # контур: цвет темы или #RRGGBB, толщина — width
opacity: 0.8
filter: duo               # цвет снимка, как LUT
bright: 110               # поверх фильтра, %: яркость 50–150, contrast 50–150, saturate 0–200
```

`filter`: основные — `gray`, `sepia`, `muted`, `vivid`, `light`, `dark`; настроение — `warm`, `cool`, `film`, `punch`, `cinema`, `dusk`, `noir`; в цветах темы — `tone`, `duo` (дуотон акцента), `duo2` (два акцента), `haze`. Фильтры в цветах темы перекрашиваются вместе с акцентом. В студии «Цвет» открывает галерею превью на самом снимке: наведите — фильтр примеряется на слайде, щелчок — применить; ниже — ползунки «Яркость», «Контраст», «Насыщенность» (сразу видно на слайде, отпустили — записано). В PPTX снимок уходит с фильтром и настройкой, как на экране.

## Карточки и данные

### `card`

```yaml
type: card
title: Эксплуатация
text: Абзац под заголовком (необязательно)
body:                  # любые блоки внутри
  type: kv
  rows: ...
```

### `panel` — выделенная панель с ячейками

```yaml
type: panel
title: Серверный ПК, Proxmox
columns: 2
cells:
  - title: GitLab
    sub: репозитории и CI
  - Redis                 # ячейка без подписи — просто строка
  - title: HashiCorp Vault
    cols: 2               # на всю ширину
```

### `kv` — «ключ — значение»

```yaml
type: kv
keyWidth: 110            # ширина колонки ключей, px
rows:
  Доступ: TLS с self-signed сертификатами
  Секреты: хранятся в Vault, не в коде
```

### `chips` — ряд чипов

```yaml
type: chips
items: [24 устройства в работе, "Сообщений: 3,4 млн", Важное*]
```

Звёздочка в конце выделяет чип. Если в тексте есть двоеточие с пробелом, возьмите его в кавычки.

### `progress` — прогресс-бар, заполняется при открытии слайда

```yaml
type: progress
label: Версия 1.4.2
value: 24 из 24 устройств
percent: 100
```

### `sliders` — настройки с ползунками

```yaml
type: sliders
rows:
  - label: Интервал отправки
    value: 60 с
    position: 0.74        # положение ползунка от 0 до 1
```

### `control` — ползунок, который управляет слайдом

Ползунок задаёт переменную, остальные блоки слайда используют её в формулах. При показе двигаете ползунок — графики, числа и подписи пересчитываются сразу и плавно. В окне докладчика и в окне показа ползунки синхронны.

```yaml
- type: control
  name: v                 # имя переменной
  label: Зрителей в день
  min: 200
  max: 3000
  step: 100
  value: 1500             # начальное положение (оно же — в PPTX и PDF)
  unit: " чел."
- type: bars
  values: ["=v*0.3", "=v*0.4", "=v*0.5"]    # «=формула» в любом поле блока
- type: text
  text: "В месяц: **{{v*30}}**"             # {{формула}} внутри текста
```

В формулах: числа, переменные ползунков этого слайда, `+ - * / ^ %`, скобки и функции `round(x, знаков)`, `min`, `max`, `abs`, `sqrt`, `floor`, `ceil`, `log10`, `ln`, `exp`, `sin`, `cos`, `tan` и число `pi`. В поле значений графика в студии формулы разделяются «;». Формулы работают в любом поле, например `highlight: "=sf-7"` выделяет столбец под текущее значение.

Выбор из вариантов вместо диапазона — `steps`, подписи вариантов — `labels`:

```yaml
- {type: control, name: bw, label: Полоса, steps: [125, 250, 500], unit: " кГц"}
- {type: control, name: cr, label: Кодовая скорость, steps: [1, 2, 3, 4], labels: ["4/5", "4/6", "4/7", "4/8"]}
```

Длинные расчёты удобно один раз записать в поле слайда `vars` — по порядку, каждая величина видит ползунки и предыдущие, блоки ссылаются на имя:

```yaml
- template: canvas
  vars:
    ts: "=2^sf/bw"                 # длительность символа, мс
    rb: "=sf*bw*1000/2^sf*4/(4+cr)"
  free:
    - {type: stat, value: "{{round(rb)}}", label: бит/с}
```

В вёрстке (`html`) числа из `{{…}}` подставляются без пробелов и с точкой — их можно писать в атрибуты SVG. Пример живого слайда — `presentations/lora`.

## Живая графика

### `network` — схема сети с бегущими импульсами

```yaml
type: network
nodes: 7                  # число устройств вокруг станции
```

### `hub` — список итогов и схема вокруг логотипа

Наведение на пункт подсвечивает узел схемы, и наоборот.

```yaml
type: hub
items:
  - title: Собран рабочий комплекс      # пункт списка
    text: Пояснение под пунктом
    node: Оборудование                  # подпись узла (по умолчанию title)
    sub: устройства и станция           # мелкая подпись узла
```

Для 4 пунктов узлы стоят слева, сверху, справа и снизу, для другого числа — по кругу.

### `tile` — плитка с иллюстрацией или фото

```yaml
type: tile
illustration: assembly    # встроенные: assembly, endpoints, station (с мигающими индикаторами)
image: ./assets/photo.jpg # фото поверх иллюстрации; убрали фото — снова видна иллюстрация
fit: contain              # и position, zoom — как у image
caption: Комплекс в сборке
```

Оформление фото на плитке — те же поля, что у `image` (`filter`, `radius`, `shadow`, `mat`, `stroke`, `width`, `opacity`), в студии — вкладка «Рисунок».

Без `image` и `illustration` плитка показывает пустое место под картинку.

### `system` — схема «Из чего состоит система»

Оборудование → сервер и базы данных → интерфейсы, внизу серверный ПК. По проводам бегут импульсы, наведение на блок подсвечивает связанные с ним.

```yaml
type: system
hardware:
  title: Оборудование
  flow:                   # цепочка, соединённая импульсом
    - { icon: sensor, title: Оконечные устройства, text: Собирают данные }
    - { icon: station, title: Базовая станция, text: Приём данных }
  items:                  # компактные пункты под цепочкой
    - { icon: chip, title: Прошивки, chips: [C*, C++*] }
server:
  title: Сервер
  text: Управление сетью
  groups:
    - { label: Backend, chips: [Go*, REST API] }
database:
  title: Базы данных
  text: Хранение и история
  chips: [PostgreSQL*, Redis*]
interfaces:
  title: Интерфейсы
  items:
    - { icon: browser, title: Лендинг, text: Сайт проекта }
host:
  title: Серверный ПК
  chips: [Proxmox*, GitLab*]
```

### `pipeline` — шаги, которые подсвечиваются по очереди

```yaml
type: pipeline
stepSeconds: 1            # сколько секунд горит каждый шаг
steps:
  - title: Коммит
    sub: GitLab
```

### `line-chart` — график, который прорисовывается

```yaml
type: line-chart
values: [53501, 53906, 57302, ...]
start: начало эксплуатации   # подпись слева под осью
end: сегодня                 # подпись справа
scale: 1000                  # делитель подписей оси (по умолчанию 1000 для больших чисел)
unit: тыс
min: 42000                   # границы оси (необязательно)
max: 67000
```

### `uptime` — полоса доступности по дням

```yaml
type: uptime
threshold: 99.5           # дни ниже порога бледнее
values: [99.66, 99.7, 98.83, ...]
```

### `bars` — столбцы, вырастающие по очереди

```yaml
type: bars
values: [1.9, 1.7, 1.6, 1.4]
labels: [Янв, Фев, Мар, Апр]   # необязательно
max: 2                         # значение для полной высоты
height: 100
highlight: 4                   # выделенный столбец с нуля (по умолчанию последний), false — все одинаковые
```

### `table` — таблица

```yaml
type: table
variant: stripes        # lines (по умолчанию), stripes — зебра, boxed — сетка, accent — акцентная шапка,
                        # soft — мягкая карточка, dark — тёмная шапка
header: [Этап, Срок, Статус]
rows:
  - [Прототип, март, "{#16A34A|● готово}"]
  - [Пилот, май, "{#CA8A04|● идёт}"]
widths: [2, 1, 1]       # доли ширины столбцов (необязательно)
align: [left, center, right]   # без него столбцы из чисел — вправо
labels: true            # первый столбец жирным
highlight: 1            # выделенная строка, с нуля
size: 17                # размер текста, px
total: true             # последняя строка — итог: жирным, с чертой сверху
density: compact        # плотность строк: compact или roomy (по умолчанию — обычная)
head: false             # скрыть шапку (данные шапки сохраняются)
```

В ячейках работает обычная разметка текста. В студии ячейки правятся прямо на слайде или сеткой полей справа; таблицу из Excel или Google Таблиц можно вставить в любую ячейку. Ширину столбцов у выделенной таблицы тянут мышью за границу между ними — она записывается в `widths`.

### `shape` — фигура

```yaml
type: shape
kind: round        # round (по умолчанию), rect, pill, ellipse, line, arrow
fill: soft         # surface, bg, alt, soft, accent, text, line, border, muted, gradient, none или #RRGGBB
stroke: accent     # рамка; у линии и стрелки — их цвет
width: 2           # толщина рамки или линии, px
dash: dash         # штрих рамки или линии: dash — пунктир, dot — точки
radius: 16         # скругление, px
shadow: sm         # true / md — заметная тень, sm — лёгкая
rotate: -30        # поворот, градусы
opacity: 0.6       # непрозрачность, от 0.1 до 1
text: Главное      # текст внутри (необязательно)
valign: top        # текст по вертикали: top, middle (по умолчанию), bottom
styles: {text: {size: 24, align: left}}   # оформление текста, как у любого поля
place: {x: 100, y: 100, w: 320, h: 180}
```

Цвета по ролям темы сами меняются в тёмной теме и при смене акцента; `gradient` — градиент от акцентного цвета. Текст на заливке подбирается сам: светлый на тёмной, тёмный на светлой.

### `video` — видео

```yaml
type: video
src: ./assets/clip.mp4       # MP4, WebM или ссылка на YouTube / Vimeo
poster: ./assets/cover.jpg   # обложка до запуска и при печати
autoplay: true               # запуск при открытии слайда (по умолчанию да)
muted: true                  # без звука (по умолчанию — если запускается сам)
loop: false                  # по кругу
controls: true               # кнопки плеера при наведении
fit: cover                   # заполнить рамку; по умолчанию видно целиком
caption: Подпись
```

При уходе со слайда видео останавливается, при возвращении начинается сначала. В окне докладчика звук всегда выключен. YouTube и Vimeo нужен интернет. Файл видео попадает внутрь собранного HTML — такой файл получается большим. В редакторе видео добавляется перетаскиванием файла на слайд или из «Блоки → Медиа».

### `model` — 3D-модель

```yaml
type: model
src: ./assets/device.glb     # glTF в одном файле (GLB)
poster: ./assets/device.png  # снимок: печать, PDF, миниатюры, окно докладчика
rotate: true                 # медленно вращается сама (по умолчанию да)
controls: true               # вращать мышью при показе (по умолчанию да)
exposure: 1                  # яркость
animation: Dance             # анимация из файла модели, играет по кругу (true — первая по списку)
caption: Подпись
```

Модель загружается, когда слайд на экране, и выгружается, когда с него ушли. Снимок делается в редакторе кнопкой «Снимок текущего вида». Библиотека 3D (около 1 МБ) попадает в собранный файл, только если в презентации есть модель.

**STL и STEP.** Перетащите `.stl` или `.step` / `.stp` на слайд в студии (или выберите в поле «Модель») — при вставке файл превратится в GLB и встанет обычной 3D-моделью: крутится мышью при показе, попадает в собранный файл, PPTX и PDF (через снимок). STEP читается ядром OpenCascade, цвета деталей и граней сохраняются — так на слайд встаёт плата из Altium (File → Export → STEP) или деталь из SolidWorks, Fusion, КОМПАС, FreeCAD. В STL цвета нет — модель будет спокойного серо-синего цвета. CAD рисуют в миллиметрах и «Z вверх»: модель поворачивается как надо. Конвертация работает в `yarn dev`; в готовую презентацию попадает уже GLB.

### `group` — группа

```yaml
type: group
place: {x: 120, y: 200, w: 520, h: 180}
base: {w: 520, h: 180}       # размер в момент группировки: от него считаются места объектов
items:
  - {type: shape, kind: ellipse, fill: accent, place: {x: 0, y: 0, w: 180, h: 180}}
  - {type: text, text: Подпись, place: {x: 200, y: 70, w: 320}}
```

Объекты группы стоят от её левого верхнего угла. Растянули группу — объекты растягиваются вместе с ней, текст остаётся своего размера. В студии группу создаёт «Сгруппировать» (Ctrl+G), разбирает — «Разгруппировать» (Ctrl+Shift+G).

### `stat` — ключевое число

```yaml
type: stat
value: 3,4 млн
label: сообщений получено
delta: +12 %           # с минусом — красное со стрелкой вниз
note: за сентябрь      # необязательно
```

### `quote` — цитата

```yaml
type: quote
text: Хорошая презентация отвечает на вопрос раньше, чем его зададут.
author: Имя Фамилия
role: должность
```

### `timeline` — хронология, линия прорисовывается до последнего пройденного этапа

```yaml
type: timeline
items:
  - { date: Март, title: Прототип, text: первые датчики, done: true }
  - { date: Декабрь, title: Масштабирование }
```

## Готовая вёрстка

Эти блоки создаёт импорт из Claude Design. Их можно и писать руками.

### `html` — фрагмент вёрстки с редактируемыми текстами и картинками

```yaml
type: html
scale: 0.6667             # пиксели вёрстки → пиксели слайда (макет 1920×1080 → 1280×720)
html: '<div style="font-size: 69px; font-weight: 800"><span data-t="0"></span></div><img data-i="0" style="width: 92px">'
texts:                    # содержимое элементов data-t, с обычной разметкой текста
  - Результаты применения
images:                   # картинки элементов data-i; кадр (fit, position, zoom) — рядом
  - src: ./assets/logo.svg
styles:                   # оформление из режима правки, по номеру текста
  "0": {size: 72, color: accent}
place: {x: 64, y: 254, w: 615}
```

Скрипты и обработчики событий из разметки удаляются.

### Стили презентации: `css`

Импорт своего HTML переносит его `<style>` в поле `css` в начале `deck.yaml`. Стили действуют только внутри слайдов-холстов и только на импортированную вёрстку: `.card` из презентации не заденет ни интерфейс, ни встроенные блоки (карточки, графики), вставленные на тот же слайд. `:root`, `html` и `body` означают сам слайд, `.slide` — корень вёрстки слайда. Цвета пишите через переменные темы: `var(--ac)`, `var(--tx)`… (список — в [docs/HTML.md](HTML.md#цвета)).

```yaml
css: |
  .card { background: var(--surf); border: 1px solid var(--bd); border-radius: 16px; }
  @keyframes pulse { 50% { transform: scale(1.05); } }
```

### `embed` — «живая» вставка (анимация, интерактив)

Отдельный HTML-документ в изолированном iframe. Запускается, когда слайд открыт. В миниатюрах, при печати и до загрузки видна заставка.

```yaml
type: embed
src: ./assets/embed-bdb2b72ca6.htm   # документ вставки
poster: ./assets/image-9cf793af35.png
theme: true                           # вставка получает цвета темы: var(--ac) и др.
place: {x: 0, y: 0, w: 1280, h: 720}
```

С `theme: true` вставка перезапускается при смене темы и акцентного цвета. В тёмной теме заставка не показывается: она снята в светлой. Если у вставки своя тёмная сцена, `dark: true` — её заставка в тёмной теме остаётся как есть.

С `interactive: true` вставка при показе отвечает на мышь. Если поверх неё лежат другие объекты (фон-анимация под заголовком), движения курсора и щелчки над ними тоже доходят до вставки. Исключения — ссылки, кнопки, поля ввода и объекты с действием по щелчку: они работают как обычно. В режиме правки мышь выделяет объекты, во вставку не уходит.

Щелчок по интерактивной вставке отдаёт ей и клавиатуру: стрелки и пробел уходят во вставку, а не листают слайды. Щелчок мимо возвращает клавиши презентации.

Тяжёлые файлы (движок WebAssembly, данные игры, большие картинки) вставка получает полем `files` — так они работают и в собранном HTML без интернета:

```yaml
type: embed
src: ./assets/embed-doom.htm
interactive: true
files:                                # имя во вставке → файл презентации (.wasm, .wad, картинки…)
  doom.wasm: ./assets/doom.wasm
  doom1.wad: ./assets/doom1.wad
```

Внутри вставки: `const files = await slideriaFiles` → `{ 'doom.wasm': ArrayBuffer, … }`. Пример — слайд с DOOM в презентации `memes`.

Код можно держать прямо в данных — поле `code` вместо `src`:

```yaml
type: embed
theme: true
interactive: true                     # при показе вставка отвечает на мышь
code: |
  <canvas id="c"></canvas>
  <script> /* анимация */ </script>
```

В студии: HTML-файл с анимацией **перетащите на слайд** — он станет живой вставкой, файл ляжет в `assets/`, заставка для миниатюр, PPTX и PDF снимется сама. **Двойной щелчок** по вставке (или «Код вставки…» в свойствах) открывает редактор: код слева, он же в работе справа, Ctrl+Enter — применить. Готовый пример — «Живой код» в галерее блоков («Интерактив»). Код работает в изолированной рамке: без доступа к презентации, студии и файлам проекта.

### `sandbox` — песочница: код и результат рядом

Редактор кода с подсветкой и номерами строк, справа — результат и консоль. **При показе код правится прямо на слайде**: результат обновляется через долю секунды после паузы в наборе, `console.log` и ошибки (с номером строки) видны в консоли. Правку видят оба окна — показа и докладчика.

```yaml
type: sandbox
title: rose.html          # имя в заголовке редактора
theme: true               # цвета темы в результате: var(--ac), var(--ac2)…
size: 15                  # кегль кода, px
split: 56                 # ширина редактора, %
console: true             # консоль под результатом
code: |
  <canvas id="c"></canvas>
  <script> /* … */ </script>
place: {x: 48, y: 140, w: 1184, h: 500}
```

При показе: щелчок в код — печатать (стрелки и пробел слайды не листают), **Esc** — снова листать, **Ctrl+Enter** или «Запустить» — сразу, **↺** — исходный код, **A− / A+** — кегль для зала. Правки показа в презентацию не сохраняются. В студии песочница — обычный объект; её код — двойным щелчком или «Код песочницы…», заставка результата снимается сама (для миниатюр, PPTX и PDF; в PPTX песочница — картинкой). Готовая — «Песочница» в галерее блоков («Интерактив»).

## Промпт для Claude

Чтобы Claude сделал презентацию сразу в `deck.yaml`, приложите этот файл (docs/COMPONENTS.md) и `presentations/microclimate/deck.yaml` как образец, а затем напишите:

````text
Сделай презентацию для Slideria в формате deck.yaml.
Используй только компоненты и поля из docs/COMPONENTS.md, образец — presentations/microclimate/deck.yaml.
Шаблоны слайдов: cover — титул, content — обычный слайд.
Финал — template: canvas: фон-анимация embed первым объектом (theme: true, interactive: true, code с canvas/JS, place во весь слайд), заголовок и подпись — text со styles (size, weight, align), ссылка с QR и кнопки — link-plate. Шаблоны finale и space — только если о них попросят прямо: их анимация — код движка, в студии не правится.
Своя анимация: появление — enter и delay, CSS-анимации — в css презентации, сложная (canvas, JS, частицы, реакция на мышь) — embed с code. Цвета внутри вставки — var(--ac, #2563EB) и другие переменные темы.
Для чисел и схем бери живые компоненты (line-chart, bars, uptime, pipeline, network, hub, system), для текста — card, kv, chips, list, grid.
Не пиши цвета и CSS: оформление даёт тема. Акцентный цвет — theme.accent в начале файла.
Каждому слайду — короткий id латиницей и notes для докладчика.
Верни только содержимое deck.yaml.
````

Файл положите в `presentations/<имя>/deck.yaml` (или создайте заготовку `yarn new имя` и замените её содержимое). `yarn dev` покажет ошибку с номером строки, если в данных что-то не так.

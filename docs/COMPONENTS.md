# Справочник компонентов

Презентация целиком из этих компонентов получается «родной»: тема, акцентный цвет, режим правки по полям, живые схемы. Её удобно поручить Claude — [промпт в конце страницы](#промпт-для-claude).

Слайд — элемент списка `slides` в `deck.yaml`. Поле `template` выбирает шаблон слайда, поле `body` содержит блоки. Каждый блок — объект с полем `type`.

Общие поля любого слайда:

| Поле | Что это |
|---|---|
| `id` | Короткое имя слайда (необязательно) |
| `template` | `content` (по умолчанию), `cover`, `finale`, `space`, `canvas` |
| `label` | Название в обзоре и в окне докладчика, если отличается от `title` |
| `notes` | Заметки докладчика. Многострочный текст пишите после `notes: \|` |
| `live` | Живой слайд: `{src: ./assets/….htm, index: 2, selector: section.slide}` — исходный HTML-файл со скриптами, показан слайд `index`. Остальные поля слайда — обычная копия для миниатюр и печати |

## Оформление текста

Внутри любого текста:

| Разметка | Результат |
|---|---|
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `__подчёркнутый__` | подчёркнутый |
| `[сайт](https://example.com)` | ссылка |
| `{#DC2626\|красное слово}`, `{accent\|слово}` | цвет части текста: `#RRGGBB` или цвет темы |
| `{s:80\|мельче}`, `{#DC2626 s:80\|…}` | размер части текста в % от размера поля (с цветом — через пробел) |
| `{mark\|главное}` | маркер: полоса цвета акцента под словами. При показе проводится после появления объекта (у объекта с выделением «Маркер» — на его шаге). В студии — кнопка «Маркер» в правке текста |
| `{g:ocean\|слова}`, `{g:#F97316,#EC4899@40,#7C3AED\|слова}` | градиент части текста: готовый по имени (duo, accent, night, sunset, ocean, forest, violet, fire) или свой — до шести цветов через запятую (`#RRGGBB` или цвет темы: `accent`, `accent2`, `text`…), у точек между — место в % после `@`, первым может идти направление: `{g:180deg,#FFD700,#B8860B\|…}` (без него — слева направо). В студии — палитра текста → «Свой градиент…» |
| строки, начинающиеся с `- ` | пункты списка |
| пустая строка | промежуток между абзацами: высотой в строку, у поля с `gap` (px в `styles`) — такой |
| `\*` | звёздочка как обычный символ |

Размер, цвет, выравнивание и шрифт отдельного поля хранятся рядом с ним, в `styles`:

```yaml
- title: Итоги
  lead: Подзаголовок
  styles:
    title: { size: 52, color: accent, align: center }
    lead: { font: serif, color: "#DC2626" }
```

- `size` — размер в пикселях слайда (слайд 1280×720);
- `color` — `#RRGGBB` или цвет темы: `accent`, `accent2`, `text`, `text2`, `muted` (цвета темы подстраиваются под тёмную тему);
- `align` — `left`, `center`, `right`;
- `font` — `sans`, `serif`, `mono`, `rounded` (системные шрифты, работают без интернета) или имя своего шрифта из `fonts`.
- `width` — наибольшая ширина поля в пикселях слайда: строки переносятся раньше.
- `weight` (400–900), `upper: true` (заглавными), `spacing` (межбуквенный, em), `leading` (межстрочный) — обычно их ставит разгруппировка, чтобы текст выглядел как в исходном блоке.

Всё это проще задавать в режиме правки: панель оформления появляется над текстом.

### Свои шрифты

Файл шрифта (WOFF2, WOFF, TTF или OTF) лежит в `assets/` и встраивается в собранный файл — работает без интернета:

```yaml
fonts:
  - name: Manrope
    src: ./assets/Manrope-VariableFont_wght.ttf   # переменный шрифт — все толщины одним файлом
theme:
  font: Manrope        # шрифт всей презентации (необязательно)
```

В студии файл шрифта достаточно перетащить на страницу (или «Добавить шрифт из файла…» внизу любого списка шрифтов, или «Свойства» → «Презентация» → «Добавить шрифт…»): он ляжет в эту презентацию и в общую библиотеку — папку `fonts/` проекта — и появится в списке шрифтов над текстом и в шрифтах на вкладке «Дизайн» и в «Шрифте презентации» во всех презентациях. Шрифт из библиотеки, выбранный в другой презентации, копируется в её `assets/`: собранный файл и папка презентации всегда несут шрифт с собой. «×» в «Свойствах» → «Презентация» убирает шрифт из презентации (шрифт, который нигде не задан, — ещё и «убрать» в «Инструменты» → «Сводка»); из библиотеки — удалением файла из `fonts/`. Шрифт без русских букв студия покажет предупреждением. Google Fonts не подключайте ссылкой — скачайте файл с fonts.google.com («Download») и перетащите. В PPTX уходит имя шрифта: если его нет на компьютере, PowerPoint подставит похожий.

Общие поля всей презентации, в начале файла:

```yaml
title: Название презентации
brand:
  logo: ./assets/logo.svg   # на титуле, в углу слайдов, на финальных слайдах и в QR-коде
  logoDark: ./assets/logo-light.svg  # необязательно: свой логотип для тёмной темы — плашка под ним тогда тоже тёмная (в QR — всегда logo)
  tint: true                # необязательно: знак одним цветом — градиентом акцентов темы, плашка — цвета карточки.
                            # Для одноцветного знака (как S шаблона): меняется с темой и в тёмном виде. Цветной логотип станет одноцветным
  mark: 0.55                # необязательно: размер знака в плашке, доля её стороны (0.3–0.95, по умолчанию 0.7);
                            # плашка своего размера не меняет. В студии — «Дизайн» → «Логотип» → «Знак»
theme:
  accent: "#2563EB"         # акцентный цвет; без него — стандартный синий
```

### Тема презентации

Тема — оформление всех слайдов сразу (в студии — вкладка «Дизайн»). Всё необязательно; без полей ниже слайды выглядят как раньше:

```yaml
theme:
  accent: "#22D3EE"
  accent2: "#A78BFA"
  accentMid: [{ c: "#EC4899", at: 50 }]   # точки градиента между accent и accent2: цвет и место, %, до четырёх
  font: Manrope             # шрифт текста (из fonts)
  head: Unbounded           # шрифт заголовков и крупных чисел (из fonts)
  headWeight: 600           # насыщенность заголовков
  headScale: 0.78           # широкий шрифт заголовков — чуть меньше, чтобы строки ложились как задумано
  mode: dark                # слайды всегда тёмные (light — всегда светлые; без поля — как тема у зрителя)
  light: { bg: "#F4F6FD", tx: "#0B1020" }   # цвета слайдов: фон и текст, остальное выводится из них
  dark: { bg: "#070B18", tx: "#E8ECFA", surf: "#0F1529" }   # можно задать и surf, alt, tx2, mu, bd, bd2
  bg: glow                  # фон: dots, plain, grid, glow, mesh, paper, notebook, band, arc, spot, neon, halftone
                            # или свой: цвет "#1E293B" или картинка ./assets/фон.jpg (на весь слайд)
  bgOpacity: 0.6            # заметность своей картинки, 0.1–1 (сквозь неё — цвет фона темы, текст читается)
  cards: glass              # карточки: soft, flat, outline, raised, glass, poster
  radius: 1.3               # скругление углов: 0 — прямые, 1 — обычные, 2 — круглые
  darkLook:                 # своё у тёмных слайдов, поверх общего (чего нет — как у всех; при mode — не действует)
    bg: grid                # узор фона, свой цвет или своя картинка (и bgOpacity)
    cards: outline          # вид карточек
    backdrop: stars         # анимированный фон; none — у тёмных без анимации
    backdropOpacity: 0.6    # его заметность и скорость
    backdropSpeed: 0.5
```

Свой фон в студии — последние плитки «Фон»: «Картинка…» (файл с компьютера, под плитками — «Заметность») и «Цвет…». Своя тема («Сохранить текущую») хранит картинку содержимым и в другой презентации кладёт её в assets/.

`darkLook` в студии — переключатель «Для всех | Для тёмных» вверху панелей «Фон», «Карточки» и «Анимация» вкладки «Дизайн» (его нет, когда слайды всегда светлые или всегда тёмные). «Для тёмных» включает тёмную тему студии, образцы — тёмные, выбор пишется в `darkLook`; точка у «Для тёмных» — у них своё, «Как у всех» убирает своё. Анимированных фонов у слайда тогда два слоя, у зрителя виден слой его вида.

Своя палитра, фон и `mode` действуют только на слайды: интерфейс программы остаётся в своих цветах. Свой фон слайда-холста (`bg` у слайда) и свои цвета слайда (`theme` у слайда) сильнее темы.

У презентации, импортированной из PowerPoint «Под темы Slideria», есть палитра исходного файла — по ней цвета слайдов следуют за темой (импорт «Как в файле» её не пишет):

```yaml
origin:
  bg: "#F0EBE4"             # фон и текст файла
  tx: "#1C343C"
  accents: ["#E0B4A4", "#4C6A78"]   # семейства цветных оттенков по частоте → accent, accent2, …
  colors: ["#E0B4A4", "#A7B3B2", ...]  # цвета слайдов, которые перекрашиваются
  theme: { ... }            # тема «Как в файле» (первая плитка во вкладке «Дизайн»)
```

Пока тема — «Как в файле» (её цвета совпадают с `origin.theme`), видны цвета файла. Другая тема пишет каждый цвет из `colors` своим: серые — по оси «фон — текст» темы, цветные — её акцентом, светлота от фона к тексту сохраняется (в тёмном виде всё переворачивается вместе с фоном). Картинки не перекрашиваются. Свободная картинка с `fileBg: true` (фон из файла) видна только в теме «Как в файле»; в другой теме вместо неё — фон слайда `bg` (её средний тон), перекрашенный как остальные цвета. Слайд с `recolor: false` остаётся в своих цветах.

## Свободные объекты

Кроме раскладки (`body`), у любого слайда могут быть свободные объекты — блоки поверх слайда на своих координатах:

```yaml
- title: Итоги
  body: …
  free:
    - type: text
      text: Подпись в любом месте
      place: { x: 820, y: 560, w: 360 }        # без h — высота по тексту
    - type: image
      src: ./assets/photo.jpg
      place: { x: 64, y: 400, w: 480, h: 270 }
```

Координаты в пикселях слайда 1280×720 от левого верхнего угла. Порядок в списке — порядок слоёв: последний сверху.

Текст с заданной высотой можно прижать к середине или низу рамки: `valign: middle` или `valign: bottom` (лишний текст уходит за обе стороны или вверх, как в PowerPoint).

Поворот: `angle` — градусы по часовой стрелке вокруг центра объекта (`angle: -12`), поле рядом с `place`. Координаты в `place` — рамки без поворота. В редакторе — кружок над рамкой (Shift — шагами по 15°) или поле «Поворот, °» в свойствах; в PowerPoint объект уходит повёрнутым.

Появление при открытии слайда: `enter` — эффект, `delay` — задержка в миллисекундах. Эффекты: `appear` — возникновение (сразу, в свой момент), `fade` — проявление, `rise` — всплытие снизу, `drop` — сверху, `left`, `right` — выезд сбоку, `scale` — увеличение, `pop` — пружина, `swivel` — вращение вокруг вертикальной оси, `growturn` — увеличение с поворотом, `blur` — из фокуса (проступает из размытия), `ripple` — из ряби (проступает из волн, рябь утихает; SVG-фильтр только на время появления, в правке и миниатюрах — просто проявление); раскрытия: `wipe` — шторка слева направо, `split` — панорама от середины к краям, `circle` — круг из центра, `diamond` — ромб, `wheel` — часовая стрелка (сектор по кругу), `mask` — проявление маской с мягким краем; у текста (надпись, фигура с текстом): `words` — по словам, `letters` — по буквам; у линий, стрелок и фигур: `draw` — прорисовка (линия растёт, контур проводится, заливка — следом). В студии — лента «Анимация объекта» на вкладке «Анимация» (листается стрелками):

```yaml
    - type: text
      text: Появлюсь вторым
      place: {x: 64, y: 400, w: 600}
      enter: rise
      delay: 380
``` Свободным может стать любой блок (карточка, график, схема): в режиме правки кнопка «Свободно» переносит его сюда с текущими координатами.

Появление по щелчку, как «по щелчку» в PowerPoint: `click: true` — при показе объект ждёт «Далее» (пробел, стрелка, пульт, окно докладчика) и появляется своим эффектом `enter` (без него — «всплыть снизу»). Таких объектов на слайде может быть сколько угодно: они идут по очереди `delay` (в студии — «Анимация» → «Ждёт щелчка» и «Порядок»), когда кончаются — «Далее» листает дальше; «Назад» прячет последний. Формула по шагам внутри такого объекта раскрывается сразу после его появления. В студии, на миниатюрах, в PDF и PPTX объект виден сразу.

```yaml
    - {type: card, title: Быстро, click: true, enter: rise, place: {x: 64, y: 200, w: 340}}
    - {type: card, title: Живо, click: true, enter: rise, delay: 300, place: {x: 440, y: 200, w: 340}}
```

Исчезновение и выделение по щелчку — тоже шаги очереди, у одного объекта их может быть несколько: появился на первом щелчке, засветился на третьем, ушёл на пятом. `exit` — исчезновение (`vanish` — сразу, `fade` — растворение, `sink` — уход вниз, `up` — вверх, `left`, `right` — уход в сторону, `shrink` — сжатие, `swivel` — вращение, `wipe` — шторка, `split` — панорама, `wheel` — часовая стрелка), `exitAt` — место в очереди; `emphasis` — выделение (`pulse`, `shake`, `spin`, `bounce`, `flash`, `glow` — свечение цветом акцента, `mark` — провести маркер в тексте; стойкие — держатся после своего шага, пока не вернулись назад: `dim` — приглушить, `grow` — увеличить, `recolor` — перекрасить текст в цвет акцента), `emphAt` — место в очереди (без него выделение играет только кнопка `play:<id>`). Места — числа одной шкалы с `delay` появлений по щелчку: меньше — раньше. Каждый шаг — свой щелчок; `clickWith: true` (у появления), `emphWith: true`, `exitWith: true` — шаг идёт на том же щелчке, что предыдущий в очереди («вместе с предыдущим»: два объекта появляются разом, один уходит, другой приходит). В студии — звено у строки в «Порядке». В студии — «Анимация» → «Выделение» и «Исчезновение» (наведение на пункт проигрывает его на объекте), порядок — «Порядок»; на слайде у объекта номера его шагов: ✦ — выделение, ✕ — исчезновение. «Назад» возвращает шаг без анимации.

```yaml
    - {type: shape, text: Старый план, click: true, exit: shrink, exitAt: 600, place: {x: 64, y: 200, w: 340, h: 120}}
    - {type: shape, text: Новый план, click: true, delay: 300, emphasis: glow, emphAt: 900, place: {x: 440, y: 200, w: 340, h: 120}}
```

По пунктам — `byItem: true` у списка (`list`) или текста с пунктами «- »: с `click: true` первый пункт появляется вместе с объектом, остальные — каждый своим щелчком (номера на слайде «2–4»); без щелчка — пункты один за другим. Длительность всех эффектов объекта — `tempo`: `fast` (быстрее), `slow` (медленнее), `slower` (очень медленно). В студии — «По пунктам» и «Длительность» на вкладке «Анимация».

```yaml
    - {type: list, items: [Проблема, Решение, Результат], click: true, byItem: true, enter: left, tempo: slow, place: {x: 64, y: 200, w: 600}}
    - {type: shape, text: Было, emphasis: dim, emphAt: 900, place: {x: 64, y: 400, w: 300, h: 100}}
    - {type: shape, text: Стало, click: true, delay: 900, emphWith: true, enter: pop, place: {x: 440, y: 400, w: 300, h: 100}}
```

Эффект текста у надписи или фигуры с текстом — `textFx`: `glitch` (глитч: сдвиг и цветные срезы), `neon` (свечение цветом темы, изредка мигает), `shine` (блик бежит по буквам), `wave` (буквы качаются), `type` (печатная машинка с курсором), `scramble` (расшифровка: символы встают на место), `liquid` (жидкость: строки букв плавно колышутся, как отражение в воде — SVG-фильтр feTurbulence + feDisplacementMap). Неон виден и в правке; остальные играют при показе и в «Просмотре», текст в данных не меняется. В студии — «Анимация» → «Эффект текста»: наведение на пункт примеряет эффект на слайде. В PDF и PowerPoint — обычный текст.

```yaml
    - {type: text, text: ДОСТУП ОТКРЫТ, textFx: scramble, styles: {text: {size: 34, weight: 800}}, place: {x: 64, y: 200, w: 500}}
```

Число набегает — `count: true`: числа в тексте объекта при появлении отсчитываются от нуля до значения в той же записи («17 234», «$12.84M», «18,5 %»); `count: odometer` — каждая цифра крутится барабаном и встаёт на своё место, младшие — дольше. В студии — «Анимация» → «Число набегает», вид — стрелкой рядом. Только при показе и в «Просмотре».

```yaml
    - {type: text, text: "Выручка 17 234 ₽", count: odometer, styles: {text: {size: 54, weight: 800}}, place: {x: 640, y: 300, w: 560}}
```

Морф (`transition: morph` у следующего слайда) переносит и поворот: объект с другим `angle` поворачивается в полёте.

Любому блоку можно добавить `style: "margin-top: 12px"`: это CSS для корневого элемента, запасной выход, если нужной настройки нет.

Щелчок по свободному объекту при показе — `action`: объект становится кнопкой. В студии то же самое — раздел «По щелчку» в «Свойствах». При экспорте в PPTX кнопка остаётся рабочей: переход или ссылка срабатывают и в PowerPoint.

```yaml
    - type: shape
      kind: pill
      fill: gradient
      text: Дальше →
      action: next            # next, prev, first, last, slide:<id слайда> или https://…, mailto:…
      place: {x: 64, y: 612, w: 200, h: 56}
```

Кнопка может показывать и скрывать другие объекты слайда — как триггеры в PowerPoint: ответ на вопрос, подсказка, вкладки. Объекту дают имя `id`, а `hidden: true` скрывает его до щелчка. Действия: `show:<id>`, `hide:<id>`, `toggle:<id>` (показать / скрыть), несколько объектов — через запятую, несколько команд — через «;». Так собираются вкладки: `show:spec,tab2;hide:wave,tab1` (см. слайд «Живой пульт» в витрине).

`play:<id>` — проиграть анимацию объекта по щелчку: его эффект выделения `emphasis` (`pulse` — пульс, `shake` — покачивание, `spin` — вращение, `bounce` — прыжок, `flash` — вспышка) или, если его нет, заново эффект появления `enter`. Скрытый объект при этом появляется. В студии: «По щелчку» → «Проиграть анимацию объекта…», у самого объекта — «Анимация по кнопке «Проиграть»». При каждом заходе на слайд всё возвращается к началу; окна показа и докладчика синхронны. В студии: «По щелчку» → «Показать объект…» и выбрать объект из списка — имя и скрытие он получит сам. В редакторе скрытый объект полупрозрачный; в миниатюрах, PPTX и PDF слайд такой, каким открывается при показе, — без скрытых объектов.

```yaml
    - type: shape
      text: Показать ответ
      action: show:answer
      place: {x: 64, y: 200, w: 260, h: 60}
    - id: answer
      hidden: true
      enter: pop              # появится этим эффектом
      type: shape
      fill: accent
      text: Восемь
      place: {x: 64, y: 300, w: 400, h: 160}
```

### Переход к слайду

У слайда: `transition` — как он сменяет предыдущий: `none` — сразу, `fade` — растворение, `push` — сдвиг (новый выталкивает старый), `cover` — наплыв (новый наезжает поверх), `uncover` — открывание (старый уезжает, под ним — новый), `wipe` — шторка, `split` — панорама от середины, `circle` — круг из центра, `clock` — часы (по кругу, как стрелка), `flash` — вспышка, `zoom` — приближение, `blur` — размытие, `morph` — морф; объёмные: `cube` — куб (слайды — грани), `flip` — отражение (переворот карточкой), `gallery` — галерея (проход вбок в глубине), `switch` — взмах (слайды меняются местами), `doors` — двери (слайд распахивается створками), `fall` — падение (опрокидывается назад); без поля — стандартное появление. `transitionMs` — длительность (600 мс). `transitionDir` — откуда идёт переход у сдвига, наплыва, открывания, шторки, куба, отражения, галереи и взмаха: `right`, `left`, `top`, `bottom` (по умолчанию справа, у шторки — слева); «Назад» — в обратную сторону. В студии — «Анимация» → «Переход к слайду»: галерея (листается стрелками), «Длительность», «Направление», «Ко всем слайдам». Из PowerPoint переходы и их направления переносятся при импорте.

```yaml
  - template: canvas
    transition: push
    transitionDir: bottom     # новый слайд поднимается снизу
    transitionMs: 800
```

## Шаблоны слайдов

### `content` — обычный слайд

```yaml
- title: Результаты эксплуатации
  badge: демо-данные      # чип рядом с заголовком (необязательно)
  gap: 8                  # расстояние между блоками тела, px (по умолчанию 22)
  logo: false             # скрыть логотип в углу (у холста наоборот: logo: true — показать)
  body:
    - type: chips
      items: [...]
    - type: grid
      items: [...]
```

### `cover` — титульный

```yaml
- template: cover
  title: Результаты применения комплекса
  lead: Подзаголовок
  meta: Сентябрь 2026, команда Palorax
  visual:                 # блок справа (необязательно)
    type: network
    nodes: 7
```

Логотип берётся из `brand.logo` в начале файла.

### `finale` — финальный: кольца, луч, слова по одному

```yaml
- template: finale
  caption: Комплекс контроля микроклимата   # мелкая надпись сверху
  title: Спасибо за внимание
  lead: Готовы ответить на вопросы
  link:
    label: Сайт проекта
    url: https://example.com/     # QR-код строится из этой ссылки автоматически
    text: example.com             # необязательно: по умолчанию url без https://
    qr: true                      # false — без QR-кода
  buttons:                        # кнопки с подписью, которая выезжает при наведении
    - icon: mail
      label: Почта
      url: mailto:hello@example.com   # без url кнопка просто показывает подпись
```

### `canvas` — пустой холст

Всё содержимое — свободные объекты (`free`). Так устроены слайды, импортированные из Claude Design.

```yaml
- template: canvas
  label: Идеология бренда   # название в обзоре
  bg: "#f8fafc"             # фон слайда
  logo: true                # логотип в углу, как у обычного слайда (по умолчанию его нет)
  free: [...]
```

В студии — «Свойства» слайда → «Логотип в углу». Если у презентации логотипа ещё нет, там же — «Добавить логотип…».

### `space` — «космический» финальный, всегда тёмный

Те же поля, что у `finale`, плюс `badge` — надпись в «пилюле» над логотипом. Звёзды слегка сдвигаются за мышью.

Анимации `cover`, `finale` и `space` — код движка, общий для всех презентаций. В студии («Код») их не открыть и не поправить. Нужна своя анимация, которую можно править, — соберите финал холстом (ниже).

### Финальный слайд со своей анимацией

Фон-анимация — живая вставка во весь слайд, поверх — обычные объекты (так сделан «Спасибо» в `presentations/slideria`). Код анимации открывается в студии: «Код» → «Анимации · HTML/JS».

```yaml
- id: thanks
  template: canvas               # фон — тема (тёмная тема — тёмный); всегда тёмный — bg: '#0B1220' и цвета текста #RRGGBB
  free:
    - type: embed                # первым: лежит под остальными объектами
      theme: true                # цвета темы внутри: var(--ac, #2563EB)
      interactive: true          # отвечает на мышь и под текстами (кроме ссылок и кнопок)
      code: |
        <canvas id="c"></canvas>
        <script> /* звёзды, частицы, волны по щелчку… */ </script>
      place: {x: 0, y: 0, w: 1280, h: 720}
    - type: text
      text: Спасибо за внимание
      styles: {text: {size: 64, weight: 800, align: center}}
      enter: rise
      place: {x: 140, y: 230, w: 1000}
    - type: text
      text: Готовы ответить на вопросы
      styles: {text: {size: 26, color: text2, align: center}}
      enter: rise
      delay: 300
      place: {x: 140, y: 340, w: 1000}
    - type: link-plate           # ссылка с QR и кнопки, как у финала
      look: fin                  # fin — плашка «Финала» (светлая и тёмная тема); orbit — широкая тёмная карточка
      link: {label: Сайт проекта, url: https://example.com/}
      buttons:
        - {icon: mail, label: Почта, url: 'mailto:hello@example.com'}
      enter: rise
      delay: 600
      place: {x: 290, y: 460, w: 700}
```

Ссылку и кнопки по отдельности дают `link-card` (только ссылка с QR) и `link-buttons` (только кнопки), с теми же полями и `look: space | orbit | fin`. Анимация документа вставки идёт, только пока слайд показан; в миниатюрах, PDF и PPTX — заставка (`poster`, в студии снимается сама).

### Где правится анимация

| Чем сделана | Где править в студии |
|---|---|
| `enter` / `delay` у объекта | Вкладка «Анимация» |
| `@keyframes` и правила в `css` презентации | «Код» → CSS |
| Живая вставка `embed` (`code` или файл `assets/*.htm`) | «Код» → «Анимации · HTML/JS» или двойной щелчок по вставке |
| Встроенные шаблоны `cover`, `finale`, `space`, живые компоненты (`network`, `hub`…) | Не правятся: это код движка. Меняются только их поля |

### Анимированный фон слайда

```yaml
- template: cover
  backdrop: aurora     # см. список ниже; none — без анимации, даже если она есть у темы
```

Фоны (от спокойных к заметным): `mesh` — переливы, `aurora` — сияние, `silk` — шёлк, `waves` — волны линий, `topo` — рельеф (горизонтали карты), `field` — поле (линии уровня текущего потенциала), `rays` — лучи, `bokeh` — боке, `particles` — частицы, `stars` — звёзды, `snow` — снегопад, `leaves` — листопад, `petals` — лепестки, `bubbles` — пузыри, `hearts` — сердечки, `confetti` — конфетти, `caustics` — блики на воде, `ripples` — капли (круги на воде), `plankton` — планктон, `pulse` — пульс, `dots` — точки с волной, `halftone` — поп-арт (растр точек), `origami` — оригами (сгибы и грани), `dither` — 8 бит (пиксельный дизеринг), `network` — сеть узлов (узлы расступаются от курсора и тянут к нему линии, от щелчка расходится кольцо; при показе — и от мыши или пальца докладчика), `hex` — соты, `orbits` — орбиты, `radar` — радар, `cymatics` — резонанс (фигуры Хладни), `dna` — ДНК, `growth` — рост (кривые вверх), `candles` — биржа (японские свечи), `spectrum` — эквалайзер, `grid` — сетка в перспективе, `retrosun` — ретро-закат; заметные: `globe` — вращающийся глобус из точек, `terrain` — ландшафт из точек, `tunnel` — полёт сквозь кольца, `lava` — капли лавы.

Фон для всех слайдов — у темы: `theme: { backdrop: waves }` («Дизайн» → «Анимация»); у слайда свой `backdrop` важнее, `backdrop: none` — без фона темы. Некоторые темы галереи приходят со своим фоном (Полночь — звёзды, Аврора — сияние, Волны — блики на воде, Зима — снегопад…).

Заметность и скорость — `backdropOpacity` (0,1–1) и `backdropSpeed` (0,25–3), у темы для всех слайдов или у слайда для него одного; в студии — ползунки под лентой фонов. «Сеть» отвечает на мышь и щелчки; если это отвлекает — `backdropTouch: false` (у темы или у слайда), в студии — галка «Отвечает на мышь и щелчки» под ползунками. У слайда-холста заметность своего фона — `bgOpacity`. Наведение на тему в галерее примеряет и её анимированный фон.

Работает у любого шаблона, цвета — из акцента и второго цвета темы. Бережно к компьютеру: мягкие фоны рисуются в уменьшенном размере и 30 кадров в секунду. Анимация идёт, только пока слайд на экране; в окне докладчика — облегчённая; при системной настройке «уменьшить движение» — один неподвижный кадр. В миниатюрах, при печати и в PDF — статичный вариант того же фона. В редакторе — «Анимация фона» в панели слайда.

## Раскладка

### `grid` — сетка

```yaml
type: grid
columns: 1.6fr 1fr    # CSS grid или число колонок: 3
rows: 1fr 1fr         # необязательно
gap: 20               # px, по умолчанию 22
height: 540           # px, по умолчанию по содержимому
align: center         # start | center | end | stretch
items:
  - type: tile
    rows: 2           # элемент занимает 2 строки
    cols: 1           # или несколько колонок
```

### `stack` — столбик

```yaml
type: stack
gap: 16
items: [...]
```

### `text`, `note`, `list`, `spacer`

```yaml
- type: text
  text: Обычный абзац. **Жирный** тоже можно.
  size: lead          # lead — крупнее, small — мелко и серым
- type: note
  text: Мелкая серая подпись
- type: list
  items: [Пункт один, Пункт два]
- type: spacer
  size: 24
```

### `image` — картинка

```yaml
type: image
src: ./assets/photo.jpg   # файл рядом с deck.yaml; без src — пустое место под картинку
srcDark: ./assets/photo-dark.jpg  # необязательно: своя картинка для тёмной темы (у tile — imageDark)
height: 360               # высота блока, px
caption: Подпись
```

Кадр (у `image` и у фото на `tile`), в режиме правки задаётся мышью:

```yaml
fit: contain              # contain — целиком, без обрезки; cover — заполнить блок (по умолчанию)
position: "50% 30%"       # какая часть видна при cover: по горизонтали и вертикали
zoom: 1.5                 # увеличение от 1 до 4
```

Наплыв камеры (эффект Кена Бёрнса) — `camera: in` (медленное приближение), `out` (отдаление), `pan` (панорама вбок): пока слайд на экране, фото медленно движется туда и обратно, кадр при этом сохраняется. В студии — «Наплыв камеры» в свойствах картинки. В правке, на миниатюрах и в PDF фото стоит.

В студии: «Кадр» на панели над картинкой или на вкладке «Рисунок» — снимок тянется внутри рамки, как «Обрезка» в PowerPoint (Esc — готово). Точно — ползунки «Видимая часть» в свойствах. Сдвигать есть что, когда снимок обрезан рамкой («Заполнить») или увеличен.

Оформление — как «Формат рисунка» в PowerPoint (вкладка «Рисунок» в студии):

```yaml
radius: 24                # скругление, px; circle — круг (по меньшей стороне рамки, по центру), oval — овал во всю рамку
shadow: md                # sm, md, lg
mat: 10                   # паспарту, px
stroke: accent            # контур: цвет темы или #RRGGBB, толщина — width
opacity: 0.8
fade: bottom              # растворение: bottom, top, left, right — край уходит в прозрачность; edges — со всех сторон
fadeSize: 60              # какая часть снимка растворяется, % (10–90, по умолчанию 50)
filter: duo               # цвет снимка, как LUT
bright: 110               # поверх фильтра, %: яркость 50–150, contrast 50–150, saturate 0–200
```

`filter`: основные — `gray`, `sepia`, `muted`, `vivid`, `light`, `dark`; настроение — `warm`, `cool`, `film`, `punch`, `cinema`, `dusk`, `noir`; в цветах темы — `tone`, `duo` (дуотон акцента), `duo2` (два акцента), `haze`. Фильтры в цветах темы перекрашиваются вместе с акцентом. В студии «Цвет» открывает галерею превью на образце-пейзаже: наведите — фильтр примеряется на сам снимок на слайде, щелчок — применить; ниже — ползунки «Яркость», «Контраст», «Насыщенность» (сразу видно на слайде, отпустили — записано). В PPTX снимок уходит с фильтром и настройкой, как на экране, — в своём разрешении (у крупного фото — до 4× от размера на слайде), а не ужатым: оформление качество снимка не снижает.

`circle` — круг, как кружки видеосообщений в Telegram или окно веб-камеры: при любой рамке снимок обрезается квадратом по меньшей стороне и стоит по центру, растянуть его в овал нельзя. Нужен овал — `oval` (так приходит и фото, обрезанное эллипсом в PowerPoint).

В студии все галереи вкладки «Рисунок» — «Стили», «Тень», «Скругление», «Цвет», «Прозрачность», «Паспарту» — показывают варианты на образце-пейзаже в плитках, как вкладка «Дизайн»: на нём тень, рамка, форма и цвет видны отчётливо, даже если сам снимок — светлый скриншот. Наведите — вариант примеряется на самом снимке на слайде, щелчок — применить; у скругления, прозрачности, паспарту и растворения ниже есть ползунок со своим значением.

`fade` — растворение: часть снимка плавно уходит в прозрачность, без резкой обрезки. Так показывают кусок интерфейса или фото в нужном масштабе: вместе с `zoom` и `position` (кадр) край не обрывается, а тает в фон слайда. В студии — стили «Тает снизу», «Тает сверху», «Тает слева», «Тает справа», «Тает по краям»: «Стили рисунка» на вкладке «Рисунок», стрелка рядом с плитками — все стили с превью на образце (наведите — примерка на самом снимке на слайде) и ползунок «Растворяется» — какая часть. В PPTX снимок уходит уже растворённым (PNG с прозрачностью), у GIF — без растворения: анимация важнее.

### `control` — ползунок, который управляет слайдом

Ползунок задаёт переменную, остальные блоки слайда используют её в формулах. При показе двигаете ползунок — графики, числа и подписи пересчитываются сразу и плавно. В окне докладчика и в окне показа ползунки синхронны.

```yaml
- type: control
  name: v                 # имя переменной
  label: Зрителей в день
  min: 200
  max: 3000
  step: 100
  value: 1500             # начальное положение (оно же — в PPTX и PDF)
  unit: " чел."
- type: bars
  values: ["=v*0.3", "=v*0.4", "=v*0.5"]    # «=формула» в любом поле блока
- type: text
  text: "В месяц: **{{v*30}}**"             # {{формула}} внутри текста
```

В формулах: числа, переменные ползунков этого слайда, `+ - * / ^ %`, скобки и функции `round(x, знаков)`, `min`, `max`, `abs`, `sqrt`, `floor`, `ceil`, `log10`, `ln`, `exp`, `sin`, `cos`, `tan` и число `pi`. В поле значений графика в студии формулы разделяются «;». Формулы работают в любом поле, например `highlight: "=sf-7"` выделяет столбец под текущее значение.

Выбор из вариантов вместо диапазона — `steps`, подписи вариантов — `labels`:

```yaml
- {type: control, name: bw, label: Полоса, steps: [125, 250, 500], unit: " кГц"}
- {type: control, name: cr, label: Кодовая скорость, steps: [1, 2, 3, 4], labels: ["4/5", "4/6", "4/7", "4/8"]}
```

Длинные расчёты удобно один раз записать в поле слайда `vars` — по порядку, каждая величина видит ползунки и предыдущие, блоки ссылаются на имя:

```yaml
- template: canvas
  vars:
    ts: "=2^sf/bw"                 # длительность символа, мс
    rb: "=sf*bw*1000/2^sf*4/(4+cr)"
  free:
    - {type: stat, value: "{{round(rb)}}", label: бит/с}
```

В вёрстке (`html`) числа из `{{…}}` подставляются без пробелов и с точкой — их можно писать в атрибуты SVG. Пример живого слайда — `presentations/lora`.

### `plot` — график функции

Кривая y = f(x) с осями и делениями, прорисовывается при открытии слайда. Ползунки слайда — по имени: двигаете ползунок, кривая меняется сразу. Отрезок в долях π (тригонометрия) подписывается π: −2π … 2π.

```yaml
- type: plot
  fn: a*sin(k*x)        # как в формулах ползунков: * / ^, sqrt, sin, tg, ln, lg, abs, pi, e
  x: [-6.2832, 6.2832]  # по x: от и до
  y: [-3.6, 3.6]        # по y; без него — по самой кривой
  color: accent         # цвет кривой
  var: t                # переменная, если не x
```

Проще всего — из формулы: двойной щелчок по формуле вида `y = …` (или `f(x) = …`) → кнопка «График». Она есть только у таких формул; график встаёт рядом, а если в формуле ползунки, диапазон по y сразу рассчитан на их крайние положения — кривая не уходит за край при показе. Запись формулы понимает умножение без знака (`2x`, `4ac`) и функции без скобок (`sin x`).

### `math` — формула

Уравнение, как в PowerPoint: дроби, корни, степени, суммы, интегралы, матрицы. Браузер рисует его сам (MathML): формула чёткая при любом масштабе, а числа в ней могут браться из ползунков слайда и пересчитываться при показе.

```yaml
- type: math
  tex: "x = (-b +- sqrt(b^2 - 4ac))/(2a)"   # простая запись или LaTeX
  size: 48            # px, по умолчанию 40
  align: left         # left | right; по умолчанию по центру
  color: accent       # роль темы (accent, muted…) или #RRGGBB; по умолчанию цвет текста
  font: classic       # шрифт формул компьютера (Windows — Cambria Math, как в PowerPoint); по умолчанию — современный Fira Math
  steps: lines        # при показе по щелчку: lines — строка за строкой, morph — превращение
```

Простая запись — как пишешь:

| Пишете | Получается |
|---|---|
| `x^2`, `x^(n+1)`, `a_1`, `a_max` | степени и индексы |
| `(a+b)/(c+d)`, `1/2x`, `m v^2/2` | дроби: числитель и знаменатель — соседние части без пробелов |
| `sqrt(x)`, `cbrt(x)`, `root(n, x)`, `√x` | корни |
| `alpha`, `pi`, `Omega` | греческие буквы |
| `sin x`, `ln(x)`, `tg x`, `lim_(x->0)`, `sum_(i=1)^n`, `int_0^1 … dx` | функции, пределы, суммы, интегралы |
| `>=` `<=` `!=` `~=` `+-` `->` `=>` `*` `...` `deg` | ≥ ≤ ≠ ≈ ± → ⇒ · … ° |
| `vec(F)`, `bar(x)`, `hat(y)`, `abs(x)` | вектор, черта, «крышка», модуль |
| `10 м/с`, `"текст"` | слова по-русски и в кавычках — обычным текстом |
| несколько строк | столбиком, выровнено по знаку «=» |
| `[[2ab]]`, `~~3~~` | выделить цветом акцента, зачеркнуть («сокращается») |

Есть в записи `\` — это LaTeX, он идёт как есть: `\frac{a}{b}`, `\begin{pmatrix} a & b \\ c & d \end{pmatrix}`, `\begin{cases} … \end{cases}`. Выделить в LaTeX — `\hl{…}`, зачеркнуть — `\cancel{…}`.

**По шагам.** `steps` — формула раскрывается при показе по щелчку («Далее», пробел, пульт), как анимация «по щелчку» в PowerPoint; когда шаги кончились, «Далее» листает дальше. Назад — шаг назад; на слайд, куда вернулись, формула приходит целиком. Окно докладчика и телефон листают шаги вместе с показом.

- `lines` — строки столбика появляются по одной на своих местах (формула не прыгает).
- `morph` — превращение: каждая строка — формула целиком, по щелчку одна перетекает в другую, одинаковые буквы, числа и скобки перелетают на новые места. Строка, которая начинается с «=», продолжает первую — левая часть подставляется сама:

```yaml
- type: math
  steps: morph
  tex: |
    (a+b)^2
    = (a+b)(a+b)
    = a^2 + ab + ba + b^2
    = a^2 + [[2ab]] + b^2
```

В студии, на миниатюрах, в PDF и PPTX формула по шагам видна в конечном виде.

Живые числа — как в тексте: `{{m}}` или `{{=m*a}}` по ползункам слайда (`control`), по-русски, с запятой:

```yaml
- {type: control, name: m, label: Масса, min: 1, max: 50, value: 12, unit: " кг"}
- {type: control, name: a, label: Ускорение, min: 0.5, max: 20, step: 0.5, value: 9.8}
- {type: math, tex: "F = m*a = {{m}}*{{a}} = {{=m*a}} Н", color: accent}
```

В студии: «Вставка → Уравнение» — заготовки (от дроби до живой формулы и превращения); двойной щелчок по формуле на слайде — поле с записью, слайд меняется на лету, кнопки вставляют дробь, степень, корень, сумму, интеграл, выделение, зачёркивание и живое число; «При показе» в свойствах — по шагам. В PowerPoint формула уходит уравнением Office — правится там же, как обычное уравнение PowerPoint (шрифт Cambria Math); внутри файла остаётся и картинка — её покажут программы без уравнений (и импорт PPTX обратно). Чего PowerPoint от нас не получит (редкие конструкции LaTeX), остаётся картинкой. В PDF и HTML — как на слайде. Набор формул и их шрифт попадают в собранный файл, только если в презентации есть формулы.

### `tile` — плитка с иллюстрацией или фото

```yaml

  title: Сервер
  text: Управление сетью
  groups:
    - { label: Backend, chips: [Go*, REST API] }

  title: Базы данных
  text: Хранение и история

  title: Серверный ПК

### `table` — таблица

```yaml
type: table
variant: stripes        # lines (по умолчанию), stripes — зебра, boxed — сетка, accent — акцентная шапка,
                        # soft — мягкая карточка, dark — тёмная шапка, plan — план работ,
                        # heat — тепловая карта: ячейки-плитки, числа подкрашены по величине, под таблицей шкала
header: [Этап, Срок, Статус]
rows:
  - [Прототип, март, "{#16A34A|● готово}"]
  - [Пилот, май, "{#CA8A04|● идёт}"]
widths: [2, 1, 1]       # доли ширины столбцов (необязательно)
align: [left, center, right]   # без него столбцы из чисел — вправо
labels: true            # первый столбец жирным
lastcol: true           # последний столбец жирным
bands: true             # чередующиеся строки (зебра поверх любого вида)
valign: top             # текст в ячейках по вертикали: top, bottom (по умолчанию — посередине)
fills:                  # заливка ячеек по строкам, как rows: цвет темы (accent, soft, alt…) или #RRGGBB;
  - [null, null, soft]  # null — как у таблицы. Тёмный цвет получает светлый текст
headFills: [accent]     # заливка ячеек шапки
merges: [[0, 0, 2, 1]]  # объединённые ячейки: [строка, столбец, строк, столбцов]; строка -1 — шапка (только по ширине)
heights: [64, null]     # высота строк в пикселях слайда (null — по тексту); headHeight — у шапки
borders: [[0, 0, 2, 2, all]]  # границы ячеек: [строка, столбец, строк, столбцов, all|outer|inner|bottom|none]
highlight: 1            # выделенная строка, с нуля
size: 17                # размер текста, px (от 4 — мелкий текст таблиц-схем из PowerPoint)
columns: [{size: 24, font: Poppins, weight: 700}, null]   # текст столбцов, если он не как у таблицы
total: true             # последняя строка — итог: жирным, с чертой сверху
density: compact        # плотность строк: compact или roomy (по умолчанию — обычная)
head: false             # скрыть шапку (данные шапки сохраняются)
colors: {head: "#1F3B4D", headText: "#FFFFFF", fill: "#FFFFFF", band: "#E8F0F3", text: "#1F2937", line: "#C9D3D8"}
                        # свои цвета вместо темы (так приходят таблицы из PowerPoint): шапка, её текст,
                        # ячейки, чередующиеся строки, текст, линии сетки; любое поле можно опустить
```

При показе строка под мышью подсвечивается, у первой ячейки — полоска акцента. В ячейках работает обычная разметка текста. В студии ячейки правятся прямо на слайде или сеткой полей справа; таблицу из Excel или Google Таблиц можно вставить в любую ячейку. Ширину столбцов у выделенной таблицы тянут мышью за границу между ними — она записывается в `widths`.

Как в PowerPoint: у выделенной таблицы протянуть мышью по ячейкам или Shift+щелчок — диапазон ячеек (Shift+стрелки расширяют, стрелки — по ячейкам, Enter — правка, Esc — снять). Backspace очищает выделенные ячейки; Delete удаляет выделенные строки или столбцы целиком вместе с содержимым (удалили шапку — шапкой становится следующая строка; выделена вся таблица — удаляется таблица), часть ячеек — очищает. «Объединить» (вкладка «Таблица», меню ячейки) — текст остальных ячеек переходит в первую с новой строки; «Разделить» — окно «Разбиение ячеек»: ячейка делится на заданное число столбцов и строк (соседние ячейки растягиваются через новые), объединённая — на свои ячейки. У таблицы с заданной высотой (потянули за нижний край) строки растягиваются на всю рамку. Высоту строки тянут мышью за её нижнюю границу; «Выровнять высоту строк» делает все строки одинаковыми. «Сортировка» на вкладке «Таблица» (по возрастанию или убыванию, по столбцу ячейки под курсором; числа — как числа) переставляет строки вместе с заливкой и высотой, строка итогов остаётся внизу. «Границы ▾» — для диапазона или всей таблицы: все, внешние, внутренние, нижняя, без границ, как в стиле. Ctrl+C / Ctrl+X копируют диапазон табуляциями (вставляется в Excel), Ctrl+V вставляет таблицу из Excel с левой верхней ячейки — таблица растёт, если данных больше. Вставка и удаление строк и столбцов, заливка и выравнивание — для всего диапазона. Tab в последней ячейке добавляет строку, стрелки с первой или последней строки ячейки переходят в соседнюю. Таблица из Excel, вставленная на пустое место слайда, становится новой таблицей. Правый щелчок по ячейке — короткое меню: вырезать, копировать, вставить, вставка и удаление строк и столбцов, очистить, объединить, разбить, удалить таблицу; остальное про объект (порядок, шаблон, рисунок) — правым щелчком по рамке таблицы и на ленте.

### `shape` — фигура

```yaml
type: shape
kind: round        # round (по умолчанию), rect, pill, ellipse, line, arrow — или фигура PowerPoint (ниже)
fill: soft         # surface, bg, alt, soft, accent, text, line, border, muted, gradient, none или #RRGGBB
stroke: accent     # рамка; у линии и стрелки — их цвет
width: 2           # толщина рамки или линии, px
dash: dash         # штрих рамки или линии: dash — пунктир, dot — точки
radius: 16         # скругление, px
shadow: sm         # true / md — заметная тень, sm — лёгкая
rotate: -30        # поворот, градусы
opacity: 0.6       # непрозрачность, от 0.1 до 1
text: Главное      # текст внутри (необязательно)
valign: top        # текст по вертикали: top, middle (по умолчанию), bottom
styles: {text: {size: 24, align: left}}   # оформление текста, как у любого поля
place: {x: 100, y: 100, w: 320, h: 180}
```

Фигуры PowerPoint — `kind` с контуром точно по стандарту (ECMA-376, как в PowerPoint, под размер фигуры): `diamond` (ромб), `triangle`, `right-triangle` (прямоугольный), `parallelogram`, `trapezoid`, `pentagon`, `hexagon`, `octagon`, `star` (звезда), `plus`, `heart`, `lightning` (молния), `donut` (кольцо), `cloud`, `block-arrow` (стрелка-блок), `double-arrow`, `chevron`, `pointer` (указатель), `callout` (выноска), `cylinder`, `brace` (фигурная скобка). Заливка (и градиенты), контур со штрихом, тень, поворот и текст — те же, что у остальных фигур; скругления у них нет. В PowerPoint они уходят той же стандартной фигурой — правятся там как родные. В студии: «Вставка» → «Фигуры» или вкладка «Фигура» → «Ещё» (наведение примеряет форму на слайде). Новая фигура из 187 стандартных — имя в `scripts/shape-presets.mjs` и в `PRESET_KINDS` (`components/shape/kinds.ts`).

Цвета по ролям темы сами меняются в тёмной теме и при смене акцента; `gradient` — градиент от акцентного цвета или свой:

```yaml
fill: gradient
gradient: { from: accent, to: "#F97316", mid: [{ c: accent2, at: 40 }], angle: 90 }   # до четырёх точек между; type: radial — от центра
```

В студии — «Заливка» → «Настроить градиент…»: щелчок по полосе — новая точка, бегунок тянется вбок, вниз (или Delete) — убрать; цвет точки — цвет темы или постоянный. Та же панель — у градиента акцента («Дизайн» → «Цвета» → «Градиент») и у своих цветов слайда. Текст на заливке подбирается сам: светлый на тёмной, тёмный на светлой.

### `video` — видео

```yaml
type: video
src: ./assets/clip.mp4       # MP4, WebM или ссылка на YouTube / Vimeo / Twitch (канал — его прямой эфир, запись, клип)
poster: ./assets/cover.jpg   # обложка до запуска и при печати
autoplay: true               # запуск при открытии слайда (по умолчанию да)
muted: true                  # без звука (по умолчанию — если запускается сам)
loop: false                  # по кругу
controls: true               # кнопки плеера при наведении
fit: cover                   # заполнить рамку; по умолчанию видно целиком
caption: Подпись
```

При уходе со слайда видео останавливается, при возвращении начинается сначала. В окне докладчика звук всегда выключен. YouTube, Vimeo и Twitch нужен интернет; прямой эфир — ссылкой на трансляцию YouTube или на канал Twitch. Файл видео попадает внутрь собранного HTML — такой файл получается большим. В редакторе видео добавляется перетаскиванием файла на слайд или из «Блоки → Медиа».

### `model` — 3D-модель

```yaml
type: model
src: ./assets/device.glb     # glTF в одном файле (GLB)
poster: ./assets/device.png  # снимок: печать, PDF, миниатюры, окно докладчика
rotate: true                 # медленно вращается сама (по умолчанию да)
controls: true               # вращать мышью при показе (по умолчанию да)
exposure: 1                  # яркость
animation: Dance             # анимация из файла модели, играет по кругу (true — первая по списку)
caption: Подпись
```

Модель загружается, когда слайд на экране, и выгружается, когда с него ушли. Снимок делается в редакторе кнопкой «Снимок текущего вида». Библиотека 3D (около 1 МБ) попадает в собранный файл, только если в презентации есть модель.

**STL и STEP.** Перетащите `.stl` или `.step` / `.stp` на слайд в студии (или выберите в поле «Модель») — при вставке файл превратится в GLB и встанет обычной 3D-моделью: крутится мышью при показе, попадает в собранный файл, PPTX и PDF (через снимок). STEP читается ядром OpenCascade, цвета деталей и граней сохраняются — так на слайд встаёт плата из Altium (File → Export → STEP) или деталь из SolidWorks, Fusion, КОМПАС, FreeCAD. В STL цвета нет — модель будет спокойного серо-синего цвета. CAD рисуют в миллиметрах и «Z вверх»: модель поворачивается как надо. Конвертация работает в `yarn dev`; в готовую презентацию попадает уже GLB.

### `group` — группа

```yaml
type: group
place: {x: 120, y: 200, w: 520, h: 180}
base: {w: 520, h: 180}       # размер в момент группировки: от него считаются места объектов
items:
  - {type: shape, kind: ellipse, fill: accent, place: {x: 0, y: 0, w: 180, h: 180}}
  - {type: text, text: Подпись, place: {x: 200, y: 70, w: 320}}
```

Объекты группы стоят от её левого верхнего угла. Растянули группу — объекты растягиваются вместе с ней, текст остаётся своего размера. В студии группу создаёт «Сгруппировать» (Ctrl+G), разбирает — «Разгруппировать» (Ctrl+Shift+G).

### `stat` — ключевое число

```yaml
type: stat
value: 3,4 млн
label: сообщений получено
delta: +12 %           # с минусом — красное со стрелкой вниз
note: за сентябрь      # необязательно
```

### `quote` — цитата

```yaml
type: quote
text: Хорошая презентация отвечает на вопрос раньше, чем его зададут.
author: Имя Фамилия
role: должность
```

### `timeline` — хронология, линия прорисовывается до последнего пройденного этапа

```yaml
type: timeline
items:
  - { date: Март, title: Прототип, text: первые датчики, done: true }
  - { date: Декабрь, title: Масштабирование }
```

### `roadmap` — дорожная карта: путь с изгибами, вехи по очереди

Сколько вех, столько изгибов: путь строится заново, когда веху добавили или убрали («Свойства» → «Вехи»). Путь прорисовывается при показе, вехи появляются по очереди, участок до последней пройденной закрашен.

```yaml
type: roadmap
items:
  - { title: Исследование, text: I квартал, done: true }   # text — срок над вехой
  - { title: Прототип, text: II квартал, done: true }
  - { title: Пилот, text: III квартал }
  - { title: Запуск, text: IV квартал }
```

### `ladder` — лестница роста

Ступени растут слева направо и проявляются по очереди; последняя — акцентом.

```yaml
type: ladder
items:
  - { title: Пилот, text: 1 команда }
  - { title: Отдел, text: 40 человек }
  - { title: Компания, text: 600 человек }
```

### `orbit` — метки на орбитах вокруг центра

```yaml
type: orbit
center: Продукт          # подпись в центре…
sub: версия 2.0
logo: true               # …или логотип презентации вместо неё
items: [{ title: Цели }, { title: Цифры }, { title: План }, { title: Итоги }]
```

### `venn` — диаграмма Венна

Два или три круга пересекаются, общее — подписью в середине (`center`); четыре круга и больше встают цепочкой. Круги прозрачные — пересечения темнеют сами — или залитые (`variant: filled`: от светлого к насыщенному, текст светлый). При появлении круги сходятся, под мышью круг подсвечивается.

```yaml
type: venn
center: Наш продукт
variant: filled          # залитые круги; без него — прозрачные
items:
  - { title: Скорость, text: Готово за минуты }
  - { title: Качество, text: Дизайн без дизайнера }
  - { title: Цена, text: Дешевле агентства }
```

### `nested` — вложенные круги

Круги друг в друге, касаются снизу (рынок: TAM, SAM, SOM); первый пункт — самый большой. `variant: target` — мишень: те же круги по центру, заголовки — в кольцах сверху, пояснения — ровной колонкой справа. Заголовок — в круге, пояснение (`text`) — справа, к нему ведёт линия; без пояснений круги стоят по центру. Круги вырастают по очереди; под мышью круг, его линия и пояснение подсвечиваются (и при наведении на само пояснение).

```yaml
type: nested
variant: target          # мишень по центру; без него — круги касаются снизу
items:
  - { title: TAM, text: 120 млрд ₽ — весь рынок }
  - { title: SAM, text: 18 млрд ₽ — наш сегмент }
  - { title: SOM, text: 1,2 млрд ₽ — доля за три года }
```

Высота обеих схем — по их пропорции: в раскладке слайда не выше 440 px, у свободного объекта — по ширине рамки.

### Схемы-фигуры: `gears`, `pillars`, `layers`, `diamonds`, `arc`, `mindmap`, `iceberg`

Те же пункты `items: [{title, text}]`, у каждой — своё появление и подсветка под мышью.

- `gears` — шестерёнки: колёса через одно большие и малые, крутятся в зацеплении (соседние — навстречу). Заголовок — в колесе, пояснение — под колёсами на одной линии.
- `pillars` — колонны: общая крыша (`center`) на опорах, по колонне на пункт; колонны вырастают, крыша опускается на них. Под мышью колонна заливается цветом.
- `layers` — изометрические слои: плиты друг над другом, первый пункт — верхняя, подписи справа. Под мышью слой приподнимается, остальные бледнеют.
- `diamonds` — ромбы в ряд с иконкой по смыслу заголовка (или своя `icon`), подписи через одну сверху и снизу. Под мышью ромб поворачивается.
- `arc` — дуга-дорога: вехи полукругом слева направо, цель (`center`) в середине, по дороге едет огонёк.
- `iceberg` — айсберг: первый пункт — верхушка над водой (что видно), остальные — под водой (что за этим стоит), подписи справа; по воде бегут волны.
- `mindmap` — карта идей: главная мысль (`center`) в середине, пункты — карточками справа и слева, к каждой ведёт ветвь.

```yaml
type: pillars
center: Стратегия 2027
items:
  - { title: Люди, text: Сильная команда }
  - { title: Продукт, text: Лучший в нише }
  - { title: Клиенты, text: Растём вместе }
```

Шестерёнки, слои, дуга, карта идей и айсберг — по своей пропорции (в раскладке не выше 440 px), колонны и ромбы — по содержимому.

`roadmap`, `ladder`, `orbit`, `venn`, `nested`, `gears`, `pillars`, `layers`, `diamonds`, `arc`, `mindmap`, `iceberg`, `timeline`, `pipeline` и другие схемы из пунктов переводятся друг в друга: «Свойства» → «Вид».

### `marquee` — бегущая строка

Пункты без конца прокручиваются вбок, края тают в фон. В правке наведение останавливает строку, чтобы поправить пункт. В миниатюрах, PDF и PowerPoint (картинкой) — строка с начала.

```yaml
type: marquee
items: [Быстрее, Понятнее, Красивее, ./assets/logo.png]   # путь к картинке — логотип
variant: chips           # без него — текст через точку; chips — плашками; outline — через один контуром
speed: slow              # slow, fast; без него — обычная
dir: right               # вправо; без него — влево
size: 32                 # размер текста, px (28)
place: { x: 0, y: 600, w: 1280 }
```

### `ring` — текст по окружности

Буквы равномерно по кругу, круг медленно вращается; размер букв подбирается по длине текста, разделитель «•» на стыке ставится сам. Круг вписан в рамку объекта.

```yaml
type: ring
text: Slideria • презентации
center: ★                # в центре: знак, слово, число…
logo: true               # …или логотип презентации
variant: badge           # печать: залитый круг в цветах темы
spin: reverse            # против часовой; none — без вращения
place: { x: 1000, y: 40, w: 220, h: 220 }
```

## Готовая вёрстка

Эти блоки создаёт импорт из Claude Design. Их можно и писать руками.

### `html` — фрагмент вёрстки с редактируемыми текстами и картинками

```yaml
type: html
scale: 0.6667             # пиксели вёрстки → пиксели слайда (макет 1920×1080 → 1280×720)
html: '<div style="font-size: 69px; font-weight: 800"><span data-t="0"></span></div><img data-i="0" style="width: 92px">'
texts:                    # содержимое элементов data-t, с обычной разметкой текста
  - Результаты применения
images:                   # картинки элементов data-i; кадр (fit, position, zoom) — рядом
  - src: ./assets/logo.svg
styles:                   # оформление из режима правки, по номеру текста
  "0": {size: 72, color: accent}
place: {x: 64, y: 254, w: 615}
```

Скрипты и обработчики событий из разметки удаляются.

### Стили презентации: `css`

Импорт своего HTML переносит его `<style>` в поле `css` в начале `deck.yaml`. Стили действуют только внутри слайдов-холстов и только на импортированную вёрстку: `.card` из презентации не заденет ни интерфейс, ни встроенные блоки (карточки, графики), вставленные на тот же слайд. `:root`, `html` и `body` означают сам слайд, `.slide` — корень вёрстки слайда. Цвета пишите через переменные темы: `var(--ac)`, `var(--tx)`… (список — в [docs/HTML.md](HTML.md#цвета)).

```yaml
css: |
  .card { background: var(--surf); border: 1px solid var(--bd); border-radius: 16px; }
  @keyframes pulse { 50% { transform: scale(1.05); } }
```

### `embed` — «живая» вставка (анимация, интерактив)

Отдельный HTML-документ в изолированном iframe. Запускается, когда слайд открыт. В миниатюрах, при печати и до загрузки видна заставка.

```yaml
type: embed
src: ./assets/embed-bdb2b72ca6.htm   # документ вставки
poster: ./assets/image-9cf793af35.png
theme: true                           # вставка получает цвета темы: var(--ac) и др.
place: {x: 0, y: 0, w: 1280, h: 720}
```

С `theme: true` вставка перезапускается при смене темы и акцентного цвета. В тёмной теме заставка не показывается: она снята в светлой. Если у вставки своя тёмная сцена, `dark: true` — её заставка в тёмной теме остаётся как есть.

С `interactive: true` вставка при показе отвечает на мышь. Если поверх неё лежат другие объекты (фон-анимация под заголовком), движения курсора и щелчки над ними тоже доходят до вставки. Исключения — ссылки, кнопки, поля ввода и объекты с действием по щелчку: они работают как обычно. В режиме правки мышь выделяет объекты, во вставку не уходит.

Щелчок по интерактивной вставке отдаёт ей и клавиатуру: стрелки и пробел уходят во вставку, а не листают слайды. Щелчок мимо возвращает клавиши презентации.

Тяжёлые файлы (движок WebAssembly, данные игры, большие картинки) вставка получает полем `files` — так они работают и в собранном HTML без интернета:

```yaml
type: embed
src: ./assets/embed-doom.htm
interactive: true
files:                                # имя во вставке → файл презентации (.wasm, .wad, картинки…)
  doom.wasm: ./assets/doom.wasm
  doom1.wad: ./assets/doom1.wad
```

Внутри вставки: `const files = await slideriaFiles` → `{ 'doom.wasm': ArrayBuffer, … }`. Пример — слайд с DOOM в презентации `memes`.

Если вставка перестала рисовать кадры (браузер «заморозил» рамку), презентация перезапускает её. Тяжёлой вставке, которая долго грузится (3D-модель, компиляция шейдеров), можно попросить подождать: `parent.postMessage({ slideriaHold: 15000 }, '*')` — до 15 секунд. Пример — 3D-слайд Getsuga Tenshou в `memes`.

Код можно держать прямо в данных — поле `code` вместо `src`:

```yaml
type: embed
theme: true
interactive: true                     # при показе вставка отвечает на мышь
code: |
  <canvas id="c"></canvas>
  <script> /* анимация */ </script>
```

В студии: HTML-файл с анимацией **перетащите на слайд** — он станет живой вставкой, файл ляжет в `assets/`, заставка для миниатюр, PPTX и PDF снимется сама. **Двойной щелчок** по вставке (или «Код вставки…» в свойствах) открывает редактор: код слева, он же в работе справа, Ctrl+Enter — применить. Готовый пример — «Живой код» в галерее блоков («Интерактив»). Код работает в изолированной рамке: без доступа к презентации, студии и файлам проекта.

### `sandbox` — песочница: код и результат рядом

Редактор кода с подсветкой и номерами строк, справа — результат и консоль. **При показе код правится прямо на слайде**: результат обновляется через долю секунды после паузы в наборе, `console.log` и ошибки (с номером строки) видны в консоли. Правку видят оба окна — показа и докладчика.

```yaml
type: sandbox
title: rose.html          # имя в заголовке редактора
theme: true               # цвета темы в результате: var(--ac), var(--ac2)…
size: 15                  # кегль кода, px
split: 56                 # ширина редактора, %
console: true             # консоль под результатом
code: |
  <canvas id="c"></canvas>
  <script> /* … */ </script>
place: {x: 48, y: 140, w: 1184, h: 500}
```

При показе: щелчок в код — печатать (стрелки и пробел слайды не листают), **Esc** — снова листать, **Ctrl+Enter** или «Запустить» — сразу, **↺** — исходный код, **A− / A+** — кегль для зала. Правки показа в презентацию не сохраняются. В студии песочница — обычный объект; её код — двойным щелчком или «Код песочницы…», заставка результата снимается сама (для миниатюр, PPTX и PDF; в PPTX песочница — картинкой). Готовая — «Песочница» в галерее блоков («Интерактив»).

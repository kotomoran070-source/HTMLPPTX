# Чат «Агент» в студии

Claude правит открытую презентацию по просьбе — прямо в студии, без отдельных программ. Пишешь задачу («обнови
цифры по этому скриншоту», «сократи текст вдвое»), прикладываешь картинки, агент читает слайды и правит их теми же
операциями, что агенты по MCP ([OPS.md](OPS.md), [MCP.md](MCP.md)): каждая правка проверяется, видна на слайде сразу,
перед ней ставится контрольная точка.

## Где

Панель справа, на месте «Свойств»: ✦ в шапке, «Агент» в строке состояния, Ctrl+J (и из её поля — закрыть).
«Свойства» (Ctrl+Shift+2) встают обратно на её место. Ширина своя — тянется за границу.

- **Сообщение:** Enter — отправить, Shift+Enter — новая строка. Открытый слайд уходит вместе с сообщением
  (плашка «Слайд 5», ✕ — без него).
- **Картинки** (PNG, JPG, WebP, GIF, до 5 МБ, до 6 в сообщении): скрепка, Ctrl+V или перетаскивание на панель.
  Агент их видит и по просьбе ставит на слайд (картинка копируется в файлы презентации).
- **Пока агент работает:** видны его шаги («Прочитал слайд 5», «Правка объекта · слайд 5») и ответ по мере
  написания. «Стоп» (кнопка или Esc) — останавливает; сделанные правки остаются.
- **Под ответом — карточка правок:** эскиз слайда, сколько правок. «Показать» — к слайду, «Вернуть» — как было до
  ответа, а то, что поправили после, остаётся (слияние трёх версий по точкам до и после).
- **Ctrl+Z** отменяет весь ответ агента одним шагом: вы сами попросили его в этом окне. Правки внешних агентов
  (по MCP) Ctrl+Z, наоборот, не трогает.
- **Модель** — в шапке панели: Claude Opus 5.5 (по умолчанию, лучше всех понимает оформление), Sonnet 5.5
  (быстрее и дешевле), Haiku 5.5 (самый быстрый). Там же — «Отключить ключ Claude».
- **Разговоры** — у каждой презентации свои: «+» — новый, часы — прошлые (открыть, удалить).

Уходите из студии после ответа агента — правки агента входят в «Сохранить изменения?» наравне со своими.

## Подключение

Нужен ключ Claude API: [platform.claude.com → Settings → API keys](https://platform.claude.com/settings/keys).
Оплата — за запросы по тарифам Claude API. Подписка Claude к сторонней программе не подключается: с подпиской
правят из окна Claude Desktop или Claude Code через MCP — подключаются в один щелчок в «Файл → Интеграции → Агенты».

Ключ при подключении проверяется у Claude (список моделей — бесплатно) и хранится только на сервере программы —
страница студии его не видит:

| Где запущено | Где ключ |
|---|---|
| Программа (Windows, macOS, Linux с хранилищем паролей) | `claude-key.bin` в данных программы, зашифрован системой (safeStorage: DPAPI, Связка ключей, GNOME Keyring или KWallet) |
| Программа на Linux без хранилища паролей | там же, зашифрован встроенным паролем Chromium — файл не читается как текст, но защита слабее; панель об этом говорит |
| `yarn dev`, `scripts/serve.mjs` | переменная `ANTHROPIC_API_KEY`; введённый в студии — в памяти до перезапуска сервера |

**Что уходит в Anthropic:** текст сообщения, приложенные картинки, данные открытого слайда (до 24 КБ, больше —
агент читает сам) и то, что агент прочитает инструментами. Только когда вы пишете агенту.

## Как устроено

`server/agent.ts` — цикл Claude API (SDK `@anthropic-ai/sdk`, ответ потоком) с инструментами:

| Инструмент | Что делает |
|---|---|
| `read_presentation` | краткое содержание или один слайд целиком (как MCP) |
| `edit_presentation` | пакет операций с `expect` — ревизиями прочитанных слайдов (как MCP) |
| `format_guide` | справка по формату — `docs/skills/slideria-deck/SKILL.md` (в установщике тоже) |
| `use_attachment` | картинка из разговора → файл презентации, ответ — путь `./assets/…` |

Правки — `core.apply` с `by: { kind: 'agent', id: 'studio-chat', name: 'Агент' }`: точки до и после, запись
журнала («Версии» — сеанс «Агент», «Файл → Интеграции → Журнал»). «Что можно агентам» чата не касается — это
просьба самого пользователя. Студия вливает правки своего чата как свои (`Editor.agentAnswer`): весь ответ — один
шаг отмены; плашка внешних агентов и их подсказка на холсте правки чата не показывают.

Предел — 40 шагов «модель → инструменты» на ответ; ввод инструмента, оборванный на пределе длины, не выполняется.
Ошибки Claude — понятным текстом: ключ отозван («Подключить заново»), лимит запросов, перегрузка, нет связи
(«Повторить»).

**Переписка** — `.slideria/chats/<имя>/<id>.json` (для панели и для Claude) и картинки рядом, в папке `<id>/`. В файл
презентации и в экспорт не попадает; уходит в корзину вместе с презентацией (`.history/chats`) и возвращается с ней.

**Команды сервера** (`server/http.ts`, только POST с этого компьютера):

| Команда | Что делает |
|---|---|
| `chat-status` | подключён ли Claude, где ключ, модели |
| `chat-connect`, `chat-disconnect` | подключить ключ `{ key }` (проверка у Claude), отключить |
| `chat-send?deck=` | сообщение `{ chat, text, images, slide, model }` — ответ потоком событий, строка JSON на событие: `chat`, `think`, `step`, `text`, `edit` (запись журнала), `error`, `done`. Закрыли запрос — агент останавливается |
| `chat-list`, `chat-read`, `chat-delete`, `chat-image` | разговоры презентации, разговор, удалить, картинка из разговора |

**Тесты** — на подставном Claude (`tests/mock-claude.ts`): поток событий как у `/v1/messages`, ходы по сценарию теста.
Адрес Claude API для сервера — `SLIDERIA_ANTHROPIC_URL` (у сервера тестов — `http://127.0.0.1:5191`).

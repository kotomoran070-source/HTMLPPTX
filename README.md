# Slideria — презентации как данные

Движок HTML-презентаций. Слайды описываются в YAML-файле, внешний вид задают компоненты, а на выходе получается **один HTML-файл**. Он открывается без интернета, его можно отправить по почте, и в нём работают темы, анимации и режим докладчика.

Проект состоит из трёх частей:

| Часть | Где лежит | Что это |
|---|---|---|
| Движок | `src/engine` | Показ, темы, обзор слайдов, режим докладчика, режим правки, навигация, печать |
| Компоненты | `src/components` | Кирпичики слайдов: схема сети, пайплайн, графики, финальные слайды… |
| Презентации | `presentations/<имя>/deck.yaml` | Только тексты и данные, без стилей и кода |

## Быстрый старт

Нужен Node.js 18 или новее (рекомендуется 20+) и yarn (`npm i -g yarn`).

```bash
yarn            # установить зависимости (один раз)
yarn dev        # мастерская: откроется браузер, правки deck.yaml видны сразу
yarn build      # собрать все презентации в dist/<имя>.html
```

Вместо yarn можно использовать npm: `npm install`, `npm run dev`, `npm run build`.

| Команда | Что делает |
|---|---|
| `yarn dev` | Локальный сервер с живым обновлением. Если презентаций несколько, откроется страница выбора: миниатюры, импорт HTML и PowerPoint, подсказка про новую презентацию, удаление (папка уходит в `presentations/.trash/`, её можно вернуть). Из презентации туда ведёт «Все слайды» → «Все презентации» |
| `yarn build` | Все презентации → `dist/<имя>.html` |
| `yarn build microclimate` | Только одна презентация |
| `yarn build microclimate --clean` | «Для показа»: тот же файл без режима правки → `dist/microclimate.show.html` |
| `yarn present microclimate` | Показ с пультом на телефоне: собрать и раздать в локальной сети (нажмите R в показе — будет QR) |
| `yarn new q3-report "Итоги квартала"` | Новая презентация из шаблона `templates/basic` |
| `yarn merge-html файл.html [имя]` | Импорт HTML: экспорт Claude Design, свой HTML по [правилам](docs/HTML.md) или правки из собранного файла. `--dry-run` — только показать, что изменится, `--no-theme` — не привязывать цвета к теме |
| `yarn import-pptx файл.pptx [имя]` | Импорт PowerPoint: новая презентация, каждый слайд — холст с объектами на своих местах. `--dry-run` — только отчёт |
| `yarn bind-theme имя` | Привязать цвета импортированной вёрстки к теме (тёмная тема, смена акцента) |
| `yarn verify` | Проверка типов и сборка: запускать после правок кода компонентов |
| `yarn test` | Автотесты: показ, правка, экспорт, студия, приложение (см. «Автотесты») |

## Приложение для компьютера

То же самое, но отдельной программой — без терминала и браузера. Это Electron: внутри тот же движок
и тот же сервер, что в `yarn dev`, поэтому всё работает одинаково.

```bash
yarn app        # запустить приложение из проекта (для проверки)
yarn app:build  # установщик для Windows → dist-app/Slideria Setup <версия>.exe
```

- Презентации лежат в **Документы/Slideria** — по папке на презентацию, как в `presentations/`.
  При первом запуске там появляется «Моя первая презентация» — путеводитель по Slideria: студия, свои блоки, интерактив, оформление, пульт и примеры по разделам. Меню (Alt) → «Файл» → «Папка с презентациями».
- Пульт с телефона: в показе нажмите **R** — появится QR. Только в этот момент приложение открывает
  вход в локальной сети, и через него виден лишь показ этой презентации: другие презентации
  и правка с телефона недоступны. В первый раз Windows сама спросит, разрешить ли Slideria
  доступ к сети, — нажмите «Разрешить». Если там нажали «Отмена» или сеть «общественная»,
  в окне с QR есть кнопка «Разрешить в брандмауэре»: правило для Slideria (порты 5180–5199,
  только локальная сеть) добавляется после подтверждения администратора.
- Библиотека шрифтов, кэш и журнал работы — в `%APPDATA%/Slideria` (журнал: меню «Справка»).
- Установщик не подписан: при первом запуске Windows покажет «Неизвестный издатель» →
  «Подробнее» → «Выполнить в любом случае».
- Код приложения — `desktop/main.mjs`; остальной код общий с `yarn dev`.

## Автотесты

```bash
yarn test        # всё: около 3 минут
yarn test:unit   # быстрые проверки без браузера, секунды
yarn test:e2e    # презентации в браузере: показ, правка, экспорт, студия
yarn test:app    # приложение Electron
```

Тесты работают на временной копии (`.tmp/test-decks`: стартовый шаблон и витрина slideria) —
`presentations/`, «Документы/Slideria» и данные приложения не трогаются. Браузер на Windows —
установленный Microsoft Edge, качать ничего не нужно; на macOS и Linux один раз:
`npx playwright install chromium`. Упавший тест оставляет в `.tmp/test-results` запись
(`npx playwright show-trace …` покажет его по шагам).

Что проверяется:

| Набор | Что ловит |
|---|---|
| unit | запись в `deck.yaml` не портит комментарии; имена папок латиницей; пульт пересылает сообщения; вход для телефона в приложении пускает только к показываемой презентации |
| e2e · показ | все слайды шаблона и витрины листаются без ошибок; номер слайда в адресе; тема T и картинки для тёмной темы; оглавление-ссылки; ползунок пересчитывает числа, кнопка открывает скрытое; обзор O |
| e2e · правка | текст на слайде → `deck.yaml` (комментарии и пути на месте), Ctrl+Z; загрузка картинки; новая презентация и корзина; чужой сайт не может править; пробный импорт HTML |
| e2e · экспорт | HTML для показа и с правкой открываются с диска без ошибок; PowerPoint — все слайды, заметки, тексты текстом |
| e2e · студия | открывается без ошибок; «Сохранить как шаблон…» → «Мои шаблоны»; меню «Цвет» картинки не закрывает слайд |
| app | первый запуск создаёт «Мою первую презентацию»; экспорт через Electron; вход для телефона |

## Во время показа

| Клавиша | Действие |
|---|---|
| → ↓ Пробел PageDown | Следующий слайд |
| ← ↑ PageUp Backspace | Предыдущий слайд |
| Home / End | Первый / последний слайд |
| Номер + Enter | Перейти к слайду, например `5` Enter |
| O | Обзор всех слайдов с миниатюрами (Esc — закрыть) |
| P | Окно докладчика |
| R | Пульт с телефона: QR для подключения |
| F | Во весь экран |
| T | Светлая / тёмная тема |
| B или . | Чёрный экран |
| E | Режим правки |

Буквенные клавиши работают и в русской раскладке. На телефоне и планшете слайды листаются свайпом. Номер слайда хранится в адресе (`…/microclimate.html#4`), поэтому после перезагрузки показ продолжается с того же места.

**Тема.** По умолчанию берётся из настроек системы. Выбор кнопкой запоминается в браузере. «Космический» финальный слайд всегда тёмный.

**Режим докладчика.** Клавиша P (в редакторе — «Режим докладчика», Alt+F5) раскладывает окна по экранам, как PowerPoint: показ уходит во весь экран на проектор, окно докладчика открывается на весь экран у вас. Это делают Chrome и Edge; при первом запуске браузер спросит разрешение «Управление окнами». Проектор должен работать в режиме «Расширить», а не «Повторить» (Windows: Win+P): при повторе экрана зрители увидят и заметки — показ подскажет об этом. В других браузерах окно показа перетаскивают на проектор вручную и нажимают F. Окно докладчика: В нём текущий слайд, следующий слайд, заметки из поля `notes`, таймер с паузой и часы. Листать можно в любом из двух окон, они синхронизированы. Границы между текущим слайдом, следующим и заметками перетаскиваются, как в PowerPoint (двойной клик — как было), раскладка запоминается. Под слайдом панель инструментов: указка (L), перо с выбором цвета (D), стереть всё (C), все слайды (G), чёрный экран (B). Всё нарисованное видно зрителям сразу и стирается при смене слайда. Тема и чёрный экран тоже передаются между окнами. Работает и в собранном файле, открытом с диска.

**Пульт с телефона.** Запустите показ командой `yarn present имя`: она соберёт презентацию и раздаст её в локальной сети, показ откроется сам. Откройте окно докладчика и нажмите в его панели кнопку с телефоном (или **R**) — QR появится у докладчика, зал его не видит. Без второго экрана — клавиша **R** прямо в показе. Наведите на QR камеру телефона. На телефоне откроется режим докладчика этого показа: живой слайд (кнопки, вкладки, ползунки и песочница работают, и зал видит то же), указка, перо и чёрный экран, заметки, таймер, крупные «Назад» и «Далее»; листать можно и свайпом по заметкам (по слайду — нет: там указка и живые объекты). Связь видна внизу: «Связь с окном показа есть» или «Нет связи — отсканируйте QR заново». Экономный режим (кнопка с паузой, включён сразу): после появления слайд на телефоне замирает — анимации, живые вставки и песочница не тратят батарею; касание оживляет его на 8 секунд, связь проверяется реже. Зал при этом видит всё как обычно. Телефон и компьютер должны быть в одной Wi-Fi (подойдёт и раздача с телефона). Из `yarn dev` пульт тоже работает, если запустить его с `--host` (тогда доступны все презентации); устройства в сети при этом только смотрят и листают — править проект можно лишь с этого компьютера. На Windows `yarn dev --host` брандмауэр только проверяет (без запросов) и, если телефону что-то мешает, подскажет в терминале выполнить `yarn firewall`; `yarn present` при первом запуске сам настроит брандмауэр: разрешит порты 5173–5199 только для устройств локальной сети и выключит запреты для Node, которые Windows создаёт, если в её окне «Разрешить доступ» нажали «Отмена» (один запрос администратора; брандмауэр отключать не нужно, правило «Slideria remote» можно удалить в настройках). `yarn firewall` настраивает то же отдельно, по вашей команде. Файл, открытый с диска, пульт не подключит: ему нужен сервер показа. Запасной способ без Node — `scripts/windows/Показ с пультом.cmd`: положите его рядом с собранной презентацией (или перетащите на него .html) и запустите двойным щелчком — он сам раздаст показ в сети и откроет показ; дальше всё как с `yarn present`. Брандмауэр он сам не трогает: если телефон не открывает страницу, в окне с QR нажмите «Разрешить в брандмауэре» (один запрос администратора).

**Кликер.** Обычная указка-кликер с USB-приёмником притворяется клавиатурой: шлёт PageDown / PageUp, B или «.» — показ понимает их без настройки. Кнопка «старт» (F5) перезагружает страницу, но показ продолжится с того же слайда.

**PDF.** Откройте презентацию, нажмите Ctrl+P (⌘P) и выберите «Сохранить как PDF». Каждый слайд окажется на отдельной странице 16:9, анимации будут в конечном состоянии.

## Режим правки

Кнопка с карандашом справа внизу или клавиша E. Правки видны сразу и работают так:

| Что | Как |
|---|---|
| Текст | Клик по тексту, правка на месте. Enter — новая строка, Esc, Ctrl+Enter или щелчок мимо — готово (правка сохраняется; отменить — Ctrl+Z), Tab — следующее поле |
| Оформление текста | Панель над текстом: шрифт, размер, цвет, жирный, курсив, подчёркнутый (Ctrl+B/I/U), ссылка (Ctrl+K), список, выравнивание, сброс. Цвет с выделением красит только выделенное. Без выделения команда применяется ко всему полю. Ручка справа от текста — ширина поля (где переносятся строки), двойной клик по ней — как было |
| Картинка, логотип, фото на плитке | Клик — выделение и панель картинки: заменить, «Целиком» (без обрезки) или «Заполнить», масштаб 30–300 %, сдвиг (тяните картинку мышью), × — убрать. Двойной клик или перетаскивание файла — замена. Убранное фото на плитке возвращает исходную иллюстрацию, иначе остаётся пустое место |
| Любой блок (карточка, плитка, график, схема…) | Клик по блоку (не по тексту) — выделение и панель: «Выше» — внешний блок, «Свободно» — открепить от раскладки, корзина или Delete — удалить |
| Свободные объекты | «Вставить» → текст или картинка появляется поверх слайда, на любом слайде. Объект тянется за любое место сразу, без предварительного клика; выделенный блок раскладки, если его потянуть, сам становится свободным. Тяните объект мышью, за 8 ручек — меняйте размер (картинки за угол — пропорционально, Shift — наоборот). Кружок над рамкой — поворот на любой угол, как в PowerPoint (Shift — шагами по 15°, возле 0/90/180° прилипает). Края прилипают к краям и центру слайда и к другим объектам, Alt — без прилипания. Стрелки — сдвиг на 1 px, Shift+стрелки — на 10 px, Ctrl+D — дубликат, кнопки — слой выше или ниже, «В раскладку» — вернуть в поток слайда. Первый клик выделяет объект, второй — правит текст. У свободной картинки кадр сдвигается в режиме «Кадр» (кнопка на панели над картинкой или на вкладке «Рисунок», Esc — готово) или с Alt |
| Ссылка и QR-код | Наведите на ссылку или кнопку → «Изменить ссылку». QR-код перестроится сам |
| Порядок слайдов | «Слайды» или O: перетащите миниатюру. Кнопки на миниатюре — дублировать и удалить. С клавиатуры: Alt + ← →, Delete |
| Новый слайд | В обзоре: «Заголовок и текст», «Три карточки», «Картинка» или «Пустой холст» |
| Заметки докладчика | Кнопка «Заметки»: поле под слайдом |
| Акцентный цвет | Кнопка «Цвет». Оттенки для светлой и тёмной темы строятся сами |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z (⌘ на Mac), до 200 шагов |

Куда сохраняются правки:

- **В `yarn dev`** — сразу в `deck.yaml`, без кнопки. Комментарии и оформление файла сохраняются, меняются только отредактированные строки. Новые картинки кладутся в `assets/`, большие фото уменьшаются до 2400 px по длинной стороне. Если правите `deck.yaml` в редакторе кода, страница обновится сама.
- **В собранном HTML-файле** — кнопка «Сохранить» или Ctrl+S. Chrome и Edge спросят, куда сохранить, и дальше будут записывать в тот же файл. Другие браузеры скачают копию файла с правками. Картинки встраиваются внутрь файла. Сохранённый файл снова открывается и правится. Если закрыть вкладку с несохранёнными правками, браузер предупредит.

Правки, сделанные в собранном файле, можно вернуть в проект — см. следующий раздел.

Окно докладчика получает правки сразу. Через режим правки меняется то, что уже есть на слайдах. Новые поля, другой компонент или раскладку проще задать в `deck.yaml` (или попросить Claude).

## Редактор (студия)

Полноценный редактор в духе PowerPoint. Работает в `yarn dev`: на странице выбора кнопка «Редактор» на карточке презентации, в показе кнопка со слоями справа внизу или адрес `?deck=имя&studio`.

| Часть экрана | Что в ней |
|---|---|
| Шапка | Все презентации, название (правится на месте), вкладки ленты, состояние сохранения, «Экспорт», тема интерфейса, «Показ» с текущего слайда |
| «Экспорт» | Скачать презентацию: **HTML для показа** — один файл без редактора (открыть в браузере, отправить, загрузить в другой сервис); **HTML с правкой** — тот же файл с режимом правки (E), правки возвращаются через импорт; **PowerPoint** — файл PPTX: подложки становятся фигурами, тексты — надписями с тем же оформлением, таблицы — таблицами, столбцы и линии — диаграммами PowerPoint, заметки — заметками докладчика; всё правится в PowerPoint. Принцип: главный формат — HTML, PPTX — лучшее, что умеет PowerPoint, и никогда не ломается. Что PowerPoint умеет — уходит родным объектом; что не умеет (фильтры и тонировка снимков, CSS-эффекты, 3D, сложная вёрстка) — картинкой, как на экране; живое (вставки, песочница, видео-фоны) — заставкой; интерактив (наведение, пульт) — не переносится. Анимации не переносятся, слайды выгружаются в светлой теме; **PDF** — окно печати, слайд на страницу. Это та же сборка, что `yarn build`, занимает пару секунд |
| Вкладки «Фигура» и «Таблица» | Появляются, пока выделена фигура или таблица, как «Формат фигуры» и «Макет таблицы» в PowerPoint, но без лишнего. Фигура: готовые стили (живые образцы в цветах темы), форма, палитра заливки и контура (цвета темы, постоянные цвета, толщина, пунктир), надпись внутри фигуры — размер, жирность, выравнивание по горизонтали и вертикали, тень, скругление, поворот, прозрачность. Таблица: шесть стилей, флажки «строка заголовка», «первый столбец», «итоговая строка», «выделить строку», вставка строк и столбцов у ячейки с курсором, «Удалить» (строку, столбец, таблицу), выравнивание столбца, ширина поровну, плотность, размер текста. Ширину столбцов тянут мышью за границу прямо на слайде |
| Лента «Главная» | Новый слайд (шаблоны), дублировать и удалить слайд, отменить и повторить, оформление текста (шрифт, размер, цвет, начертание, ссылка, список, выравнивание — оживает, когда правится текст), вставка, порядок и группировка, выравнивание на слайде |
| Лента «Вставка», «Дизайн», «Показ» | Шаблоны новых слайдов; акцентный цвет и тема; показ с начала или с текущего слайда, просмотр анимации слайда |
| Слева | Миниатюры слайдов: клик — перейти, перетаскивание — порядок, правый клик — меню |
| В центре | Слайд: правка на месте как в режиме правки (текст, картинки, блоки, свободные объекты с направляющими). Shift+клик — выделить несколько объектов: тянуть вместе, выровнять относительно друг друга, распределить с равными промежутками, дать всем один эффект или «по очереди». Картинку можно перетащить из папки прямо на слайд или вставить из буфера (скриншот). HTML-файл с анимацией, перетащенный на слайд, становится живой вставкой: скрипты работают, двойной щелчок открывает её код. «Песочница» (галерея блоков → «Интерактив») — код и результат рядом: при показе код правится прямо на слайде. «Сгруппировать» (Ctrl+G) объединяет выделенные объекты: группа двигается, выравнивается и растягивается как один объект; второй клик выделяет объект внутри группы — его можно перекрасить, поправить текст и подвинуть, Esc возвращает к группе. «Разгруппировать» (Ctrl+Shift+G) разбирает группу обратно, а также карточку, панель, сетку, числа или импортированную вёрстку на отдельные фигуры, тексты и картинки на тех же местах — каждую часть можно двигать отдельно; графики и схемы рисуются целиком и не разбираются. «Формат по образцу» (кисть на «Главной») переносит оформление выделенного объекта на тот, по которому щёлкнете; двойной щелчок по кисти — на несколько объектов подряд, Esc — выключить. Объект того же типа получает всё оформление, другого — оформление основного текста. Правый клик — меню объекта |
| Справа | Свойства; редкие разделы (анимация, кадр картинки, состав, дополнительно) свёрнуты и запоминают, что вы развернули. Ничего не выделено: поля шаблона слайда (заголовок, подзаголовок, ссылка и QR-код, кнопки с иконками…), фон холста из готовых вариантов или свой цвет, объекты слайда в порядке появления (эффект у каждого, «раньше / позже», «все по очереди»), название и цвет презентации. Выделен блок: его содержимое — форма по типу блока (пункты списка, чипы, ячейки панели, строки «ключ — значение», значения графиков, шаги, картинка и кадр…), для свободного объекта ещё X, Y, ширина, высота, выравнивание, анимация появления, порядок; CSS блока в «Дополнительно» |
| Лента «Вставка» → «Блоки» | Библиотека готовых блоков с живыми превью: тексты, фигуры (прямоугольник, капсула, круг, линия, стрелка), числа, таблицы (линии, зебра, сетка, акцентная шапка, сравнение), графики, карточки, схемы, картинки. Блок встаёт в центр слайда и сразу выделен |
| Вкладка «Код» (Ctrl+\`) | Код текущего слайда в YAML, как в `deck.yaml`, и стили презентации (CSS) рядом со слайдом. Правки применяются сами, как только текст корректен; ошибка — с номером строки. Над кодом — «Объекты слайда»: дерево блоков (раскладка, свободные объекты, вложенные карточки и группы) с путём в YAML. Клик по узлу выделяет объект на слайде и подсвечивает его строки в коде; выделили объект на слайде — дерево и код переходят к нему; курсор в коде обводит объект под ним. Дерево сворачивается |
| Над слайдом | Путь к выделенному: «Слайд 4 › Сетка › Плитка». При наведении показывает, что под курсором; клик по звену выделяет внешний блок. Esc — на уровень выше |
| Раздел «Состав» | У выделенного блока — его части: вложенные блоки и поля с текстом. Наведение подсвечивает часть на слайде, клик выделяет блок или начинает правку текста |
| Снизу | Заметки докладчика, номер слайда, масштаб (Ctrl + колесо, «Вписать») |
| Границы панелей | Ленту слайдов, панель свойств, заметки и код можно растянуть мышью (или стрелками на выделенной границе), двойной клик — как было; лента сворачивается кнопкой у вкладок или Ctrl+F1. Раскладка запоминается |

| Клавиши | Действие |
|---|---|
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+C / Ctrl+X / Ctrl+V | Копировать, вырезать, вставить объекты; без выделения — слайд. Вставка на тот же слайд — со сдвигом, на другой — на то же место. Текст и картинки из других программ вставляются новым объектом |
| Shift+клик, Ctrl+A | Добавить объект к выделению; выделить все свободные объекты слайда |
| Ctrl+S | Сохранить сразу (иначе правки пишутся в `deck.yaml` сами) |
| Ctrl+M | Новый слайд |
| Ctrl+D | Дублировать объект, без выделения — слайд |
| Ctrl+Shift+C / Ctrl+Shift+V | Копировать / вставить оформление объекта |
| Delete | Удалить объект; в ленте миниатюр — слайд |
| Ctrl+\` | Показать или скрыть код слайда |
| Ctrl+Enter | В коде — применить сразу |
| Стрелки | Объект выделен — сдвиг на 1 px (Shift — 10 px), иначе — соседний слайд |
| Alt + ↑ ↓ | В ленте миниатюр — переставить слайд |
| F5 / Shift+F5 | Показ с начала / с текущего слайда |
| Esc | Снять выделение, остановить просмотр анимации |

Правки сохраняются туда же, куда и в режиме правки: в `deck.yaml` и `assets/`. Код студии в собранный файл не попадает: там остаётся быстрый режим правки (клавиша E).

## Три способа сделать презентацию

| Способ | Когда подходит | Руководство |
|---|---|---|
| **Claude Design → импорт** | Хочется рисовать каркас мышью | [docs/CLAUDE-DESIGN.md](docs/CLAUDE-DESIGN.md) |
| **Свой HTML → импорт** | Презентацию верстает Claude в чате (или вы сами), хочется сразу видеть результат в браузере | [docs/HTML.md](docs/HTML.md) |
| **Сразу deck.yaml** | Презентацию будут долго поддерживать: схемы, графики, таблицы — родными компонентами | [docs/COMPONENTS.md](docs/COMPONENTS.md#промпт-для-claude) |

В каждом руководстве есть готовый промпт для Claude.

Первые два способа заканчиваются импортом. Запустите `yarn dev` и перетащите HTML-файл на страницу (или «Все слайды» → «Импорт…»). Окно покажет, что получится, и предложит привязать цвета к теме, чтобы работали тёмная тема и смена акцента. В терминале то же самое: `yarn merge-html файл.html имя`.

После импорта каждый слайд — холст (`template: canvas`). Вёрстка хранится как есть (`type: html`), а её тексты и картинки вынесены в поля `texts` и `images`, поэтому правятся на месте. Отдельные элементы — свободные объекты: их можно двигать, растягивать, удалять и дублировать. Анимации на JavaScript становятся «живыми» вставками (`type: embed`). Картинки уменьшаются до нужного размера и сжимаются в WebP. Одинаковые картинки не дублируются ни в `assets/`, ни в собранном файле. Подробности — в [справочнике](docs/COMPONENTS.md#готовая-вёрстка).

Третий способ даёт полностью «родные» слайды: как титул, «Что получилось», «Оборудование» и финалы в `presentations/microclimate`. Остальные её слайды импортированы из Claude Design и артефакта — пример смешанной презентации.

### Из PowerPoint

Перетащите файл `.pptx` на страницу (или «Все слайды» → «Импорт…», в приложении — карточка «Импорт»). Окно покажет, сколько будет слайдов и что стоит проверить; имя папки можно поменять. В терминале: `yarn import-pptx файл.pptx имя`.

Каждый слайд становится холстом (`template: canvas`), объекты стоят там же, где в PowerPoint, и правятся в студии:

- надписи и тексты в фигурах — текстом с размером, цветом, шрифтом, жирным и курсивом, выравниванием и отступами; списки — списками;
- простые фигуры (прямоугольник, скругление, овал, линии и стрелки) — фигурами Slideria; сложные, с градиентом и группы из фигур — картинкой SVG на своём месте;
- картинки — с обрезкой, как на слайде; таблицы — таблицами со своими цветами (`colors`); диаграммы — столбцами или линией с теми же данными;
- фон, заметки докладчика, переходы, тема и шрифты из образца и макетов (фигуры образца закреплены, чтобы не мешали правке);
- объекты за краем слайда не переносятся.

Что не переносится: анимации PowerPoint, SmartArt без запасной картинки, текст по кривой (WordArt), видео и звук. Такие места перечислены в отчёте.

### Живые слайды: любой HTML как есть

В окне импорта можно выбрать, какими будут слайды:

| | Редактируемые | Живые |
|---|---|---|
| Как выглядят | Почти 1:1 | 1:1, это сам исходный файл |
| Скрипты файла (наведение, параллакс, калькуляторы) | Не работают, кроме CSS-наведения и связанной подсветки | Работают |
| Правка текстов и картинок на месте | Да | Нет. Слайд можно удалить, переставить, дублировать, написать заметки. Кнопка «Сделать редактируемым» превращает его в обычный |
| Тёмная тема и акцент | Да | Если файл сам их поддерживает (`data-theme`, переменные `var(--ac)`) |
| Какие файлы | Claude Design, свой HTML, артефакты | Любые |

Живой слайд показывает исходный файл в изолированной рамке, только нужный слайд. Кнопки, счётчики и чужая навигация скрыты, листание — клавишами и кнопками проекта. Файл хранится в презентации один раз. В миниатюрах и при печати видна обычная копия слайда (или заглушка с названием, если файл незнаком).

Если формат файла не распознан, импорт сам предложит живые слайды: так открывается любой HTML. Слайды находятся по типичным признакам (`section.slide`, reveal.js и похожие), в крайнем случае вся страница становится одним слайдом. В терминале: `yarn merge-html файл.html имя --live`.

## Импорт правок из HTML-файла

Сценарий: собрали `dist/microclimate.html`, отправили коллеге, он поправил текст и картинки прямо в браузере и прислал файл обратно. Правки переносятся в `deck.yaml` одним из способов:

- **в `yarn dev`** — перетащите файл на страницу (или «Все слайды» → «Импорт…»). Откроется окно: какие слайды изменены, добавлены, удалены, какие появятся картинки. «Импортировать» — записать, «Отмена» — ничего не трогать;
- **в терминале** — `yarn merge-html ~/Downloads/microclimate.html`. С `--dry-run` только покажет отчёт. Вторым аргументом можно указать другую презентацию: `yarn merge-html файл.html copy` создаст `presentations/copy`.

Как это работает:

- **Слияние, а не замена.** Собранный файл помнит версию проекта, из которой его собрали. Поэтому сохраняются и правки из файла, и то, что вы успели поменять в проекте после сборки: новый слайд в `deck.yaml` не пропадёт из-за правки текста в файле. Слайды сопоставляются по `id`.
- **Конфликты.** Если одно и то же поле поменяли и там, и там, берётся версия из файла, а место показывается в отчёте.
- **Резервная копия.** Перед записью прежний `deck.yaml` копируется в `presentations/<имя>/.backup/` (папка не попадает в git).
- **Картинки** из файла кладутся в `assets/`. Одинаковые картинки не дублируются: логотип останется `logo.svg`.
- **Комментарии и оформление** `deck.yaml` сохраняются, как и при правке в `yarn dev`.
- Файл, собранный из другой презентации или старой версией движка без исходной версии, тоже импортируется: данные файла заменят данные проекта (отчёт предупредит). Если презентации с таким именем нет, она будет создана.

## Как править презентацию в deck.yaml

Всё содержимое лежит в `presentations/microclimate/deck.yaml`:

```yaml
- id: firmware
  title: Прошивка и удалённая настройка
  body:
    type: grid
    columns: 1fr 1fr
    items:
      - type: card
        title: Обновление по воздуху
        body:
          - type: progress
            label: Версия 1.4.2
            value: 24 из 24 устройств
            percent: 100
  notes: Текст для окна докладчика.
  backdrop: particles   # анимированный фон: particles, aurora, grid
```

- **Порядок слайдов** — порядок в списке `slides`.
- **Шаблон слайда** — поле `template`: `content` (по умолчанию), `cover`, `finale`, `space`.
- **Тело слайда** — `body`: один блок или список блоков сверху вниз.
- **Картинки** — положите файл в `presentations/<имя>/assets/` и укажите путь: `image: ./assets/photo.jpg`. При сборке картинка встроится в HTML.
- **Чипы**: `[Go*, REST API]`. Звёздочка в конце выделяет чип цветом.
- **Оформление внутри текста**: `**жирный**`, `*курсив*`, `__подчёркнутый__`, `[ссылка](https://…)`, `{#DC2626|цветной}`, строки с `- ` — список. Размер, цвет и выравнивание поля — в `styles` (см. [справочник](docs/COMPONENTS.md#оформление-текста)).
- **Акцентный цвет** — в начале файла:

  ```yaml
  theme:
    accent: "#16A34A"
  ```

Все компоненты и их поля описаны в [docs/COMPONENTS.md](docs/COMPONENTS.md). Если в данных ошибка (не закрыта кавычка, неизвестный компонент), `yarn dev` покажет её на странице с номером строки.

## Как добавить свой компонент

1. Создайте папку `src/components/my-thing/` с файлами `my-thing.ts` и `my-thing.css`.
2. Зарегистрируйте компонент:

```ts
import { defineBlock } from '../../engine/component';
import { t } from '../../engine/html';
import type { Block } from '../../types';
import './my-thing.css';

interface Props extends Block {
  title: string;
  value: number;
}

defineBlock<Props>('big-number', {
  // Разметка должна быть самодостаточной: из неё же строятся миниатюры и печать
  render(p) {
    return `<div class="big-number r"><b>${t(p.value)}</b><span>${t(p.title)}</span></div>`;
  },
  // Необязательно: интерактивность после вставки в страницу
  mount(el) {
    el.addEventListener('click', () => el.classList.toggle('active'));
  },
});
```

3. Добавьте `import './my-thing/my-thing';` в `src/components/index.ts`.
4. Используйте в любой презентации: `- type: big-number`.
5. Чтобы блок правился формой в студии и был в библиотеке, опишите его поля в `src/studio/schema.ts` (`BLOCKS['big-number'] = { fields: [{ k: 'value', label: 'Число', type: 'text' }] }`) и добавьте заготовку в `src/studio/library.ts`.

Соглашения:
- цвета только через переменные темы (`var(--ac)`, `var(--surf)`, `var(--tx)`…) из `src/styles/tokens.css`, тогда тёмная тема заработает сама;
- класс `r` на элементе — появление с задержкой по очереди при открытии слайда;
- анимации, которые должны запускаться при открытии слайда, пишите через `.slide.on .ваш-класс { animation: … }`;
- текст из данных выводите через `t()` (экранирование и `**жирный**`), атрибуты — через `esc()`;
- чтобы текст правился в режиме правки, добавьте элементу метку из `src/engine/marks.ts`: `<b${ea(p, 'title')}>${t(p.title)}</b>`. Для картинки — `eimg(p, 'src')`, для ссылки — `eurl(p, 'url')`, для списка чипов — `chips(p.items)`. Метка знает, где значение лежит в `deck.yaml`, остальное редактор сделает сам.

# HTMLPPTX — презентации как данные

Движок HTML-презентаций. Слайды описываются в YAML-файле, внешний вид задают компоненты, а на выходе получается **один HTML-файл**. Он открывается без интернета, его можно отправить по почте, и в нём работают темы, анимации и режим докладчика.

Проект состоит из трёх частей:

| Часть | Где лежит | Что это |
|---|---|---|
| Движок | `src/engine` | Показ, темы, обзор слайдов, режим докладчика, навигация, печать |
| Компоненты | `src/components` | Кирпичики слайдов: схема сети, пайплайн, графики, финальные слайды… |
| Презентации | `presentations/<имя>/deck.yaml` | Только тексты и данные, без стилей и кода |

## Быстрый старт

Нужен Node.js 18 или новее (рекомендуется 20+) и yarn (`npm i -g yarn`).

```bash
yarn            # установить зависимости (один раз)
yarn dev        # мастерская: откроется браузер, правки deck.yaml видны сразу
yarn build      # собрать все презентации в dist/<имя>.html
```

Вместо yarn можно использовать npm: `npm install`, `npm run dev`, `npm run build`.

| Команда | Что делает |
|---|---|
| `yarn dev` | Локальный сервер с живым обновлением. Если презентаций несколько, покажет список |
| `yarn build` | Все презентации → `dist/<имя>.html` |
| `yarn build microclimate` | Только одна презентация |
| `yarn new q3-report "Итоги квартала"` | Новая презентация из шаблона `templates/basic` |
| `yarn verify` | Проверка типов и сборка: запускать после правок кода компонентов |

## Во время показа

| Клавиша | Действие |
|---|---|
| → ↓ Пробел PageDown | Следующий слайд |
| ← ↑ PageUp Backspace | Предыдущий слайд |
| Home / End | Первый / последний слайд |
| Номер + Enter | Перейти к слайду, например `5` Enter |
| O | Обзор всех слайдов с миниатюрами (Esc — закрыть) |
| P | Окно докладчика |
| F | Во весь экран |
| T | Светлая / тёмная тема |
| B или . | Чёрный экран |

Буквенные клавиши работают и в русской раскладке. На телефоне и планшете слайды листаются свайпом. Номер слайда хранится в адресе (`…/microclimate.html#4`), поэтому после перезагрузки показ продолжается с того же места.

**Тема.** По умолчанию берётся из настроек системы. Выбор кнопкой запоминается в браузере. «Космический» финальный слайд всегда тёмный.

**Режим докладчика.** Клавиша P открывает второе окно. В нём текущий слайд, следующий слайд, заметки из поля `notes`, таймер с паузой и часы. Листать можно в любом из двух окон, они синхронизированы. Тема и чёрный экран тоже передаются между окнами. Работает и в собранном файле, открытом с диска.

**PDF.** Откройте презентацию, нажмите Ctrl+P (⌘P) и выберите «Сохранить как PDF». Каждый слайд окажется на отдельной странице 16:9, анимации будут в конечном состоянии.

## Как править презентацию

Всё содержимое лежит в `presentations/microclimate/deck.yaml`:

```yaml
- id: firmware
  title: Прошивка и удалённая настройка
  body:
    type: grid
    columns: 1fr 1fr
    items:
      - type: card
        title: Обновление по воздуху
        body:
          - type: progress
            label: Версия 1.4.2
            value: 24 из 24 устройств
            percent: 100
  notes: Текст для окна докладчика.
```

- **Порядок слайдов** — порядок в списке `slides`.
- **Шаблон слайда** — поле `template`: `content` (по умолчанию), `cover`, `finale`, `space`.
- **Тело слайда** — `body`: один блок или список блоков сверху вниз.
- **Картинки** — положите файл в `presentations/<имя>/assets/` и укажите путь: `image: ./assets/photo.jpg`. При сборке картинка встроится в HTML.
- **Чипы**: `[Go*, REST API]`. Звёздочка в конце выделяет чип цветом.
- **Жирный текст**: `**так**`.

Все компоненты и их поля описаны в [docs/COMPONENTS.md](docs/COMPONENTS.md). Если в данных ошибка (не закрыта кавычка, неизвестный компонент), `yarn dev` покажет её на странице с номером строки.

## Как добавить свой компонент

1. Создайте папку `src/components/my-thing/` с файлами `my-thing.ts` и `my-thing.css`.
2. Зарегистрируйте компонент:

```ts
import { defineBlock } from '../../engine/component';
import { t } from '../../engine/html';
import type { Block } from '../../types';
import './my-thing.css';

interface Props extends Block {
  title: string;
  value: number;
}

defineBlock<Props>('big-number', {
  // Разметка должна быть самодостаточной: из неё же строятся миниатюры и печать
  render(p) {
    return `<div class="big-number r"><b>${t(p.value)}</b><span>${t(p.title)}</span></div>`;
  },
  // Необязательно: интерактивность после вставки в страницу
  mount(el) {
    el.addEventListener('click', () => el.classList.toggle('active'));
  },
});
```

3. Добавьте `import './my-thing/my-thing';` в `src/components/index.ts`.
4. Используйте в любой презентации: `- type: big-number`.

Соглашения:
- цвета только через переменные темы (`var(--ac)`, `var(--surf)`, `var(--tx)`…) из `src/styles/tokens.css`, тогда тёмная тема заработает сама;
- класс `r` на элементе — появление с задержкой по очереди при открытии слайда;
- анимации, которые должны запускаться при открытии слайда, пишите через `.slide.on .ваш-класс { animation: … }`;
- текст из данных выводите через `t()` (экранирование и `**жирный**`), атрибуты — через `esc()`.

## Структура

```
presentations/
  microclimate/
    deck.yaml          презентация: тексты, данные, заметки
    assets/logo.svg    картинки этой презентации
templates/basic/       шаблон для yarn new
src/
  engine/              движок: показ, обзор, докладчик, темы, синхронизация окон
  components/          компоненты и шаблоны слайдов
  styles/              токены темы, базовые стили, интерфейс, печать
plugins/decks.ts       загрузка YAML и сборка презентаций
scripts/               yarn build, yarn new
docs/COMPONENTS.md     справочник компонентов
```

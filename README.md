# Slideria — презентации как данные

Движок HTML-презентаций. Слайды описываются в YAML-файле, внешний вид задают компоненты, а на выходе получается **один HTML-файл**. Он открывается без интернета, его можно отправить по почте, и в нём работают темы, анимации и режим докладчика.

Проект состоит из трёх частей:

| Часть | Где лежит | Что это |
|---|---|---|
| Движок | `src/engine` | Показ, темы, обзор слайдов, режим докладчика, режим правки, навигация, печать |
| Компоненты | `src/components` | Кирпичики слайдов: схема сети, пайплайн, графики, финальные слайды… |
| Презентации | `presentations/<имя>/deck.yaml` | Только тексты и данные, без стилей и кода |

## Быстрый старт

Нужен Node.js 18 или новее (рекомендуется 20+) и yarn (`npm i -g yarn`).

```bash
yarn            # установить зависимости (один раз)
yarn dev        # мастерская: откроется браузер, правки deck.yaml видны сразу
yarn build      # собрать все презентации в dist/<имя>.html
```

Вместо yarn можно использовать npm: `npm install`, `npm run dev`, `npm run build`.

| Команда | Что делает |
|---|---|
| `yarn dev` | Локальный сервер с живым обновлением. Если презентаций несколько, откроется страница выбора: миниатюры, импорт HTML и PowerPoint, подсказка про новую презентацию, удаление (папка уходит в `presentations/.trash/`, её можно вернуть). Из презентации туда ведёт «Все слайды» → «Все презентации» |
| `yarn build` | Все презентации → `dist/<имя>.html` |
| `yarn build microclimate` | Только одна презентация |
| `yarn build microclimate --clean` | «Для показа»: тот же файл без режима правки → `dist/microclimate.show.html` |
| `yarn build memes --compact` | Картинки сжаты в WebP (GIF — в анимированный WebP): файл заметно меньше, видео и модели как есть |
| `yarn build memes --look=dark --motion` | «Как на этом компьютере»: файл открывается с тёмными (`--look=light` — светлыми) слайдами, а не как в системе зрителя, и показывает анимации, даже если там включено «Уменьшить движение» |
| `yarn present microclimate` | Показ с пультом на телефоне: собрать и раздать в локальной сети (нажмите R в показе — будет QR) |
| `yarn new q3-report "Итоги квартала"` | Новая презентация из шаблона `templates/basic`: 29 слайдов — титул, путеводитель по студии и примеры — графики, схемы, анимация по щелчку, морф, формулы, интерактив, темы. На слайдах с возможностями внизу — «Как сделать»: что нажать, чтобы получить так же |
| `yarn merge-html файл.html [имя]` | Импорт HTML: экспорт Claude Design, свой HTML по [правилам](docs/HTML.md) или правки из собранного файла. `--dry-run` — только показать, что изменится, `--no-theme` — не привязывать цвета к теме |
| `yarn import-pptx файл.pptx [имя]` | Импорт PowerPoint: новая презентация, каждый слайд — холст с объектами на своих местах. `--dry-run` — только отчёт, `--themes` — под темы Slideria (цвета и шрифты меняются вместе с темой) |
| `yarn bind-theme имя` | Привязать цвета импортированной вёрстки к теме (тёмная тема, смена акцента) |
| `yarn verify` | Проверка типов и сборка: запускать после правок кода компонентов |
| `yarn test` | Автотесты: показ, правка, экспорт, студия, приложение (см. «Автотесты») |
| `yarn licenses` | Лицензии библиотек, которые программа везёт с собой; лицензия вне разрешённого списка (`plugins/licenses.mjs`) — ошибка |

## Приложение для компьютера

То же самое, но отдельной программой — без терминала и браузера. Это Electron: внутри тот же движок
и тот же сервер, что в `yarn dev`, поэтому всё работает одинаково.

```bash
yarn app        # запустить приложение из проекта (для проверки)
yarn app:build  # установщик для Windows → dist-app/Slideria Setup <версия>.exe
```

- Презентации лежат в **Документы/Slideria** — по папке на презентацию, как в `presentations/`.
  При первом запуске там появляется «Моя первая презентация» — путеводитель по Slideria: студия, свои блоки, интерактив, оформление, пульт и примеры по разделам. Меню (Alt) → «Файл» → «Папка с презентациями».
- Пульт с телефона: в показе нажмите **R** — появится QR. Только в этот момент приложение открывает
  вход в локальной сети, и через него виден лишь показ этой презентации: другие презентации
  и правка с телефона недоступны. В первый раз Windows сама спросит, разрешить ли Slideria
  доступ к сети, — нажмите «Разрешить». Если там нажали «Отмена» или сеть «общественная»,
  в окне с QR есть кнопка «Разрешить в брандмауэре»: правило для Slideria (порты 5180–5199,
  только локальная сеть) добавляется после подтверждения администратора.
- Библиотека шрифтов, свои темы, шаблоны, эффекты и образы «Цвет+» (`library/`), кэш и журнал работы — в `%APPDATA%/Slideria` (журнал: меню «Справка»).
- Лицензии: «Инструменты» → «Лицензии» (или меню «Справка» → «Лицензии») — лицензия Slideria, Electron и Chromium, шрифтов комплекта (OFL) и всех библиотек с авторами. `yarn app:build` останавливается, если среди библиотек появилась лицензия вне разрешённого списка (`yarn licenses`). В собранный HTML-файл сами собой попадают авторы и тексты лицензий встроенных в него библиотек и шрифтов комплекта (невидимый блок `#slideria-licenses`); шрифт, который автор не разрешил встраивать, в файл не едет.
- Подпись установщика: сертификат задаётся переменной окружения, и `yarn app:build` подписывает программу
  и установщик — как получить сертификат и проверить подпись, в [docs/SIGNING.md](docs/SIGNING.md).
  Без сертификата установщик собирается неподписанным, и при первом запуске Windows покажет
  «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».
- Защита кода: в установщике не исходники, а сжатый код; загрузчик — в `app.asar`, программа сверяет свои
  файлы с отпечатками и с изменёнными не запускается; предохранители Electron закрывают запуск в роли Node
  и отладчик. Что защищено, а что нет, и как проверить (`yarn test:stage`) — в [docs/PROTECTION.md](docs/PROTECTION.md).
- **Установленная программа — снимок кода на день сборки.** Всё, что добавлено в проект потом, появится
  только в новом установщике (`yarn app:build` → установить поверх). От какого числа программа — внизу
  страницы «Все презентации» и в меню «Справка» («сборка от 10.10.2026 (c071598)»); `yarn app` из проекта — всегда
  свежий код («запуск из проекта»). Перед сборкой установщика стоит прогнать `yarn test` — в нём есть и тест
  самого приложения: запуск, экспорт HTML, PDF и PowerPoint.
- «Экспорт → PDF» в приложении сразу сохраняет файл (окно «Сохранить как», с фонами, лист — размером со
  слайд): системное окно печати Electron не умеет «Сохранить как PDF», поэтому PDF делает сам Electron.
- Код приложения — `desktop/main.mjs`; остальной код общий с `yarn dev`.

## Автотесты

```bash
yarn test        # всё: около 3 минут
yarn test:unit   # быстрые проверки без браузера, секунды
yarn test:e2e    # презентации в браузере: показ, правка, экспорт, студия
yarn test:app    # приложение Electron
yarn test:perf   # скорость студии (листать, тянуть акцент, примерять темы, печатать) и показа (небо «Космоса», анимированные фоны) — время и работа браузера таблицей (только по запросу)
```

Тесты работают на временной копии (`.tmp/test-decks`: стартовый шаблон и витрина slideria) —
`presentations/`, «Документы/Slideria» и данные приложения не трогаются. Браузер на Windows —
установленный Microsoft Edge, качать ничего не нужно; на macOS и Linux один раз:
`npx playwright install chromium`. Упавший тест оставляет в `.tmp/test-results` запись
(`npx playwright show-trace …` покажет его по шагам).

Что проверяется:

| Набор | Что ловит |
|---|---|
| unit | запись в `deck.yaml` не портит комментарии; имена папок латиницей; пульт пересылает сообщения; вход для телефона в приложении пускает только к показываемой презентации |
| e2e · показ | все слайды шаблона и витрины листаются без ошибок; номер слайда в адресе; тема T и картинки для тёмной темы; оглавление-ссылки; ползунок пересчитывает числа, кнопка открывает скрытое; обзор O |
| e2e · правка | текст на слайде → `deck.yaml` (комментарии и пути на месте), Ctrl+Z; загрузка картинки; новая презентация и корзина; чужой сайт не может править; пробный импорт HTML |
| e2e · экспорт | HTML для показа и с правкой открываются с диска без ошибок; PowerPoint — все слайды, заметки, тексты текстом |
| e2e · студия | открывается без ошибок; «Сохранить как шаблон…» → «Мои шаблоны»; меню «Цвет» картинки не закрывает слайд |
| app | первый запуск создаёт «Мою первую презентацию»; экспорт через Electron; вход для телефона |

## Во время показа

| Клавиша | Действие |
|---|---|
| → ↓ Пробел PageDown | Следующий слайд |
| ← ↑ PageUp Backspace | Предыдущий слайд |
| Home / End | Первый / последний слайд |
| Номер + Enter | Перейти к слайду, например `5` Enter |
| O | Обзор всех слайдов с миниатюрами (Esc — закрыть) |
| P | Окно докладчика |
| R | Пульт с телефона: QR для подключения |
| F | Во весь экран |
| T | Светлая / тёмная тема |
| B или . | Чёрный экран |
| A | Автопоказ: листать само (пауза — ещё раз A) |
| + / − (или Ctrl + / Ctrl −, Ctrl + колесо) | Крупнее / мельче, шагом 2 % (90–110 %) |
| 0 (или Ctrl 0) | Как на слайде |
| E | Режим правки |
| S | В редактор на этом слайде (только `yarn dev`) |

**«Крупнее»** — когда у зрителей мелкий экран. Каждый шаг + — на 2 % крупнее, до 110 %, но содержимое всегда целиком в окне: за край уходят только пустые поля слайда и логотип в углу. Плотному слайду хватает места примерно на 108 %; если слайду больше не помещается, надпись скажет, сколько вышло. Шаги − ниже 100 % (до 90 %) делают слайд мельче окна — когда проектор или телевизор обрезает края экрана. Выбор запоминается в браузере, из окна докладчика те же + − 0 работают у зрителей. **S** из показа, открытого редактором (F5), закрывает окно показа и возвращает в редактор на текущий слайд; иначе редактор открывается в этом же окне.

Буквенные клавиши работают и в русской раскладке. На телефоне и планшете слайды листаются свайпом. Номер слайда хранится в адресе (`…/microclimate.html#4`), поэтому после перезагрузки показ продолжается с того же места.

**Тема.** По умолчанию берётся из настроек системы. Выбор кнопкой запоминается в браузере. «Космический» финальный слайд всегда тёмный.

**Режим докладчика.** Клавиша P (в редакторе — «Режим докладчика», Alt+F5) раскладывает окна по экранам, как PowerPoint: показ уходит во весь экран на проектор, окно докладчика открывается на весь экран у вас. Это делают Chrome и Edge; при первом запуске браузер спросит разрешение «Управление окнами». Проектор должен работать в режиме «Расширить», а не «Повторить» (Windows: Win+P): при повторе экрана зрители увидят и заметки — показ подскажет об этом. В других браузерах окно показа перетаскивают на проектор вручную и нажимают F. Окно докладчика: В нём текущий слайд, следующий слайд, заметки из поля `notes`, таймер с паузой и часы; задан план доклада («Показ → План» в редакторе) — у таймера метка: сколько осталось и запас или отставание. Листать можно в любом из двух окон, они синхронизированы. Границы между текущим слайдом, следующим и заметками перетаскиваются, как в PowerPoint (двойной клик — как было), раскладка запоминается. Под слайдом панель инструментов: указка (L), перо с выбором цвета (D), стереть всё (C), все слайды (G), чёрный экран (B), автопоказ (A) — слайды дальше листаются сами (время слайда — «Показ → Автопоказ» в редакторе, по умолчанию 5 с после анимаций); под панелью — таймлайн слайда: чёрточки — шаги, конец — следующий слайд, справа — сколько ещё; листать руками можно и дальше, ещё раз A — пауза. Всё нарисованное видно зрителям сразу и стирается при смене слайда. Тема и чёрный экран тоже передаются между окнами. Видео на слайде слушается докладчика: запуск, пауза и перемотка в окне докладчика или на телефоне-пульте повторяются у зрителей (при включённом «Мышь и 3D у зрителей», M; ролики YouTube и Vimeo — пока нет). Работает и в собранном файле, открытом с диска.

**Пульт с телефона.** Запустите показ командой `yarn present имя`: она соберёт презентацию и раздаст её в локальной сети, показ откроется сам. Откройте окно докладчика и нажмите в его панели кнопку с телефоном (или **R**) — QR появится у докладчика, зал его не видит. Без второго экрана — клавиша **R** прямо в показе. Наведите на QR камеру телефона. На телефоне откроется режим докладчика этого показа: живой слайд (кнопки, вкладки, ползунки и песочница работают, и зал видит то же), указка, перо и чёрный экран, заметки, таймер, крупные «Назад» и «Далее»; листать можно и свайпом по заметкам (по слайду — нет: там указка и живые объекты). Связь видна внизу: «Связь с окном показа есть»; пропала — внизу плашка с подсказками и кнопкой «Подключиться сейчас» (заметки при этом видны). **QR одноразовый**: подключает один телефон, и каждое открытие окна с QR даёт новый код (прежний гаснет). По коду телефон получает пропуск, и дальше из сети без пропуска не отдаётся ничего — ни страница, ни заметки, ни команды: случайно отсканировавший код зритель, если успел раньше вас, виден в списке и отключается. В том же окне видно, кто подключён, с кнопкой «Отключить»; отключённый телефон (и любой, когда показ закрыт дольше минуты) теряет заметки и слайды и видит «Пульт отключён». Значок с глазом в шапке телефона — «не гасить экран», пока открыт пульт. Экономный режим (кнопка с паузой, включён сразу): после появления слайд на телефоне замирает — анимации, живые вставки и песочница не тратят батарею; касание оживляет его на 8 секунд, связь проверяется реже. Зал при этом видит всё как обычно. Небо «Космоса» и анимированные фоны на телефоне и у зрителей одни и те же: частицы на тех же местах и в той же фазе (общие часы показа), поэтому касаться можно, глядя в телефон. Палец на элементе с наведением даёт наведение и у зрителей, и на самом телефоне. Телефон и компьютер должны быть в одной Wi-Fi (подойдёт и раздача с телефона). Из `yarn dev` пульт тоже работает, если запустить его с `--host` (тогда доступны все презентации); устройства в сети при этом только смотрят и листают — править проект можно лишь с этого компьютера. На Windows `yarn dev --host` брандмауэр только проверяет (без запросов) и, если телефону что-то мешает, подскажет в терминале выполнить `yarn firewall`; `yarn present` при первом запуске сам настроит брандмауэр: разрешит порты 5173–5199 только для устройств локальной сети и выключит запреты для Node, которые Windows создаёт, если в её окне «Разрешить доступ» нажали «Отмена» (один запрос администратора; брандмауэр отключать не нужно, правило «Slideria remote» можно удалить в настройках). `yarn firewall` настраивает то же отдельно, по вашей команде. Файл, открытый с диска, пульт не подключит: ему нужен сервер показа. Запасной способ без Node — `scripts/windows/Показ с пультом.cmd`: положите его рядом с собранной презентацией (или перетащите на него .html) и запустите двойным щелчком — он сам раздаст показ в сети и откроет показ; дальше всё как с `yarn present`. Брандмауэр он сам не трогает: если телефон не открывает страницу, в окне с QR нажмите «Разрешить в брандмауэре» (один запрос администратора).

**Кликер.** Обычная указка-кликер с USB-приёмником притворяется клавиатурой: шлёт PageDown / PageUp, B или «.» — показ понимает их без настройки. Кнопка «старт» (F5) перезагружает страницу, но показ продолжится с того же слайда.

**PDF.** Откройте презентацию, нажмите Ctrl+P (⌘P) и выберите «Сохранить как PDF». Каждый слайд окажется на отдельной странице 16:9, анимации будут в конечном состоянии.

## Режим правки

Кнопка с карандашом справа внизу или клавиша E. Правки видны сразу и работают так:

| Что | Как |
|---|---|
| Текст | Клик по тексту, правка на месте. Enter — новая строка, Esc, Ctrl+Enter или щелчок мимо — готово (правка сохраняется; отменить — Ctrl+Z), Tab — следующее поле |
| Оформление текста | Панель над текстом: шрифт, размер, цвет, жирный, курсив, подчёркнутый (Ctrl+B/I/U), ссылка (Ctrl+K), список, выравнивание, сброс. Цвет с выделением красит только выделенное. Без выделения команда применяется ко всему полю. Ручка справа от текста — ширина поля (где переносятся строки), двойной клик по ней — как было. Список шрифтов — с поиском (стрелки и Enter): после шрифтов темы и презентации — шрифты компьютера; выбранный копируется в презентацию (обычный, жирный, курсив) и на другом компьютере выглядит так же. Рядом — начертание (светлый, полужирный и т. д.) из тех, что есть у шрифта: выбранное тоже копируется. В браузере (Chrome, Edge) список открывается пунктом «Показать шрифты компьютера…» с разрешением; шрифт, который автор не разрешил встраивать (флаг в файле шрифта: запрет или «только просмотр и печать» — презентацию ведь потом правят, как и в PowerPoint), остаётся по имени и виден там, где установлен. Перетащенный файл шрифта с таким флагом не добавляется (студия скажет почему) |
| Картинка, логотип, фото на плитке | Клик — выделение и панель картинки: заменить, «Целиком» (без обрезки) или «Заполнить», масштаб 30–300 %, сдвиг (тяните картинку мышью), × — убрать. Двойной клик или перетаскивание файла — замена. Убранное фото на плитке возвращает исходную иллюстрацию, иначе остаётся пустое место |
| Любой блок (карточка, плитка, график, схема…) | Клик по блоку (не по тексту) — выделение и панель: «Выше» — внешний блок, «Свободно» — открепить от раскладки, корзина или Delete — удалить |
| Свободные объекты | «Вставить» → текст или картинка появляется поверх слайда, на любом слайде. Объект тянется за любое место сразу, без предварительного клика; выделенный блок раскладки, если его потянуть, сам становится свободным. Тяните объект мышью, за 8 ручек — меняйте размер (картинки за угол — пропорционально, Shift — наоборот). Кружок над рамкой — поворот на любой угол, как в PowerPoint (Shift — шагами по 15°, возле 0/90/180° прилипает). Края прилипают к краям и центру слайда и к другим объектам, Alt — без прилипания. Стрелки — сдвиг на 1 px, Shift+стрелки — на 10 px, Ctrl+D — дубликат, кнопки — слой выше или ниже, «В раскладку» — вернуть в поток слайда. Первый клик выделяет объект, второй — правит текст. У свободной картинки кадр сдвигается в режиме «Кадр» (кнопка на панели над картинкой или на вкладке «Рисунок», Esc — готово) или с Alt |
| Ссылка и QR-код | Наведите на ссылку или кнопку → «Изменить ссылку». QR-код перестроится сам |
| Порядок слайдов | «Слайды» или O: перетащите миниатюру. Кнопки на миниатюре — дублировать и удалить. С клавиатуры: Alt + ← →, Delete |
| Новый слайд | В обзоре: «Заголовок и текст», «Три карточки», «Картинка» или «Пустой холст» |
| Заметки докладчика | Кнопка «Заметки»: поле под слайдом |
| Акцентный цвет | Кнопка «Цвет». Оттенки для светлой и тёмной темы строятся сами |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z (⌘ на Mac), до 200 шагов |

Куда сохраняются правки:

- **В `yarn dev`** — сразу в `deck.yaml`, без кнопки. Комментарии и оформление файла сохраняются, меняются только отредактированные строки. Новые картинки кладутся в `assets/`, большие фото уменьшаются до 2400 px по длинной стороне. Если правите `deck.yaml` в редакторе кода, страница обновится сама. Несколько окон одной презентации (студия, окно докладчика, вторая вкладка) не затирают правки друг друга: каждое записывает только то, что поменяло само, и подтягивает чужие правки.
- **В собранном HTML-файле** — кнопка «Сохранить» или Ctrl+S. Chrome и Edge спросят, куда сохранить, и дальше будут записывать в тот же файл. Другие браузеры скачают копию файла с правками. Картинки встраиваются внутрь файла. Сохранённый файл снова открывается и правится. Если закрыть вкладку с несохранёнными правками, браузер предупредит.

Правки, сделанные в собранном файле, можно вернуть в проект — см. следующий раздел.

Окно докладчика получает правки сразу. Через режим правки меняется то, что уже есть на слайдах. Новые поля, другой компонент или раскладку проще задать в `deck.yaml` (или попросить Claude).

## Редактор (студия)

Полноценный редактор в духе PowerPoint. Работает в `yarn dev`: на странице выбора кнопка «Редактор» на карточке презентации, в показе кнопка со слоями справа внизу или адрес `?deck=имя&studio`.

| Часть экрана | Что в ней |
|---|---|
| Шапка | Все презентации, название (правится на месте), вкладки ленты, состояние сохранения, «Экспорт», тема интерфейса, «Показ» с текущего слайда |
| «Экспорт» | Скачать презентацию: **HTML для показа** — один файл без редактора (открыть в браузере, отправить, загрузить в другой сервис); **HTML с правкой** — тот же файл с режимом правки (E), правки возвращаются через импорт; **PowerPoint** — файл PPTX: подложки становятся фигурами, тексты — надписями с тем же оформлением, таблицы — таблицами, столбцы и линии — диаграммами PowerPoint, заметки — заметками докладчика; всё правится в PowerPoint. Принцип: главный формат — HTML, PPTX — лучшее, что умеет PowerPoint, и никогда не ломается. Что PowerPoint умеет — уходит родным объектом (градиенты фигур и выделенных слов — градиентами PowerPoint со всеми точками и прозрачностью); что не умеет (фильтры и тонировка снимков, CSS-эффекты, 3D, сложная вёрстка) — картинкой, как на экране; живое (вставки, песочница, видео-фоны) — заставкой; интерактив (наведение, пульт) — не переносится. Анимации не переносятся, слайды выгружаются в светлой теме; **PDF** — окно печати, слайд на страницу. Галочка **«Как на этом компьютере»** под качеством (включена, запоминается; к обоим HTML): файл открывается в том виде слайдов, светлом или тёмном, что сейчас в студии (T при показе переключает), и показывает анимации, даже если в системе зрителя включено «Уменьшить движение»; без неё вид берётся из системы зрителя. У презентации с постоянным видом слайдов он и так один. Это та же сборка, что `yarn build`, занимает пару секунд. **Качество** сверху меню (запоминается): «Компактное» — файл в 2–3 раза меньше: в HTML картинки сжаты в WebP, GIF — в анимированный WebP (видео и 3D-модели как есть); в PowerPoint фотографии ужаты до размера на слайде, снимки фонов и графики — в JPEG; «Обычное» — картинки как есть, сложная графика в PowerPoint в двойной чёткости; «Высокое» — она же в тройной, для экранов 4K и печати (HTML — как «Обычное»: картинки и так исходные). Тексты, фигуры, таблицы и диаграммы векторные при любом качестве |
| Найти и заменить | Ctrl+F (или «Главная» → «Найти»), замена — Ctrl+H. Ищет по текстам всех слайдов, названию и заметкам (кнопка с заметками включает и выключает их); «Аа» — с учётом регистра, «ab» — только слово целиком. Совпадения подсвечены на слайде, Enter / Shift+Enter (или стрелки) — следующее и предыдущее, блок с совпадением выделяется; под полем — список всех совпадений, щелчок ведёт к месту. Адреса, цвета, код и стили не затрагиваются. «Заменить все» — одна правка: Ctrl+Z откатывает её целиком. Кнопка `</>` или Ctrl+Shift+F — поиск в коде: YAML всех слайдов и стили; щелчок открывает строку во вкладке «Код» (заменяют в самом редакторе кода) |
| «Дизайн»: темы | Тема — оформление всей презентации одним щелчком: цвета слайдов для светлой и тёмной темы, шрифты заголовков и текста, фон, вид карточек и скругление. Все темы — на одном слайде-образце («Все темы»), наведение примеряет тему на открытом слайде, щелчок применяет (Ctrl+Z — вернуть). Шрифты тем свободные, с кириллицей (`src/fonts`, лицензия OFL) и копируются в презентацию. Дальше любую часть можно поменять отдельно: «Градиент» (готовые сочетания и свои точки — до шести цветов, `accentMid`), «Шрифты», «Фон», «Карточки», «Углы», «Логотип» (плашка под логотипом — в цветах темы или в цветах самого логотипа: студия подбирает их по файлу и подбирает заново, если логотип сменили; «В цвет темы» — одноцветный знак перекрашивается градиентом акцентов темы и в тёмном виде, `brand.tint`; «Знак» — размер знака внутри плашки, плашка своего размера не меняет, `brand.mark`), а в «Слайды» — светлые, тёмные или как тема у зрителя. В «Фон» после узоров — свой фон: «Картинка…» (на весь слайд, ползунок «Заметность» — чтобы текст читался) и «Цвет…»; своя тема уносит картинку с собой. У тёмных слайдов фон, карточки и анимация могут быть своими: вверху панелей «Фон», «Карточки» и «Анимация» — «Для всех | Для тёмных» («Для тёмных» включает тёмную тему студии, точка — у тёмных своё, «Как у всех» — убрать своё; `theme.darkLook`). Цвета темы в палитрах заливки, контура и текста — образцы наискось: половина цвета у светлых слайдов, половина у тёмных, видно, что цвет меняется с темой (постоянные цвета — нет). В deck.yaml — `theme:` со всеми значениями, собранный файл от галереи не зависит. У импортированной из PowerPoint — первая плитка «Как в файле»: другая тема перекрашивает цвета и шрифты файла, эта возвращает исходные |
| «Рисунок» → «Цвет+» | Цветокоррекция картинки, как в DaVinci Resolve: температура и оттенок, экспозиция, света и тени, контраст, насыщенность, цветовые круги (тени, полутона, света), кривые, HSL по восьми цветам, 3D LUT (.cube), «В цвета бренда» (карта градиента из акцента презентации), виньетка, зерно и инверсия яркости. Практичные образы: «Чистый белый» (скриншот или скан — серая подложка становится белой), «Тёмная версия» (светлый скриншот для тёмного слайда: светлое — тёмным, цвета остаются), «Светлее» (тёмное фото). «Авто» (A) — экспозиция, точки чёрного и белого, баланс белого по почти серым местам и немного контраста — по самой картинке; скриншот с белым фоном не темнеет. Исходный файл не меняется: результат — новый файл в `assets/` в формате исходника (PNG и WebP не пережимаются в JPEG — снимки экрана остаются чистыми; JPEG — с качеством 95), а в данных картинки (`grade`) — путь к исходнику и параметры; «Сбросить» возвращает исходник. В собранный файл попадает только готовая картинка. Картинку можно разглядывать: колесо — масштаб, перетаскивание — сдвиг, двойной щелчок — 100 %, «Крупно» (F) — только картинка |

| Вкладки «Фигура» и «Таблица» | Появляются, пока выделена фигура или таблица, как «Формат фигуры» и «Макет таблицы» в PowerPoint, но без лишнего. С «Анимации» лента не уходит: вкладка объекта только появляется рядом. Наведение на стиль, форму или цвет (стили фигуры, таблицы и рисунка на ленте, палитры заливки и контура, заливка ячеек, цвет текста) примеряет вариант на самом объекте; увели мышь — как было, щелчок — применить. Фигура: готовые стили (живые образцы в цветах темы), форма, палитра заливки и контура (цвета темы, постоянные цвета, толщина, пунктир), надпись внутри фигуры — размер, жирность, выравнивание по горизонтали и вертикали; «Тень», «Скругление», «Поворот» и «Прозрачность» — плитками на образце фигуры, как галереи «Рисунка»: наведите — вариант примеряется на самой фигуре, щелчок — применить, ползунок ниже — своё значение (скругление, угол, прозрачность). Таблица: шесть стилей и «Заливка» ячеек, флажки «строка заголовка», «строка итогов», «чередующиеся строки», «первый столбец», «последний столбец», «выделить строку»; «Выделить» (строку, столбец, таблицу), вставка строк и столбцов, «Удалить» (строки, столбцы, таблицу), выравнивание по горизонтали и вертикали, ширина поровну, плотность, размер текста. Ячейки — как в PowerPoint: протянуть мышью или Shift+щелчок — диапазон; Backspace очищает ячейки, Delete удаляет выделенные строки или столбцы целиком (часть ячеек — очищает); «Объединить» ячейки и «Разделить» — окно «Разбиение ячеек» (число столбцов и строк, как в PowerPoint; объединение уходит в PowerPoint и приходит из него); правый щелчок в правке текста — «Вырезать», «Копировать», «Вставить» и пункты таблицы; таблицу тянут и по высоте — строки растягиваются; Ctrl+C / Ctrl+V (в том числе из Excel), заливка, вставка и удаление — для всего диапазона; Tab в последней ячейке — новая строка. Таблица из Excel, вставленная на пустое место слайда, становится таблицей. Ширину столбцов и высоту строк тянут мышью за границу прямо на слайде; «Выровнять высоту строк», «Сортировка» по столбцу (строка итогов остаётся внизу). «Границы ▾» (все, внешние, внутренние, нижняя, без границ, как в стиле) и «Плотность» — плитками на мини-таблице, как галереи «Рисунка» и «Фигуры»: наведите — вариант примеряется на самой таблице (границы — на выделенных ячейках), щелчок — применить. На каждой вкладке объекта — «Упорядочить»: «Вперёд ▾» и «Назад ▾» — на шаг (над или под ближайший перекрывающий объект, Ctrl+] / Ctrl+[), в меню стрелки — на передний или задний план (Ctrl+Shift+] / Ctrl+Shift+[) |

| Вкладка «Вставка» | Группы как в PowerPoint: новый слайд; надпись и заготовки текста; картинка и фигуры; таблица, диаграмма, числа, уравнение; схемы и карточки; видео, 3D-модель, интерактив; все блоки. Кнопки со стрелкой открывают свою галерею с живыми миниатюрами |
| «Вставка» → «Уравнение» | Формулы как в PowerPoint: дроби, корни, суммы, интегралы, матрицы, вывод столбиком. Пишутся просто — `x^2`, `(a+b)/c`, `sqrt(x)`, `alpha`, `<=` — или на LaTeX. Двойной щелчок по формуле — поле с записью прямо под ней: слайд меняется на лету, кнопки вставляют дробь, степень, корень, сумму, интеграл. Живые числа `{{m}}`, `{{=m*a}}` берутся из ползунков слайда и пересчитываются при показе. `[[2ab]]` — выделить цветом, `~~3~~` — зачеркнуть («сокращается»). «При показе» в свойствах: по щелчку строка за строкой или превращение — формула перетекает из строки в строку, одинаковые части перелетают; «Далее» сначала открывает шаги, потом листает (и из окна докладчика, и с телефона). У формулы вида `y = a·sin(x)` в правке есть кнопка «График»: рядом встаёт живой график функции — двигаете ползунок, кривая меняется. В PPTX формула — уравнение Office, правится в PowerPoint (картинка остаётся запасной). Шрифт — современный (Fira Math, едет вместе с презентацией) или классический, как в PowerPoint. ## Три способа сделать презентацию

| Способ | Когда подходит | Руководство |
|---|---|---|
| **Claude Design → импорт** | Хочется рисовать каркас мышью | [docs/CLAUDE-DESIGN.md](docs/CLAUDE-DESIGN.md) |
| **Свой HTML → импорт** | Презентацию верстает Claude в чате (или вы сами), хочется сразу видеть результат в браузере | [docs/HTML.md](docs/HTML.md) |
| **Сразу deck.yaml** | Презентацию будут долго поддерживать: схемы, графики, таблицы — родными компонентами | [docs/COMPONENTS.md](docs/COMPONENTS.md#промпт-для-claude), навык для Claude — [docs/skills/slideria-deck](docs/skills/slideria-deck/SKILL.md) |

В каждом руководстве есть готовый промпт для Claude. Навык `slideria-deck` загружается в Claude или кладётся в `.claude/skills/` для Claude Code: Claude сам пишет `deck.yaml` по структуре Slideria. Связки по шагам — слайд «Связки» стартового шаблона.

Первые два способа заканчиваются импортом. Запустите `yarn dev` и перетащите HTML-файл на страницу (или «Все слайды» → «Импорт…»). Окно покажет, что получится, и предложит привязать цвета к теме, чтобы работали тёмная тема и смена акцента. В терминале то же самое: `yarn merge-html файл.html имя`.

После импорта каждый слайд — холст (`template: canvas`). Вёрстка хранится как есть (`type: html`), а её тексты и картинки вынесены в поля `texts` и `images`, поэтому правятся на месте. Отдельные элементы — свободные объекты: их можно двигать, растягивать, удалять и дублировать. Анимации на JavaScript становятся «живыми» вставками (`type: embed`). Картинки уменьшаются до нужного размера и сжимаются в WebP. Одинаковые картинки не дублируются ни в `assets/`, ни в собранном файле. Подробности — в [справочнике](docs/COMPONENTS.md#готовая-вёрстка).

Третий способ даёт полностью «родные» слайды: как титул, «Что получилось», «Оборудование» и финалы в `presentations/microclimate`. Остальные её слайды импортированы из Claude Design и артефакта — пример смешанной презентации.

### Из PowerPoint

Перетащите файл `.pptx` на страницу (или «Все слайды» → «Импорт…», в приложении — карточка «Импорт»). Окно покажет, сколько будет слайдов и что стоит проверить; имя папки и оформление («Как в файле» или «Под темы Slideria», см. ниже) можно поменять. В терминале: `yarn import-pptx файл.pptx имя`.

Каждый слайд становится холстом (`template: canvas`), объекты стоят там же, где в PowerPoint, и правятся в студии:

- надписи и тексты в фигурах — текстом с размером, цветом, шрифтом, жирным, курсивом и подчёркиванием, выравниванием, отступами и интервалами между абзацами; фрагменты другого размера в строке — разметкой `{s:80|…}`; текст с градиентом — градиентом со всеми точками и направлением (`{g:…|…}`), а не первым цветом; списки — списками со своим маркером и его цветом;
- простые фигуры (прямоугольник, скругление, овал, линии и стрелки) — фигурами Slideria; остальные — все 187 стандартных фигур PowerPoint по их определениям из стандарта (ECMA-376), с градиентами, затенёнными частями и группами — картинкой SVG на своём месте; повёрнутые и отражённые группы — как в файле;
- картинки — с обрезкой, прозрачностью, отражением и прямыми углами, как на слайде; таблицы — таблицами со стилем таблицы из файла (шапка, полосы, крайние строки и столбцы; «Средний стиль 2» PowerPoint — встроенный), заливкой и линиями ячеек, высотами строк (пустая ячейка — по размеру конца абзаца, как в PowerPoint), полями, выравниванием и шрифтом столбцов (`columns`); диаграммы — столбцами или линией с теми же данными;
- фон, заметки докладчика, переходы, тема и шрифты из образца и макетов (фигуры образца закреплены, чтобы не мешали правке); заливка, контур и форма заготовок — от макета и образца;
- текст по середине и по низу рамки остаётся там же, лишний уходит вверх, как в PowerPoint; межстрочный интервал — по метрикам шрифта, как в PowerPoint; автоподгонка («Сжать текст при переполнении») уменьшает и размер, и интервал, как в файле; шрифта нет на компьютере — берётся замена с теми же размерами букв (Arimo ↔ Arial, Calibri ↔ Carlito, Cambria ↔ Caladea, Times New Roman ↔ Tinos, Verdana → DejaVu Sans), иначе Arial, и строки переносятся почти там же;
- объекты за краем слайда не переносятся.

Что не переносится: анимации PowerPoint, SmartArt без запасной картинки, текст по кривой (WordArt), видео и звук. Такие места перечислены в отчёте. Сверка — по эталону LibreOffice: все слайды двух шаблонов (Google Slides и PowerPoint) рядом с оригиналом.

**Своя тема поверх чужой презентации.** В окне импорта — «Оформление»: **Как в файле** (по умолчанию) — точная копия, цвета и шрифты записаны как есть и темы их не меняют; **Под темы Slideria** (`yarn import-pptx файл.pptx --themes`) — импорт запоминает оформление файла: фон и текст (какие на слайдах на самом деле, а не в схеме темы), акценты (семейства цветных оттенков по частоте) и шрифты заголовков и текста — это тема «Как в файле», первая на ленте «Дизайн». Любая другая тема перекрашивает слайды файла в свои цвета: серые — по оси «фон — текст» темы, цветные — в её акценты; светлота сохраняется, поэтому светлое на тёмном остаётся читаемым и в тёмном виде слайдов. Шрифты меняются на шрифты темы, фон слайдов — на её фон с узором и анимацией. «Как в файле» возвращает исходный вид точь-в-точь. Картинки не перекрашиваются. Картинка фоном на весь слайд (из образца, макета или самого слайда) и узоры образца — полупрозрачные или крупные картинки — видны только в теме «Как в файле» (`fileBg: true`), логотипы остаются; под ней записан её средний тон, и в другой теме слайд получает этот тон, перекрашенный вместе с текстом, — титульные и финальные слайды тоже меняют цвета. Палитра файла хранится в `origin` в `deck.yaml`.

### Живые слайды: любой HTML как есть

В окне импорта можно выбрать, какими будут слайды:

| | Редактируемые | Живые |
|---|---|---|
| Как выглядят | Почти 1:1 | 1:1, это сам исходный файл |
| Скрипты файла (наведение, параллакс, калькуляторы) | Не работают, кроме CSS-наведения и связанной подсветки | Работают |
| Правка текстов и картинок на месте | Да | Нет. Слайд можно удалить, переставить, дублировать, написать заметки. Кнопка «Сделать редактируемым» превращает его в обычный |
| Тёмная тема и акцент | Да | Если файл сам их поддерживает (`data-theme`, переменные `var(--ac)`) |
| Какие файлы | Claude Design, свой HTML, артефакты | Любые |
| Микрофон и звук вкладки (аудиовизуализаторы) | — | В студии и приложении — с вопросом о разрешении; в собранном файле и на телефоне — без звука ([подробнее](docs/PERMISSIONS.md)) |

Живой слайд показывает исходный файл в изолированной рамке, только нужный слайд. Кнопки, счётчики и чужая навигация скрыты, листание — клавишами и кнопками проекта. Файл хранится в презентации один раз. В миниатюрах и при печати видна обычная копия слайда (или заглушка с названием, если файл незнаком).

Если формат файла не распознан, импорт сам предложит живые слайды: так открывается любой HTML. Слайды находятся по типичным признакам (`section.slide`, reveal.js и похожие), в крайнем случае вся страница становится одним слайдом. В терминале: `yarn merge-html файл.html имя --live`.

## Импорт правок из HTML-файла

Сценарий: собрали `dist/microclimate.html`, отправили коллеге, он поправил текст и картинки прямо в браузере и прислал файл обратно. Правки переносятся в `deck.yaml` одним из способов:

- **в `yarn dev`** — перетащите файл на страницу (или «Все слайды» → «Импорт…»). Откроется окно: какие слайды изменены, добавлены, удалены, какие появятся картинки. «Импортировать» — записать, «Отмена» — ничего не трогать;
- **в терминале** — `yarn merge-html ~/Downloads/microclimate.html`. С `--dry-run` только покажет отчёт. Вторым аргументом можно указать другую презентацию: `yarn merge-html файл.html copy` создаст `presentations/copy`.

Как это работает:

- **Слияние, а не замена.** Собранный файл помнит версию проекта, из которой его собрали. Поэтому сохраняются и правки из файла, и то, что вы успели поменять в проекте после сборки: новый слайд в `deck.yaml` не пропадёт из-за правки текста в файле. Слайды сопоставляются по `id`.
- **Конфликты.** Если одно и то же поле поменяли и там, и там, берётся версия из файла, а место показывается в отчёте.
- **Резервная копия.** Перед записью прежний `deck.yaml` копируется в `presentations/<имя>/.backup/` (папка не попадает в git).
- **Картинки** из файла кладутся в `assets/`. Одинаковые картинки не дублируются: логотип останется `logo.svg`.
- **Комментарии и оформление** `deck.yaml` сохраняются, как и при правке в `yarn dev`.
- Файл, собранный из другой презентации или старой версией движка без исходной версии, тоже импортируется: данные файла заменят данные проекта (отчёт предупредит). Если презентации с таким именем нет, она будет создана.

## Как править презентацию в deck.yaml

Всё содержимое лежит в `presentations/microclimate/deck.yaml`:

```yaml
- id: firmware
  title: Прошивка и удалённая настройка
  body:
    type: grid
    columns: 1fr 1fr
    items:
      - type: card
        title: Обновление по воздуху
        body:
          - type: progress
            label: Версия 1.4.2
            value: 24 из 24 устройств
            percent: 100
  notes: Текст для окна докладчика.
  backdrop: particles   # анимированный фон: mesh, aurora, silk, waves, topo, field, rays, bokeh, particles, stars, snow, leaves, petals, bubbles, hearts, confetti, caustics, ripples, plankton, pulse, dots, halftone, origami, dither, network, hex, orbits, radar, cymatics, dna, growth, candles, spectrum, grid, retrosun, globe, terrain, tunnel, lava; none — без фона темы
  backdropOpacity: 0.6  # заметность анимированного фона, 0.1–1 (у слайда — своя)
  backdropSpeed: 1.5    # скорость, 0.25–3
  backdropTouch: false  # фон не отвечает на мышь и щелчки (у «Сети»; так же у темы — для всех слайдов)
```

- **Порядок слайдов** — порядок в списке `slides`.
- **Шаблон слайда** — поле `template`: `content` (по умолчанию), `cover`, `finale`, `space`.
- **Тело слайда** — `body`: один блок или список блоков сверху вниз.
- **Картинки** — положите файл в `presentations/<имя>/assets/` и укажите путь: `image: ./assets/photo.jpg`. При сборке картинка встроится в HTML.
- **Чипы**: `[Go*, REST API]`. Звёздочка в конце выделяет чип цветом.
- **Оформление внутри текста**: `**жирный**`, `*курсив*`, `__подчёркнутый__`, `[ссылка](https://…)`, `{#DC2626|цветной}`, `{g:#F97316,#EC4899@40,#7C3AED|с градиентом}`, строки с `- ` — список. Размер, цвет и выравнивание поля — в `styles` (см. [справочник](docs/COMPONENTS.md#оформление-текста)).
- **Акцентный цвет** — в начале файла:

  ```yaml
  theme:
    accent: "#16A34A"
  ```

Все компоненты и их поля описаны в [docs/COMPONENTS.md](docs/COMPONENTS.md). Если в данных ошибка (не закрыта кавычка, неизвестный компонент), `yarn dev` покажет её на странице с номером строки.

## Как добавить свой компонент

1. Создайте папку `src/components/my-thing/` с файлами `my-thing.ts` и `my-thing.css`.
2. Зарегистрируйте компонент:

```ts
import { defineBlock } from '../../engine/component';
import { t } from '../../engine/html';
import type { Block } from '../../types';
import './my-thing.css';

interface Props extends Block {
  title: string;
  value: number;
}

defineBlock<Props>('big-number', {
  // Разметка должна быть самодостаточной: из неё же строятся миниатюры и печать
  render(p) {
    return `<div class="big-number r"><b>${t(p.value)}</b><span>${t(p.title)}</span></div>`;
  },
  // Необязательно: интерактивность после вставки в страницу
  mount(el) {
    el.addEventListener('click', () => el.classList.toggle('active'));
  },
});
```

3. Добавьте `import './my-thing/my-thing';` в `src/components/index.ts`.
4. Используйте в любой презентации: `- type: big-number`.
5. Чтобы блок правился формой в студии и был в библиотеке, опишите его поля в `src/studio/schema.ts` (`BLOCKS['big-number'] = { fields: [{ k: 'value', label: 'Число', type: 'text' }] }`) и добавьте заготовку в `src/studio/library.ts`.

Соглашения:
- цвета только через переменные темы (`var(--ac)`, `var(--surf)`, `var(--tx)`…) из `src/styles/tokens.css`, тогда тёмная тема заработает сама;
- класс `r` на элементе — появление с задержкой по очереди при открытии слайда;
- анимации, которые должны запускаться при открытии слайда, пишите через `.slide.on .ваш-класс { animation: … }`;
- текст из данных выводите через `t()` (экранирование и `**жирный**`), атрибуты — через `esc()`;
- чтобы текст правился в режиме правки, добавьте элементу метку из `src/engine/marks.ts`: `<b${ea(p, 'title')}>${t(p.title)}</b>`. Для картинки — `eimg(p, 'src')`, для ссылки — `eurl(p, 'url')`, для списка чипов — `chips(p.items)`. Метка знает, где значение лежит в `deck.yaml`, остальное редактор сделает сам.
